# 什么是物理AI
- 能够理解现实世界并与之进行交互的AI模型
- 传统大语言模型是理解生成文字，图像，对现实中的物理规律不理解

# 场景
   适合加载在具身机器人，身处于现实中并拥有“感知-推理-行动-反馈”

# 组成 
  物理AI组成：
- 感知系统--采集环境数据--多模态采集现实中多模态数据，通过摄像头及传感器相当于机器的眼睛和皮肤
- 决策系统--规划行动及策略 --以世界模型为核心理解和预测物理规律的基础上做出规划，和传统的AI模型不同，物理AI的决策必须在不确定行下进行，且要考虑重力，关系，碰撞等物理约束。黄仁勋发布的开源世界模型Cosmos
- 执行系统--执行端操作，完成动作

# AI的三个阶段
-  第一阶段：理解和生成数字内容的AI（大预言模型）
-  第二阶段：在数字世界中自主行动的Agentic AI （具身智能体，或者是自主行动：这里的行动不仅是运动也是比如调用工具，调用网页或者API接口等行为）
- 第三阶段：能在物理现实世界中感知，决策和执行的物理AI
- 最终阶段：AGI（通用人工智能）-**有通用智能**：能像人类一样学习、推理、解决**任何**领域的问题（不仅是数字世界的操作），并具备意识、常识、迁移学习能力。

落地场景：
- 自动驾驶
- 仓储物理
- 工业制造
- 人形系统
- 可穿戴设备
