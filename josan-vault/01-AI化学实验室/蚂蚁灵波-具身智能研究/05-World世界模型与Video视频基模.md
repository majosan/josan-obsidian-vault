## LingBot-World（世界模型）

### 一句话定义

**"在脑子里模拟物理世界"**——给定当前状态+一个动作，预测动作后的世界状态。

### 核心定义

> 沈宇军："在一个状态下，模型拿到一个action（动作），然后它能不能预测下一个state（状态）。"

```
输入：当前场景画面 + "机械臂右移5cm"
输出：机械臂右移5cm后的场景画面（预测）
```

### 世界模型 ≠ 视频生成（五大区别）

| 能力 | 普通视频生成（Sora等） | 真正世界模型 |
|------|----------------------|------------|
| **可控性** | 输入文本→生成影片，"一锤子买卖" | 输入动作→预测状态，可连续交互 |
| **实时性** | 可以慢，生成1分钟要10分钟 | 必须快，机器人等着做决定 |
| **合理性** | "猪在天上飞"被鼓励 | 必须符合物理规律 |
| **记忆性** | 不在乎前后一致性 | 必须记住之前发生了什么 |
| **持久性** | 几秒钟短视频 | 长时间维持世界状态 |

### 两个阶段

```
第一阶段：评测器
  "方案A vs 方案B，哪个更好？"
  → 在World里各跑10次模拟 → 比较结果 → 再上真机

第二阶段：策略优化
  "刚才那个动作导致物体被撞倒 → World给出负反馈"
  → 模型学习：下次换一种方式
```

### "沿途下蛋"

蚂蚁自己说World模型是"沿途下蛋"——不是最终目标，而是做具身智能路上顺带产生的副产品：

```
核心目标：做出能执行物理任务的机器人大脑
  ↓
过程中发现："需要能力预测动作后的结果"
  ↓
训练了World模型
  ↓
发布后C端觉得"视频生成好惊艳"
  ↓
但蚂蚁说：这只是"沿途下的蛋"，真正目标是具身智能
```

## LingBot-Video（视频基础模型）

### 一句话定义

VA和World的底层视频能力引擎。

### 作用

- 为VA模型提供视频编码/解码能力
- 为World模型提供视频生成底座
- 2.0版本更强调推理效率（解决VA延迟问题）

### 定位差异

蚂蚁明确说他们和Sora/通义万相/可灵是**不同赛道**——那些是视频生成基模，蚂蚁是在视频生成体系里做世界建模相关的"子方向"。
