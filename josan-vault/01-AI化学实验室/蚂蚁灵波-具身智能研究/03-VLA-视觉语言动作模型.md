# VLA：视觉-语言-动作基座模型

> 核心对比：[[VA-视频动作模型]] | [[VLA与VA对比与切换逻辑]]

## 一句话定义

**"看图 + 听懂人话 → 决定怎么动"**——机器人最主流的"大脑"路线。

## 通俗比喻

VLA像**一个会说中文的厨师**。你说"帮我切胡萝卜"，他看了菜板一眼（Vision），看到萝卜在哪（Depth），然后伸手去拿刀和萝卜开始切。

## 架构

```
输入1（视觉）：摄像头画面 → [Vision编码器] ─┐
                                            ├→ [VLM大模型] → 动作预测
输入2（语言）：人类指令 "把苹果拿给我" ────┘
```

**VLA核心**：先对齐 Vision↔Language（多模态对齐），再在这个空间里对齐 Action。

## 例子：拿苹果

```
场景：桌上有绿色苹果和红色杯子
指令："把苹果拿过来"

VLA工作流程：
  ① Vision → "桌上有绿色圆形物体、红色圆柱体"
  ② Depth → "绿色物体在中央偏右35cm处"
  ③ 语言理解 → "苹果=绿色圆形物体，拿=夹取+移动"
  ④ 动作预测 → "7自由度关节角度=[15°,23°,-8°,...]"
  ⑤ 发给电机执行
```

## VLA的两大限制（这就是为什么需要VA）

### 限制1：没有记忆

让机器人擦盘子三次→第一次擦完和第二次擦完的画面**一模一样**→VLA陷入死循环一直擦。

### 限制2：没有时间建模

"把盒子打开又关上"→开始和结束状态都是"盒子关着"→VLA以为**已经完成了**，不会开始。

```
VLA的盲区：
  时间轴：开始 → 动作1 → 动作2 → 完成
  视觉帧：[关着] → [打开] → [关着]
           ↑                       ↑
           VLA看这两个画面：一模一样！
           所以VLA无法区分"还没开始"和"已经完成"
```

## 蚂蚁灵波VLA的工程成就

- **2万小时真机数据**（实际采集约10万小时，数据漏斗~5:1）
- 覆盖 **17个品牌、20+种机器人构型**（1.0为9种）
- 覆盖 **300个评测任务**
- **GM-100真机评测得分超越Pi0.5**
- **仅需80条示例数据**即可迁移到新任务
- 推理延迟 ~**100ms**（可部署到Orin端侧芯片）
