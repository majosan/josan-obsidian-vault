# 芯片的定义：
- 芯片的本质就是在==半导体衬底上==制作能实现一系列特定功能的==集成电路==
- 半导体指常温下导电性能介于导体和绝缘体之间，且导电性可控的材料---**元素半导体和化合物半导体**
- 晶体管是一种固体半导体器件，具有检波，整流，放大，开关，信号调制等多种功能
- 逻辑门是在集成电路上的基本组件。==简单的逻辑们可由晶体管组成==

# 芯片制造过程：
- 主要包括IC设计，==晶圆制造==，封装和测试等一些列工序。整个流程类似3D打印的过程，一步步进行各部件的分层安装
- 晶圆制造是最重要的核心工序
