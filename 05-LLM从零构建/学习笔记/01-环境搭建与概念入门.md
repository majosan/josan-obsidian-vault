### 环境搭建（WS 公司台式）

**机器配置**：RTX 4060 (8GB) | CUDA 12.7 | Windows

**完整安装步骤**（供 HM/LP 参考）：

#### 1️⃣ 安装 Miniconda

- 下载地址：https://docs.anaconda.com/miniconda/
- 选择 **Windows x86_64** 版本
- 安装时**务必勾选** `Add Miniconda3 to my PATH environment variable`
- 或者装完后手动配 PATH 或在 PowerShell 执行：
  ```powershell
  [Environment]::SetEnvironmentVariable("PATH", "$env:PATH;F:\miniconda3;F:\miniconda3\Scripts;F:\miniconda3\Library\bin", "User")
  ```

#### 2️⃣ conda 初始化

```cmd
conda init
:: 然后关掉 cmd 重开
```

#### 3️⃣ 接受 Anaconda ToS（新版需要）

```cmd
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/msys2
```

#### 4️⃣ Clone 代码

```cmd
d:
mkdir learning
cd learning
git clone --depth 1 https://github.com/rasbt/LLMs-from-scratch.git
cd LLMs-from-scratch
```

#### 5️⃣ 创建环境

```cmd
conda create -n llms python=3.10 -y
conda activate llms
```

#### 6️⃣ 安装依赖 + GPU 版 PyTorch

```cmd
pip install -r requirements.txt
```

> ⚠️ 默认装的 PyTorch 是 **CPU 版本**，如果有 N 卡需要重装 CUDA 版：
> ```cmd
> pip uninstall torch torchvision torchaudio -y
> pip install torch==2.5.1 torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
> ```

#### 7️⃣ 验证

```cmd
python -c "import torch; print(f'PyTorch {torch.__version__}'); print(f'CUDA: {torch.cuda.is_available()}')"
```

✅ **预期输出**：
```
PyTorch 2.5.1+cu124
CUDA: True
```
