## 🔑 核心概念速览（Ch1）

### LLM 训练三阶段

```
阶段一：预训练（Pretraining）
  大量无标注文本 → 学习语言结构和知识
  ↓
阶段二：分类微调（Classification Finetuning）
  有标注数据 → 适配具体分类任务（情感分析等）
  ↓
阶段三：指令微调（Instruction Finetuning）
  指令-回复对 → 学会遵循指令（像 ChatGPT）
```

### GPT 模型骨架

```
输入文本
  ↓
Tokenizer（文本 → token IDs）
  ↓
Token Embedding（token IDs → 向量）
  ↓
Positional Encoding（加入位置信息）
  ↓
Transformer Block × N
  ├── Masked Self-Attention（关注上下文）
  └── Feed Forward（非线性变换）
  ↓
Output Layer（向量 → 下一个 token 概率）
```
