# 🔍 Ch2 代码实践 — Embedding 与 Position Embedding 深度理解

> 来源：2026-07-31 敲完 Ch2 代码后的理解整理
> 前置：`02-文本数据处理-Ch2数据输入Pipeline.md`

---

## 1. Embedding 本质 = 查表（Look-up Operation）

```
Token ID (如 5) ──→ 查表 ──→ [0.23, -1.05, ..., 0.87]  (768 维向量)
```

- 模型维护一张大表：**vocab_size × 768**（GPT-2 小模型）
- 每个 token ID 对应表里**一行**向量，查表 = 按行号取值
- PyTorch 实现就是一个 `nn.Embedding(vocab_size, emb_dim)` 层

### ⚠️ 关键澄清：向量不是"算法生成"的

| 误解 ❌ | 正解 ✅ |
|--------|--------|
| 内置算法算出一个多维特征向量 | 表是**随机初始化**的，训练中靠梯度**学出来**的 |
| 查表 = 生成向量 | 查表 = **取**向量（表里早就有了，只是数值被训练调优） |

> 一句话：**表是训练学出来的参数，查表只是取数。**
> 这与"词汇表是 BPE 预训练阶段构建的"是同一类认知——区分"训练时学出来的" vs "运行时算出来的"。

### 为什么叫"嵌入"（Embedding）
把离散的 token ID（整数）映射到连续的高维向量空间，
相似的词在向量空间里距离更近（"猫"和"狗"近，"猫"和"火箭"远）。

## 2. Position Embedding（GPT-2 = 可学习绝对位置）

- 为什么需要：**查表只给了"是什么"（词义），没给"在哪里"（顺序）**
- 语言顺序很重要："我打你" ≠ "你打我"
- GPT-2 方案：**绝对位置编码**，每个位置一个向量，**也是可学习的**

```python
# GPT-2 里就是一个独立的 Embedding 层
nn.Embedding(max_length=1024, emb_dim=768)   # 固定最大长度 1024
```

### ⚠️ 关键澄清：GPT-2 位置向量不是算出来的

| 方案 | 是否可学习 | 谁在用 |
|------|-----------|--------|
| 正弦/余弦公式（sin/cos） | ❌ 固定公式，不可学习 | Transformer 原论文 |
| **可学习位置表** | ✅ 训练中学出来 | **GPT-2**（以及多数现代 LLM） |

- 不是按当前文本长度"动态计算"位置向量
- 而是**固定 1024 行**的表，位置 0 查第 0 行，位置 1 查第 1 行……
- 超过 1024 的文本 GPT-2 处理不了（上下文窗口限制）

---

## 3. 输入向量 = Token Embedding + Position Embedding

```
输入向量 = 查 token 表(取词义) + 查位置表(取位置)
         = [768维]          + [768维]        → 逐元素相加 → 也是 768 维
```

- 两个向量**形状相同**才能相加
- 相加后进入 Transformer 的 Attention 层（Ch3 的主角）

---

## 4. 核心记忆框架

```
GPT-2 里两张"可学习"的表：
┌─────────────────┬──────────────┬─────────────┐
│ 表               │ 形状          │ 回答的问题   │
├─────────────────┼──────────────┼─────────────┤
│ Token Embedding  │ vocab × 768  │ 这是什么词？ │
│ Position Embedding│ 1024 × 768  │ 它在第几位？ │
└─────────────────┴──────────────┴─────────────┘
输入向量 = 两张表查出来的向量相加 → 送给 Attention
```

## 5. 项目映射：触觉 VQ-VAE 的 codebook

- VQ-VAE 的 **codebook（码本）** 就是"触觉 token 的 embedding 表"
- 触觉信号 → 量化 → 查 codebook → 取向量，和 GPT 查表是同一思想
- 触觉时序数据同样需要位置/顺序信息（压力轨迹的先后顺序）

## 6. 自测题

1. `nn.Embedding(vocab_size, 768)` 的参数数量是多少？（答：vocab_size × 768）
2. 训练刚开始时，两张表里的数值是什么状态？（答：随机初始化，尚未学习）
3. GPT-2 能处理多长的文本？（答：≤1024 token）
4. 如果把 Position Embedding 去掉，模型会失去什么能力？（答：无法感知词序，"我打你/你打我"分不清）
