# 📚 LLMs-from-scratch 教程分析

> **仓库**: [rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch)
> **作者**: Sebastian Raschka (PhD)
> **配套书籍**: 《Build a Large Language Model (From Scratch)》Manning 出版
> **技术栈**: Python + PyTorch，纯手写不依赖第三方 LLM 库
> **硬件**: 普通笔记本即可，有 GPU 自动利用

## ⭐ 评价：强烈推荐

### 作者背景
Sebastian Raschka 是 Manning 出版社的常青树作者，PyTorch 社区核心人物。他的《Python Machine Learning》是很多人的 ML 入门读物。不是普通博主，是正经的 ML 教育者。

### 内容结构（7 章递进）

```
Ch1  概念入门           → LLM 是什么，整体路线图
Ch2  文本数据处理        → Tokenizer/BPE/Embedding
Ch3  Attention 机制      → 自注意力/因果注意力/多头注意力
Ch4  从零搭 GPT 模型     → 完整 GPT 结构
Ch5  预训练              → 正式训练你的模型
Ch6  Fine-tune 分类任务   → 有监督微调
Ch7  Fine-tune 指令跟随   → Instruction Following

附录 A → PyTorch 入门（零基础也能跟上）
附录 D → 训练技巧（学习率调度等）
附录 E → LoRA 微调
```

### 跟我们的项目关联

| 我们的项目 | 这个教程能给的 |
|---|---|
| LabVLA / VLA 模型 | 理解 Transformer 底层工作原理 |
| Agent 设计 | 搞懂"大脑"内部机制 |
| LoRA 微调 | 附录 E 专门讲参数高效微调 |
| 化学实验室自动化 | 未来可能需要自己训练/微调小模型 |
| 触觉数据编码 (VQ-VAE) | 需要理解模型内部结构 |

### 学习资源
- **📖 有书**：Manning / Amazon 购买
- **💻 有代码**：全 Jupyter Notebook，每章节分好
- **🎬 有视频**：17 小时配套视频课程（可选）
- **✍️ 有练习**：每章末尾，附带答案
- **🆓 有测验**：免费 170 页自测 PDF

### 续作：Build A Reasoning Model (From Scratch)
从预训练模型出发，教你实现 reasoning（推理时扩展、强化学习、蒸馏等）。

## 🗓️ 建议学习节奏

```
Day 1（今天）:  环境搭建 + Ch1 概念概览
Day 2-3:        Ch2 文本处理（BPE/Embedding）
Day 4-5:        Ch3 Attention（最核心，建议看两遍）
Day 6-7:        Ch4 搭 GPT 模型
Day 8-9:        Ch5 预训练
Day 10:         Ch6 分类微调
Day 11-12:      Ch7 指令微调 + LoRA (附录E)
```

**关键**：别光读，一定要跑代码。
