## 📝 今天学到了什么？

**环境搭建要点**
- conda 创建环境 → `conda create -n llms python=3.10 -y`
- Anaconda 新版需要先 `conda tos accept` 接受条款
- `pip install` 默认装 CPU 版 PyTorch，有 N 卡要手动换 CUDA 版
- 验证命令：`python -c "import torch; print(torch.cuda.is_available())"` 要返回 True

**LLM 三阶段**
1. Building — 设计模型架构
2. Training — 大规模无监督预训练
3. Finetuning — 分类微调 / 指令微调
