## 📝 今天学到了什么？

**1. Ch1 核心概念清晰化**
- Embedding：词 ID → 768 维向量的查找表（可训练参数）
- Multi-Head Attention：12 个头并行关注不同关系类型，最后拼起来
- Loss & 梯度下降：训练阶段的事，推理阶段没有
- RAG vs 微调：RAG 是外挂知识库不用改模型，微调是调模型参数

**2. 数据输入 Pipeline（Ch2 核心）**
```
原始文本 → Tokenizer(BPE查表) → Token IDs → Embedding层(查表) → 向量 + 位置编码 → Transformer入口
```

**3. 关键纠正**
- 词汇表是 BPE 训练阶段预生成的，不是处理文本时现建的
- Embedding 层是模型的第一个可训练参数层，不是预处理

---

## ⭐ 最有价值的收获

**Tokenizer → Embedding → Position Encoding 三步骤**是整个 GPT 的基础，
理解了它就能理解后续所有 Attention 机制是"在什么数据上干活"的。
