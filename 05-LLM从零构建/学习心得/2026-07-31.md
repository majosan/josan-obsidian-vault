## 📝 今天学到了什么？

**1. Embedding 本质 = 查找表（look-up operation）**
- 内置算法生成一个 embedding 多维特征向量集合（权重矩阵）
- 通过 token 的 ID 数值去查表，取回对应的特征向量
- ⚠️ 澄清：向量不是"算"出来的，是**训练中学出来的参数**（随机初始化 + 梯度更新），
  查表只是"取"的过程，不是"生成"的过程

**2. Position Embedding（GPT-2 = 绝对位置）**
- 为每个位置分配一个绝对顺序的位置向量
- ⚠️ 澄清：GPT-2 的位置向量也是**可学习参数**（固定最大长度 1024 的查找表），
  不是按文本长度动态计算出来的；区别于 Transformer 原论文的正弦/余弦固定公式

**3. 输入向量 = Token Embedding + Position Embedding（逐元素相加）**
