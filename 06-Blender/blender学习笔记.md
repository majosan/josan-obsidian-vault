# 🟠 Blender 学习笔记

> 3D 建模场景三要素：**1 模型 · 2 灯光 · 3 摄像头**

## 基础操作

- **删除**：选中物体按 `Delete` 或 `X`
- **新建物体**：`Shift + A`
- **移动**：按 `G` 进入移动，再按 `X` / `Y` / `Z` 沿对应轴直线移动（也可按住滚轮滑动选择轴方向）
- **缩放**：按 `S`，鼠标拖动放大缩小
- **旋转**：按 `R`
- **恢复初始变换**：`Alt + G` / `Alt + R` / `Alt + S` 回到最初的视角大小和位置

## 视图控制

- 小键盘 `1` / `3` / `5` 是各个正视图，`2` / `4` / `6` 按 15° 角度微调，`.` 把视角推进，`0` 是相机视角
- 按住 `~` 会弹出视角盘（类似 SolidWorks 按住右键滑动调出视角盘）
- `Ctrl + Space` 恢复界面

## 游标与原点

- `Shift + 右键`：游标出现在点击位置
- `Shift + C`：游标回到最初位置
- `Shift + S`：调出专门控制游标的饼状菜单

## 鼠标设置

- 鼠标滚轮缩放默认以视图中心为基准；想在鼠标所在位置缩放，可以在偏好设置中修改
- 按住滚轮旋转默认是围绕物体旋转，也可以在设置中修改
