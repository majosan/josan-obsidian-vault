先看各自工艺：

Copy

```
STAG（MIT）：
  压阻薄膜（整张）→ 打孔 → 导电纱线穿过去缝到手套上
  优点：薄膜是连续的，传感器位置由孔位决定
  缺点：薄膜不透气、不能揉、折叠多了薄膜会裂

你的（三层织物）：
  底层镀银纱线（横）→ 压敏纱线（中间）→ 顶层镀银纱线（纵）
  全部用刺绣机一次性绣出来
  优点：全透气、可折叠揉搓、机器批量生产一致性高
  缺点：刺绣过程中纱线张力不一致可能导致传感点偏移
```

**精度对比：**

|维度|STAG 薄膜穿孔|你的织物刺绣|
|---|---|---|
|**单件精度**|孔位准确定位，误差小|绣花机精度 ±0.1mm，也很高|
|**批间一致性**|**差** —— 每只手工缝制，位置会偏|**好** —— 机器绣，参数固定|
|**规模化**|❌ 手工活，产量上不去|✅ 机器批量绣，一模一样|

**结论：** 你的担心可以放下。STAG 是**手工实验品**，你的工艺反而更适合量产。STAG 发 Nature 靠的是原理创新，不是制造精度。刺绣机的重复精度足够保证传感器位置一致。

## 问题二：弯曲干扰——这是你要攻克的核心工程问题

你直觉很准——这是**织物传感器最头疼的问题，没有之一**。

### 物理根源

Copy

```
你的三层织物传感器：
  镀银纱线（电极层）
  压敏纱线（传感层）
  镀银纱线（电极层）

平铺时：三层平整接触 → 电阻稳定
握拳时：织物弯曲 → 三层之间压力变化 → 电阻变化
效果：你以为握住了东西，其实只是弯了手指
```

STAG 的薄膜因为有一定刚性，弯曲时薄膜本身的形变小，所以干扰小。织物是软的，干扰就是它柔软性的**副作用**。

### 解决办法——软硬结合

#### ✅ 硬件层面（推荐优先做）

**① 在非传感区域做结构加强**

Copy

```
问题核心：弯曲时三层之间的压力变化
解决办法：在传感点周围加固，减少弯曲对传感层的挤压

具体做法：
  在每行传感点之间绣一条"隔离线"（非导电纱线）
  作用：弯曲时应力被隔离线吸收，不传递到传感点
```

这个方法在柔性 PCB 领域叫 **strain relief**（应变释放），织物上也可以类比做。

**② 手套尺寸要贴手但不能紧**

Copy

```
太松 → 传感器悬空，信号不稳定
太紧 → 不握东西已经有预压，弯曲时变化大

建议：定制尺寸，而非均码。STAG 也是定制的针织手套。
```

#### 💻 软件层面（必须做）

**① 基线校准（最简单的办法）**

Copy

```
开机后：先采集一组"空手姿态"的基线数据
  握拳状态 → 记录基线A
  五指张开 → 记录基线B
  自然弯曲 → 记录基线C

实际使用时：
  实时信号 - 当前姿态的基线 = 真正的接触信号
```

这能消除大部分弯曲干扰。

**② IMU 辅助校准（更高级）**

你的手套有 IMU（手背 BNO055），正好派上用场：

Copy

```
IMU 数据告诉你手现在是什么姿态
  │
  ▼
查表：这个姿态下应该有什么基线值
  │
  ▼
减去基线 → 得到净接触信号
```

**③ 高频滤波**

Copy

```
弯曲产生的干扰：低频信号（0-2Hz，弯曲的动作慢）
接触物体产生的：中高频信号（2-20Hz，抓握瞬间冲击）

用高通滤波器切除 1Hz 以下的成分
  → 保留接触信号
  → 滤掉慢速弯曲漂移
```

**④ 训练时加入负样本**

这是最彻底的办法——让你的模型自己学会区分：

Copy

```
采集训练数据时，专门录制一段：
  "空手做各种手势"的数据（弯曲但不碰东西）
  ↓
在训练 VLA 模型时，把这些数据标注为：
  "没有接触"（即不触发动作）
  ↓
模型自己能学会：弯曲≠接触
```

### 推荐方案组合

Copy

```
近期（样品测试阶段）：
  ✅ 高频滤波（一行代码的事）
  ✅ 基线校准（采集3个姿态的基线）

中期（正式采集数据前）：
  ✅ 加上 IMU 辅助校准
  ✅ 在绣花设计上加应力释放结构

长期（模型训练时）：
  ✅ 采集空手姿态的负样本
  ✅ 让模型学习区分弯曲 vs 接触
```
