## 🎯 各自角色——一句话说清楚

### 1. MuJoCo — **物理世界的模拟器**

就像游戏引擎（物理引擎），定义了「重力怎么拉、碰了会弹、摩擦多大」。因为真机实验贵又慢，先在虚拟环境里跑。

**类比**：你建了个虚拟实验室，MuJoCo 就是这个虚拟世界的物理法则。

### 2. RoboGenesis — **自动做实验的数据工厂**

它**跑在 MuJoCo 之上**，不是模型。它封装了 pick（抓）、pour（倒）这些原子操作，你只需要说"生成 1000 条倒水的数据"，它就自动在仿真里倒 1000 次，把每帧的手爪位置、角度、速度全部记录下来。

**类比**：一个自动化学实验员，在虚拟实验室里不停重复做实验，记录下每一步的操作数据。

### 3. LabVLA — **整个模型框架的名字**

VLA = Vision-Language-Action（视觉-语言-动作）。LabVLA 是浙大开源的**科学实验室版 VLA**，核心是一个神经网络：你给它一张实验台照片 + 指令"把烧杯里的水倒进试管"，它输出机械臂关节如何运动。

**类比**：一个人脑（神经网络），看了画面、听了指令，决定手怎么动。

### 4. 编码通道 — **翻译器 / 压缩包**

你的触觉手套每帧输出 124 个压力值，这些**原始数据模型看不懂**。编码通道的作用：

- **CNN（空间）** → 看 124 个点排成 8×16 阵列，提取「压力集中在哪个区域」
- **VQ-VAE（时间）** → 看连续 16 帧的变化趋势，压缩成几个关键的「模式码」

**类比**：你用手语说话，需要一个翻译把动作转成文字，模型才能理解。

```
        ▼

```

## 📊 速查表

|名词|本质|一句话|
|---|---|---|
|**MuJoCo**|物理引擎|仿真世界的地心引力和物理规则|
|**RoboGenesis**|数据工厂|自动在仿真里做实验、生成训练数据|
|**LabVLA**|模型框架|视觉+语言→动作输出的神经网络|
|**编码通道**|数据预处理|把触觉原始信号转成模型能消化的格式|
