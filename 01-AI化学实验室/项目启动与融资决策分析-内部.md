## 一、核心结论（一句话）

**走"场景化"（DRIFTS 机器人化切入），不走"触觉传感器单飞"——因为触觉单独没有市场抓手，嵌进场景才有定价权、数据飞轮和政策买单。决策靠"最小验证 + 分阶段 Gate"，不靠"赌市场大"。**

---

## 二、两条路线的抉择

| 维度 | A 触觉单飞融资 | B 场景化（DRIFTS 切入）✅ |
| :-- | :-- | :-- |
| 商业逻辑 | 卖零件，无定价权 | 卖系统，¥30-50 万/套 |
| 客户抓手 | 下游不成熟、无批量切入点 | 高校/科研，政策买单 |
| 数据飞轮 | 拿不到 | 每次实验产触觉+视觉+光谱数据 |
| 壁垒 | 单点技术，易被抄 | 四维交叉（场景+触觉+力控+AI 闭环） |
| 融资/并购 | 故事弱 | 有完整闭环 + 并购先例（Chemspeed→Bruker） |

**为什么 B 对（三条）**：
1. 投资人不投"纯零部件"（除非已是龙头）——触觉单飞第一问"卖给谁"答不上来。
2. B 把触觉从"卖不出去的产品"变成"系统里的关键部件"——现有 1024 阵列/电路/软件原封复用。
3. B 有完整投资闭环（场景→客户→付费方→壁垒→数据→退出）。

**老板质疑"结合度"的回答核心**：不是"另起炉灶"，是"旧技术终于找到了能赚钱的场景"。（详见简报 3.3 四条硬逻辑）

---

## 三、决策框架：最小验证 + 分阶段 Gate

**别 all in。** 把"要不要投一大笔"拆成逐步走、每步带退出按钮：

1. **先投"最小验证资金"**：只投能验证最核心假设的最小一笔——即 DRIFTS 最难的 0.05N 力控 + 触觉采集 + 真机闭环能否跑通（M1 仿真 → M2 POC）。
2. **设明确 Gate 标准**：Gate A「80 分」即现成标准。过 → 投下一笔 + 启动融资；不过 → 止损退出（简报 8.2 已写）。
3. **融资是"验证之后"才有效**：demo 没跑通，融资故事是空的；跑通 M2 POC，才有"真东西"去融。
4. **市场调研与 demo 并行**，但市场不决定"要不要启动"——启动决策靠"技术能否跑通"。

**一句话**：从"要不要投一大笔"→"投最小那笔验证最核心假设，看 Gate 结果"。

## 四、厘清"赌未来"心结

**投资人不投"赛道大"，投"你能拿到第一笔收入"。**

- 不用证明"AI 实验室市场大"（证明不了，也不需要）。
- 只需证明"DRIFTS 这个细分有人愿意付钱、我能交付"。
- **DRIFTS 市场小没关系**：它的定位是"小切口、验证能力、拿第一单"，不是"撑起估值"。真正的故事是"AI 无人高通量实验室"大盘子，DRIFTS 是敲门砖，再复制到 XRD/TPD/能源现场。

## 五、两个要记住的风险

### 1. 股权要早谈（现在不定比例，但定"角色 + 触发条款"）
- 当前状态：还在上班领工资，未谈股权。
- **不要现在定比例**（没依据、老板不会答应），但**要现在定两件事**：
  - **定性**：我是这个项目的"技术负责人/联合发起人"，不是普通员工做项目。
  - **触发条款**：约定"到 [里程碑 X]（如 demo 跑通 / 新公司成立 / 融到第一笔）时，双方正式约定股权/利益分配"——哪怕一封邮件、一页备忘录。
- **为什么不能拖到"某个阶段"才第一次谈**：到那时技术已成型，你的议价能力反而变低（变成"可替代的执行者"）。房地产老板转型最易踩的坑：出钱的、出技术的都安排了，**出方向的被落下**。

### 2. 关系好，更要早签协议（IP 归属 / 未来股权 / 退出机制）
- 核心壁垒在浙大朋友手里（催化 know-how + AI agents），用户全程参与。
- **横向合作阶段正是最该写清楚的时候**：合作期间产生的 IP 归谁？未来新公司怎么分？方向不行怎么退出？
- 不是怀疑朋友，而是"先小人后君子"——提前写清，避免项目起来了再谈反而伤感情。
- **用户自己的筹码定位**：触觉技术（1024 阵列/电路/软件）+ 转型方向 + 整合执行 → 新公司里更接近"CEO/整合者"角色，而非"核心科学家"。谈股权时要想清楚这一点。

## 六、对外解释逻辑（可放进简报 / BP 的表述）

1. **为什么是 DRIFTS 切入**：DRIFTS 是催化研究"金标准"、存量仪器多、零竞争、政策买单、数据价值高——"小切口验证能力"。
2. **为什么不是直接卖触觉**：零件无定价权、无数据、无场景、无政策；系统才有（简报 3.3 四条硬逻辑）。
3. **结合度**：触觉手套是 DRIFTS 机器人的"手"，现有技术原封复用，不是另起炉灶。
4. **市场怎么算**：自下而上 = 催化课题组数 × 单套改造费 × 渗透率（不用证明"市场大"，只证明"细分有人买"）。
