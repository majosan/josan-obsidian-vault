## 一、触觉手套数据 → "触觉视频帧"

### 核心概念

VA说的"视频"，本质是**按时间排列的帧序列**。帧不一定是RGB图片，**任何时间序列的传感器数据都可以做成"帧"**。

### 触觉手套数据维度

假设触觉手套传感器配置：
```
每根手指：压力传感器×2（指尖+指腹）+ 弯曲传感器×1
手掌：压力传感器×3（掌心+两侧）
IMU：加速度计3轴 + 陀螺仪3轴
温度×1
────────────────────────
总维度：5指×(2+1) + 3 + 6 + 1 = 25维
```

**每10ms采集一次** → 每秒100帧。

### 一帧触觉向量

```
时间t的触觉帧 = [25维向量]
[ 
  拇指尖压力, 拇指腹压力, 拇指弯曲,
  食指尖压力, 食指腹压力, 食指弯曲,
  ...
  accel_x, accel_y, accel_z,
  gyro_x, gyro_y, gyro_z,
  温度
]
```

### "触觉视频" = 连续N帧堆叠

以"夹取样品"为例（约2秒=200帧）：

```
帧1:  [0.0, 0.0, ...]   ← 手指还没到位
帧20: [0.8, 0.6, ...]   ← 接触到样品瓶，压力上升
帧40: [2.0, 1.8, ...]   ← 夹紧完成
帧50: [2.0, 1.8, ...]   ← 提起（IMU检测向上加速）
帧60: [1.8, 1.6, ...]   ← 提起中，轻微晃动
帧200:[0.0, 0.0, ...]   ← 释放，回到原位
```

### 编码为VA的输入

```
步骤1：帧编码（Frame Encoder）
  输入：原始触觉帧 [25维]
  输出：触觉token [d维]
  实现：MLP
  25维 → 64 → 128 → d

步骤2：位置编码
  给每个token加上"它是第几帧"的信息
  保证因果attention——帧30只能看到1-29

步骤3：送入VA自回归Transformer
  [token1, token2, ..., tokenN] → VA → 预测下一帧 + 输出动作指令
```

## 二、光谱序列编码成"帧"

### DRIFT光谱的一帧

```
每个DRIFT光谱 = 400-4000 cm⁻¹的强度值（约1001个数据点）
第t秒的光谱帧 = [I₄₀₀, I₄₀₁, ..., I₄₀₀₀] = [1001维向量]
```

### 光谱"视频"（60分钟，5分钟/次，12帧）

```
帧1  (t=0min):  [0.12, 0.13, ...]  ← 背景
帧2  (t=5min):  [0.12, 0.15, ...]  ← 开始出现峰
...
帧12 (t=60min): [0.11, 0.15, ...]  ← 反应结束
```

### 光谱帧编码器设计

```
原始光谱 [1001维]
  → 降采样到标准长度（512或1024点）
  → 1D-CNN编码器：Conv1D → ReLU → MaxPool → Conv1D → ...
  → 输出光谱token [d维]
  → 加上时间位置编码（第N分钟）
  → 喂给VA
```

### 处理稀疏帧（关键技巧）

原位实验每5-10分钟才采一次光谱，不像视频每秒30帧。

**方案A：帧插补（推荐）**
```
原始：帧1(t=0min), 帧2(t=5min), 帧3(t=10min)...
插补后：帧1(t=0), 帧1.1(t=1), 帧1.2(t=2)...帧2(t=5)...
好处：VA看到"连续"变化，更容易学习时间规律
```

**方案B：稀疏Transformer**
```
修改VA的attention机制
帧1可以直接attention到帧12（如果因果允许）
时间差作为position encoding的一部分
```

### 多模态"混合视频帧"

```
第t帧 = [视觉特征 || 触觉特征 || 光谱特征]

① 视觉帧：摄像头→Vision模型→视觉token [128维]
② 触觉帧：触觉手套→MLP编码器→触觉token [64维]
③ 光谱帧：DRIFT光谱→1D-CNN编码器→光谱token [64维]
④ 拼接：[128+64+64] = [256维]

"混合视频" = 帧1, 帧2, ..., 帧N（每帧256维）
```

## 三、VLA↔VA切换逻辑

### 原则

**不能让两个模型同时指挥机械臂。**

### 伪代码

```
while 实验进行中:
  if 当前任务.type == "单步操作":
    model = VLA
    VLA执行(当前视觉帧, 触觉帧, 指令)
    if 当前任务 == "开始原位追踪":
      编排器.启动VA()  # 在后台初始化VA
  
  elif 当前任务.type == "时序追踪":
    model = VA
    VA输出 = {
      下一帧预测光谱,
      当前反应阶段判断,   # 诱导期/加速期/平稳期
      建议下一步动作,     # 继续采集/主动干预
      置信度
    }
    # 检查点机制
    if 当前时间 % 15min == 0:
      VLA检查 = VLA(当前状态)  # VLA确认一下
      if VLA检查 != VA判断:
        编排器.触发仲裁(置信度比较)
```

### 完整场景展示

```
步骤1："取样" → [VLA]
  编排器路由：→ VLA
  VLA执行：夹取样瓶→称20mg→放入DRIFT样品杯

步骤2："开始原位追踪" → [VLA启动] + [VA后台初始化]
  VLA执行：采背景光谱→开始加热→注入反应气
  VA启动：接收光谱流→构建"光谱序列"
  编排器收到"反应已启动"→切换到VA主模式

步骤3："持续追踪60分钟" → [VA主模式]
  每5分钟采一次光谱 → VA更新反应进程模型
  VA预测下一阶段光谱
  正常→继续；异常→触发检查点

步骤4："检查点"（每15分钟）→ [VLA确认]
  VLA看当前状态："和VA说的差不多"→继续
  
  异常触发（假设出现CO₂峰）：
    VA判断："可能是漏气"（置信度0.6）
    编排器：置信度低于阈值→调用VLA确认
    VLA看画面+指令："检查手套箱密封"
    如果VLA也确认异常→切换到应急流程

步骤5："实验完成" → [VLA]
  VLA执行：停止加热→保存数据→清理→报告
```

### 注意：任务内部的混合使用

即使"取样"这样的VLA任务，如果需要对比多次取样的一致性，也可以临时调用VA比较光谱序列（跑一小段，2帧对比），再切回VLA继续执行。
