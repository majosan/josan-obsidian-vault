# VA：视频-动作模型（世界动作模型）

> 核心对比：[[VLA-视觉语言动作模型]] | [[VLA与VA对比与切换逻辑]]

## 一句话定义

**"看视频学会怎么动"**——用视频生成的方式来预测动作，天生具备记忆和时间感知。

## 通俗比喻

VA就像**一个用"看视频"学做菜的厨师**。他看了10万小时做菜视频，形成了"肌肉记忆"。现在你说"切胡萝卜"，他不是分析画面算角度，而是直接回想视频中"切胡萝卜"的画面序列，用这个序列指导手怎么动。

## 和VLA的核心差异：对齐路径不同

```
VLA：  Vision → Language → [对齐] → Action
       先让"看"和"说"对上，再说怎么动

VA：   Video(motion) → Action → [对齐] → Language
       先让"看视频"和"怎么动"对上，再理解语言指令
```

## 例子：擦盘子三次（对比VLA）

```
VLA的表现（无记忆）：
  帧1：看盘子有污渍 → 擦一次
  帧2：看盘子还有点污渍 → 再擦一次  
  帧3：看盘子干净了 → VLA不知道擦了几次 → 死循环
  ❌ 失败

VA的表现（有记忆）：
  帧1：看到盘子 → 内部记忆=已擦0次
  帧2：确认"污渍减少了" → 内部记忆=已擦1次
  帧3：预测"再擦一次会更干净" → 内部记忆=已擦2次
  帧4：确认干净 → 主动停止 ✅
  ✅ 成功：VA用视频序列建模，天然有记忆
```

## VA的核心问题

### 问题1：幻觉（视频生成"无中生有"）

```
真实场景：桌上只有红色杯子
VA预测画面：桌上多了个瓶子 ← 视频生成模型幻觉了！
结果：机器人伸手去抓空气 → 失败 ❌

蚂蚁灵波的解法：
  ① 高速刷新（一帧帧修正）→ 用真实摄像头画面实时校正
  ② 后训练强化学习 → 约束生成内容符合物理事实
```

### 问题2：延迟

```
VLA：100ms就能决定动作
VA： 300-400ms才能决定动作（要先"画"几帧再看结果）

差了3-4倍！解法：异步推理
"机器人边动边想"——动作执行中，VA在后台持续生成预测
```

## VA 2.0的四大核心创新

### 1. 语义视觉-动作Tokenizer（新编码器）
以前Vision编码只做"看懂图像"，现在编码器同时学习"这帧画面和动作有什么关系"。

### 2. 严格因果预训练（单向注意力）
只能用过去的画面预测未来，不能"回头看"。就像人类：你看不到未来，但未来可以看到你的过去。

### 3. MoE（混合专家架构）
模型里有很多"小专家"，各自擅长不同任务。遇到"抓取"调抓取专家，遇到"推动"调推动专家，不用全激活省算力。

### 4. 异步推理 → 150Hz实时推理
通过异步推理从300ms降到了约6.6ms/帧。方法：边执行动作边在后台预测下一帧，永不等待。

## 指标总结

| 指标 | VA 1.0 | VA 2.0 |
|------|--------|--------|
| 推理延迟 | 300-400ms | 150Hz (~6.6ms/帧) 异步 |
| 架构 | 自回归扩散 | 自回归扩散+MoE+因果 |
| 推理速度 | 慢 | 单卡150Hz |
| 幻觉 | 存在问题 | 通过高速刷新+RL缓解 |
