## 快速开始（5 步）

1. **查公司制度**：确认没有兼职限制/竞业协议（决定"接单"这条路能不能走，最重要）
2. **备素材**：按 `08` 拍传感器实拍 + 翻出电竞桌/智能家居旧照片（有就行，不要求精致）
3. **发第一篇**：`10` 号文件第一篇（人设开篇）今天就能发，AI 图+旧照片即可
4. **每天回私信**：有人问就引导加微信，进入接单流程（SOP 在 `06`）
5. **第 2 周**：把数据（阅读/互动/私信）发我，我们调选题聚焦

## 三条红线

1. **接单前确认公司兼职政策**——副业别砸主业饭碗
2. **公司项目脱敏**：不拍涉密区、不暴露未公开细节；接单业务不与公司业务直接冲突
3. **小红书引流规则**：正文/评论不放微信号，用"私信"承接，企业号（¥600/年）合规挂载
