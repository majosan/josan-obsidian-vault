# 12 · 私信接单话术库（复制即用）

> 目的：当第一个询盘来的时候，你不慌。以下话术按场景抄改即可。
> 总原则：**先筛选、再报价、收定金、留记录**。你不是客服，你是技术顾问。

## 场景 1：有人私信"这个是怎么做的？能教吗？"

> 谢谢你感兴趣！原理我后面会专门写一篇拆解，可以先关注不迷路。
> 如果你是想要类似的效果/产品，可以聊聊你的需求，我这边做定制开发。

（判断：纯好奇 → 留在评论区养着；有需求 → 转入场景 3）

## 场景 2：有人私信"你们产品卖吗？多少钱？"

> 目前产品还在 demo 阶段，还没量产哈。不过如果你有具体需求，我可以帮你评估方案、做定制开发——你想用在什么场景？

（诚实说明状态 + 把"买产品"翻译成"谈需求"。demo 阶段不硬卖，卖能力。）

## 场景 3：有人私信"能帮我做个 XX 吗？"（询价核心场景）

**第一步 · 需求确认四问（缺一不可）：**
1. "这个大概用在什么场景？"（用途决定技术路线）
2. "功能上必须满足什么？什么可以妥协？"（分清刚需和加分项）
3. "时间上有要求吗？"（周期影响报价）
4. "预算大概什么范围？方便我评估方案可行性"（先探预算再报价，别先报价）

**第二步 · 加微信（注意平台规则）：**
- 稳妥版："方便的话你留个微信，我加你细聊需求，私信里说不清楚。"
- 让对方留联系方式、你主动加，比你在私信里甩微信号更安全（防平台检测）
- 加了微信后：先寒暄一句 → 把四问再确认一遍 → 出一页简版方案 + 报价

**第三步 · 报价（参考区间，按你实际调整）：**
| 业务 | 参考价 |
|---|---|
| 技术咨询（选型/方案评审/答疑） | ¥200-500/小时 |
| 小型 demo 定制 | ¥3k-1w |
| 完整产品开发（机械+软硬件） | ¥2w-10w+ |
| 长期外包/技术顾问 | 面议 |

报价话术：
> 按你描述的需求，我给个初步评估：XX 功能 + XX 周期，整体预算大概在 X 万这个量级。详细方案我整理一页发你，你确认后我们开工。

## 场景 4：对方嫌贵

> 理解，预算确实是个现实问题。给你两个思路：一是砍功能，把非刚需的部分去掉，能降到 X；二是分阶段做，先做核心 demo 验证，跑通再加功能。你看哪个方向合适？

（给选择不给让步，把"降价"变成"换方案"——别轻易自砍价，自砍一次以后都是这个价。）

## 场景 5：谈成后（定金与记录）

- **收定金**：30-50%，话术："确认没问题的话，先付 30% 定金，我排期开工。尾款交付时结清。"
- **留记录**：把需求、功能清单、周期、价格写成一页确认单（微信里发文字版即可），对方回复"确认"截图存好——口头承诺不算数
- **不接的果断拒**：需求不清、预算离谱、催得急又不肯付定金的，礼貌婉拒："这个需求目前排期做不了，建议你找 XX 方向的服务商，抱歉帮不上。"

## 场景 6：交付后（滚雪球）

- 交付时问一句："如果方便的话，这个案例我可以脱敏后发出来做展示吗？"（客户同意 → 变成你的内容素材，案例越多单越贵）
- 顺便铺垫复购："后续有迭代需求随时找我，老客户优先排期。"

## 红线（接单前必须确认）

1. **查公司制度**：有无兼职限制/竞业协议 → 有就别接，或只接不冲突领域的单
2. 不接与公司业务直接竞争的单
3. 用业余时间做，不在办公时间/办公设备上做私单
4. 每单收定金、留书面确认，不赊账、不做免费方案
