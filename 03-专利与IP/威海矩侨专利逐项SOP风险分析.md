# 威海矩侨 15 项专利逐项 SOP 风险分析（供代理所沟通）

> 编制：Sensing Vanguard ⚡
> 日期：2026-08-14
> 说明：本文对威海矩侨 15 项专利逐条做「权利要求要点 → 我方重合特征 → 风险判定 → 规避建议」分析。其中已授权实用新型与核心发明为**权利要求级**深度，其余为**摘要级**。建议后续以国知局（CNIPA）官方权利要求文本复核。

## 0. 分析 SOP（方法说明）

每项专利按 5 步走：
1. **基本信息**：公开号 / 名称 / 法律状态 / 优先权日
2. **独立权利要求要点**：必要技术特征拆解（侵权判定只看独立权利要求字面范围）
3. **我方重合特征**：对应我方 7 项专利 / 无人实验室应用的哪个点
4. **风险判定**：🔴新颖性（我方专利被驳）/ 🟠侵权（我方产品落地被诉）双维度
5. **规避建议**：可执行的结构/方法规避动作

## 1. 已授权实用新型（侵权风险最高，逐条深挖）

### 1.1 CN224125610U「柔性纤维压力防褥疮传感器床垫」 🔴🔴🔴 核心结构专利

- **状态**：✅ 已授权（2026-04-17），有效期至 2035-03-28
- **优先权日**：2025-03-28
- **发明人**：何海鹏 / 张景淇 / 陈安笑 / 李亚妮

**独立权利要求要点**（自上而下依次包括）：
1. 第一封装层
2. 第一数据采集层
3. 压力数值采集层
4. 第二数据采集层
5. 第二封装层
6. 电路板模块（分别电连接第一、第二数据采集层）

**从属权利要求要点（关键）**：
- 封装层 = 布料（防静电/防水/抗菌等可选）
- **第一/第二数据采集层 = 纵向/横向传输线，交叉排列，交叉位置即「压力传感点」**
- 压力数值采集层 = 多个柔性纤维压力传感器按纺织工艺制成布料形状

**我方重合特征**：
- 我方发明②「纺织级智能传感织物」＝ 上导电层 + 中压敏层 + 下导电层（正交交叉）
- 我方实用新型「养老监护床垫」直接对标
- **「上下正交导线交叉＝传感点」正是你点名的「刺绣电路结构和布局」的在先权利**

**风险判定**：
- 🟠 侵权风险 **高**：若我方床垫/织物沿用「封装层+纵向线+压力层+横向线+封装层+电路板」五层结构，字面落入独立权利要求。
- 🔴 新颖性风险 **高**：我方养老床垫实用新型的传感结构大概率被此件破坏新颖性。

**规避建议**：
1. **改布线拓扑**：不用「上下正交交叉」→ 用单层同面布线、斜向走线、锯齿走线（我方发明①的锯齿刺绣走线反而是差异化方向）。
2. **改层数/一体成型**：我方发明②的「三层一体织造成型」vs 对方「五层叠加」，强调一体织造而非分层缝纫。
3. **去电路板模块**：把采集电路集成进织物/柔性电路，避免「电路板模块」这一特征。

- **状态**：✅ 已授权（2026-03-27），有效期至 2035-03-07
- **优先权日**：2025-03-07
- **发明人**：谷震源 / 何海鹏

**独立权利要求要点**：
1. 平台本体
2. 高灵敏度传感平台（含纤维压力传感器）
3. 纤维压力传感器 = 传感点阵 + 分布压力点
4. **机械臂（安装在平台本体上端）**
5. 固定板

**⚠️ 两个关键点**：
- 独立权利要求**必须含「机械臂」**——保护的是「传感平台＋机械臂」一体整机；
- 说明书明确写「纤维压力传感器 5 是**现有技术结构**」——即威海矩侨自己承认传感点阵/分布压力点非其创新。

**我方重合特征**：无人实验室「实验台面压力阵列＋机械臂抓取」场景。

**风险判定**：
- 🟠 侵权风险 **中**：若我方做「传感平台＋机械臂」一体整机则可能落入；若**只做传感阵列/织物本体，不含机械臂**，字面不落入独立权利要求。
- 🔴 新颖性风险 **中**：我方若申请「平台＋机械臂」组合专利，新颖性不足。

**规避建议**：**绝不碰「平台＋机械臂」一体整机**；传感阵列作为独立部件销售，机械臂用第三方，由我方做接口适配。

### 2.1 CN119973997A「纺织级柔性高灵敏度坐标传感平台」（发明，与 1.2 同族）

- **规避**：同 1.2；并监控其授权文本。

### 2.2 CN120962736A「智能抓取传感系统、方法、介质及设备」 🔴🔴 方法专利

- **状态**：在审，优先权 2025-08-14
- **方法权利要求要点（4 步）**：
  1. 压力传感器采集卡爪式机械手触碰物体各点压力值 → 压力模拟信号
  2. 信号调理模块放大 → 放大压力模拟信号
  3. A/D 转换器 → 压力参数
  4. 卡爪式机械手接收压力参数，据此抓取/放下物体
  5. （附加）实时识别被夹持物异常位移/松动 → 动态调整夹持力智能补偿

- **我方重合特征**：无人实验室机械臂「压力反馈抓取＋夹持力补偿」。
- **风险判定**：🟠 侵权风险 **中高（若授权）**——方法侵权需我方完整执行全部步骤；若我方机械臂采用「压力采集→调理→A/D→动态补偿」同一链路，风险高。
- **规避建议**：
  1. 抓取策略差异化：用**力/力矩传感器**（非织物压力阵列）或视觉+力混合，避开「压力点阵→模拟信号→A/D」链路；
  2. 去掉「动态夹持力补偿」步骤，改固定夹持力或独立算法；
  3. 监控其审查进程，若被驳回则风险解除。

### 2.3 CN121447619A「机器人触觉交互系统及方法（模式识别）」 🔴🔴

- **状态**：在审，优先权 2025-10-21
- **要点**：机器人表面多维接触压力分布实时感知 → 转化为模式识别。
- **我方重合特征**：机器人柔性触觉实用新型 / 无人实验室机器人触觉。
- **风险判定**：🟠 侵权风险 **中（若授权）**；🔴 新颖性风险 **中**（我方机器人触觉实用新型的「压力分布+模式识别」表述可能撞车）。
- **规避建议**：实用新型权利要求**只落结构、不写「模式识别」功能**；产品侧用不同识别算法。

### 2.4 WO2025161600A1「姿态调整方法/系统/装置」 🟠

## 8. 两个专项问题说明（Josan 提问）

### 8.1 改间距 / 改角度交叉，能不能规避？

**结论：都不能。** 原因在于侵权判定只对「独立权利要求」的字面范围：

- CN224125610U 独立权利要求只写了六要素（封装层 + 采集层 + 压力层 + 采集层 + 封装层 + 电路板模块），**既没限定间距，也没限定「正交」**。
- 「间距 1cm / 32×32 点阵」只出现在说明书实施例里，**不是权利要求特征** → 改间距（1cm→0.5cm/2cm）不影响侵权判定。
- 「正交交叉」在**从属权利要求**里；独立权利要求只写「第一数据采集层 + 第二数据采集层」→ 你改成有角度交叉，**依然有两层采集层、依然六要素齐全，照样字面侵权**。
- **真正有效的规避 = 减少/替换独立权利要求的必要技术特征**：五层→三层一体织造（去掉某层封装层、或合并采集层）、去「电路板模块」改柔性集成、改连接关系——同时还要避免「等同侵权」（如把电路板模块换成柔性电路，若功能/手段/效果实质相同仍可能被等同咬住）。

### 8.2 正交结构在先专利已命中，是进攻武器（2026-08-14 更新）

- **已定位的具体在先证据**（详见《正交结构在先专利检索分析.md》）：
