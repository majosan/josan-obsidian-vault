> 编制：Sensing Vanguard ⚡

## 0. 检索范围与方法

- **对象**：Josan 上传的 36 件国内外专利（25 件国外 + 11 件国内 sefar 文件夹）。
- **方法**：全部 PDF 提取全文（含 OCR），按权利人聚类 → 识别主题 → 检索关键词（orthogonal / perpendicular / warp / weft / 压敏 / 交叉 / 导电纱线）→ 锁定披露"正交交叉传感点"结构的专利 → 权利要求级比对。
- **原始文档**：`projects/juqiao/patents/发明专利/`（交底书 + 36 件 PDF）。

## 2. 核心命中（按证据强度排序）

### 2.1 ⭐⭐⭐ 尧乐 CN202310070547「织物传感器制作方法」（国内黄金证据）

- **申请号**：CN202310070547；**申请日 2023.01.12**；**公开 2023.05.02**
- **权利人**：尧乐网络科技（上海）有限公司
- **发明人**：周潇 / 吕莉蕴 / 罗正
- **IPC**：G01L1/22（压阻测力）
- **用途**：汽车座椅柔性压力传感器

**独立权利要求 1 完整披露**：
1. **第一导电层**：缝制在无纺布上，多行**横向**第一导电电极（同一根导线来回布线）
2. **压敏材料层**：粘合在无纺布上，位于第一导电层上方，多行等间隔压敏材料
3. **第二导电层**：布设在压敏材料层上表面，多行**纵向**第二导电电极
4. **布线区 + 连接器**：所有导线经布线区连接连接器

**从属权利要求补充**：表面保护层（覆盖第二导电层上方）、参考压敏点（电阻补偿）、热敏电阻（温漂补偿）、铆接点（导线固定）、布基胶带包裹。

**对位矩侨 CN224125610U 的映射**：

| 矩侨 CN224125610U 独立权利要求六要素 | 尧乐 CN202310070547 对应特征 |
|------------------------------------|------------------------------|
| 第一封装层 | 无纺布基底 + 表面保护层（从属） |
| 第一数据采集层 | 第一导电层（横向电极） |
| 压力数值采集层 | 压敏材料层 |
| 第二数据采集层 | 第二导电层（纵向电极） |
| 第二封装层 | 表面保护层（从属） |
| 电路板模块 | 布线区 + 连接器 |

> **关键判断**：尧乐 2023 年这份专利**几乎完整对位**矩侨"五层结构 + 电路板模块 + 上下正交交叉"的全部必要技术特征，且申请日（2023.01.12）**早于矩侨全部 2024-2026 申请**。这是国内在先、同领域、中文、取证便宜的黄金证据。

### 2.2 ⭐⭐⭐ Sefar EP3447463A1「Drucksensor」（国外证据）

- **申请号**：EP 17187670.9；**申请日 2017-08-24**；**公开 2019-02-27**（A1）
- **权利人**：Sefar AG（瑞士 Thal/Heiden）
- **IPC**：G01L 1/18、D03D 1/00、G06F 3/041、G06F 3/047

**多层"三明治"实施例（Fig 7–8，权利要求 12/9）**：
- 上层接触层：导电纱线沿**第一方向**
- 中间：压阻纱线织物层（压敏层）
- 下层接触层：导电纱线沿**第二方向**（相对上层**旋转 90° = 正交**）
- 压力作用时，交叉点处两导电纱线之间电阻变化 → 检测压力

**单层实施例（Fig 1–6）**：经向织导电纱线 + 纬向织压阻纱线（或互换），交叉点即传感点。

**压阻纱线结构**：芯纱（金属/导电聚合物，单丝或绞合 Litze）+ 压阻材料包覆层（聚合物 + 金属离子/碳粒子）。

### 2.3 ⭐ US10386224（Studio 1 Labs，多伦多）

- 授权号 US 10,386,224 B2，**授权 2019-08-20**，PCT 申请 2017-10-24（WO2018/076106）
- 主题：柔性导电装置与压力检测系统
- 原理：两导电面接触面积随压力增大 → 电导增大（**接触面积型**，非正交纱线矩阵）
- **相关性中等**：是柔性压力传感，但传感机制与矩侨"正交压阻纱线交叉"不同，作为补充背景证据。

## 3. 法律结论（回答"矩侨五层能形成专利吗 / 能反驳吗"）

### 3.1 先纠正一个关键认知

- 矩侨 CN224125610U 是**已授权的实用新型**（2026-04-17 授权），**不是"形成不了专利"**。
- 但中国实用新型**只做形式审查、不做实质审查**（新颖性/创造性不审就发证），所以其"五层结构"很可能重复了已公开技术，**有效性存疑，可以被无效**。

### 3.2 两条反驳路径

| 路径 | 性质 | 证据 | 作用 |
|------|------|------|------|
| **无效宣告** | 主动进攻 | 尧乐 2023 + Sefar 2019 + DE 60111510 T2 组合 | 主张"五层 + 正交交叉"缺新颖性/创造性，打掉专利 |
| **现有技术抗辩** | 防守 | 同上 | 侵权诉讼中主张我方实施的是现有技术，不构成侵权 |

### 3.3 证据覆盖范围

- **对从属权利要求「上下正交交叉 = 传感点」**：尧乐 2023 + Sefar 2019 均完整、明确、同领域公开，可稳打。
- **对独立权利要求「五层 + 电路板模块」**：尧乐 2023 的"第一导电层 + 压敏层 + 第二导电层 + 布线区 + 连接器 + 保护层"几乎完整对位；DE 60111510 T2 补"两层导电 + 中间压敏"本体。仅"电路板模块"一字之差需比对——尧乐的"布线区 + 连接器"实质上就是采集连接模块。

> **结论**：矩侨的"五层结构"是**纸老虎**——形式上授权，但核心创新性很可能被尧乐 2023 这份国内专利直接破坏。我方的风险比早期评估的低。

3. **我方真正的护城河（务必咬死）**：

   - **锯齿走线**（非正交直线交叉）
