## 一、结构与面料

### 1.1 尺寸

| 项 | 规格 | 说明 | 状态 |
|---|---|---|---|
| 整垫尺寸（长 × 宽） | **1700 × 900 mm** | 适配单人床；四角 **R30** 圆角 | ✅ |
| 整垫厚度 | **≤ 8 mm（目标 6 ± 2 mm）** | 平铺于床垫上、床单下；卷曲半径 ≥ 50 mm | ✅ |
| 有效传感区 | **≈ 1550 × 775 mm** | 四周留 **≥ 60 mm** 封边/走线带 | ✅ |
| 信号引出端 | **床头端（头端）** | 见 §三 | ✅ |
| 重量 | **≤ 2.5 kg**（目标 ≤ 2.0 kg） | 单人可铺床 | ⚠️ |

### 1.2 阵列与传感点

| 项 | 规格 | 状态 |
|---|---|---|
| 阵列规模 | **32 × 32 = 1024 点** 🔒 | 🔒 |
| 点间距（长向 / 宽向） | **50 mm / 25 mm** | ✅ |
| 单传感点尺寸 | **4 × 4 mm**（镀银纱 × 压敏纱正交） | ✅ |
| 走线 | 刺绣锯齿形走线；IO 汇到**头端**引出区 | ✅ |
| 最小可检测压力 | **≥ 20 g / 点**（优先一致性与耐久） | ✅ |
| 串扰 | 相邻点串扰 ≤ 邻点信号 10% | ✅ |

### 1.3 面料与封装

**四层结构（自上而下）：**

| 层 | 材料建议 | 作用 | 关键要求 | 状态 |
|---|---|---|---|---|
| **① 表层（亲肤，可拆洗）** | **针织纯棉 / 竹纤维 / 莫代尔**（160–220 g/㎡） | 舒适透气、亲肤 | 可拆洗外套，机洗 ≤ 40℃、≥ 30 次不失效；**禁涤纶** | ✅ |
| **② 传感核心层** | 镀银纱电极 + 压敏纱三层织物 | 压力感知本体 | 仅表面擦拭；整体**三防**（防潮/防霉/防污） | ✅ |
| **②b 核心保护封装（V0.2 新增）** | **超薄无纺布（≤ 0.2 mm，医用级亲肤）** 或热熔网膜复合 | 保护核心层**表面纱线**、防磨防勾丝 | 复合适度：对灵敏度衰减 **≤ 10%**；不起皱、不形成预压力 | ⚠️ |
| **③ 底层（防滑/防水）** | **TPU 防水膜（≤ 0.15 mm）+ 点塑防滑颗粒** | 防滑、阻断液体上行 | 膜完整不破 | ✅ |
| 四边封合 | 高频热合 / 包边缝合 + 防水胶条 | 强度 + 防水 | 接缝不渗液 | ✅ |

> **V0.2 说明（回应 Josan）**：核心层外**加一层极薄无纺布**做机械保护是对的 —— 保护表面纱线耐摩擦。**关键约束**：必须"薄 + 软 + 透气"，否则会衰减灵敏度；定样前需实测封装前后灵敏度差 ≤ 10%。

**防静电（ESD）：** 表层棉/竹（低静电）；传感层银镀纱引出区做**统一参考地**；采集板电极接口加 **TVS（±8kV）**；系统 **5V SELV 安全低压** 🔒。（同 v0.1）

### 1.4 舒适 / 安全 / 阻燃（回应 Josan 第 7 问）

> **问：阻燃是对采集板硬件还是织物材料有要求？**
> **答：两者都有，但重点在织物材料。**
> - **织物（重点）**：面积大、贴身、可燃 —— **机构/养老院/医院招标常要求阻燃面料**（如 GB/T 17591、B1 级）；**家用一般不作强制**。
> - **采集板/外壳**：5V 低压小功率、有独立外壳，风险低；可选 **PCB 阻燃（UL94 V-0）+ 外壳 V-0**，通常够用，不是主矛盾。
> - **建议**：先做**家用版（织物不强制阻燃）**；若目标客户是**机构**，再把织物升级为阻燃面料（成本上升）。

| 项 | 要求 | 状态 |
|---|---|---|
| 亲肤安全 | 面料参照 OEKO-TEX Standard 100（或等同） | ⚠️ |
| **织物阻燃** | **家用不强制；机构招标再加（GB/T 17591 / B1）** | ⚠️ 待定客户 |
| 采集板/外壳阻燃 | 可选 UL94 V-0 | ✅ |
| 整垫防水 | IPX4（防溅，非浸水） | ✅ |
| 承重/耐久 | 静载 ≥ 120 kg；疲劳 ≥ 5 万次 | ⚠️ |

## 二、硬件规格

### 2.1 供电与功耗

| 项 | 规格 | 状态 |
|---|---|---|
| 供电 | **DC 5V / Type-C（通用）**；适配器 **5V/1A**，**线长 2 m** | ✅ |
| 是否需适配器 | **需要**（Demo/试点有线常供），随箱 1 个 | ✅ |
| 板载电压 | 5V → **3.3V**（LDO/Buck）；WiFi TX 峰值 ≤ 500 mA | ✅ |
| 功耗 | 待机 < 0.3 W；典型 < 0.5 W；峰值 < 1.5 W | ✅ |
| 电池版（P2） | 3.7V 可充，续航 ≥ 30 天 | ⚠️ |

### 2.2 通信模组（回应 Josan 第 1 问）

> **问：ESP32 模组有点大、占地方，能不能用纯 WiFi 模组？**
> **答：可以纯 WiFi，但不建议——会失去 BLE 配网。**
> - **"占地方"通常指开发板**；量产用的 **MINI 模组其实很小**：
>   - **ESP32-C3-MINI-1** ≈ **13.2 × 16.6 mm**（WiFi + BLE 5）
>   - **ESP32-C2-MINI-1** ≈ **≈11 × 14 mm**（WiFi + BLE 5，**更小**）
> - **纯 WiFi 模组（无 BLE）**：配网只能走 **SoftAP**（用户要切到设备热点输密码），**体验明显变差**；省下的尺寸也就几毫米。
> - **结论**：推荐 **ESP32-C2-MINI-1（最小 + 带 BLE）**；如坚持纯 WiFi，则配网降级为 SoftAP-only（协议已支持，需在固件需求里写明）。

| 项 | 规格 | 状态 |
|---|---|---|
| 频段 | **2.4 GHz**（802.11 b/g/n），不支持 5G | 🔒 |
| 蓝牙 | **BLE 5.0**（配网首选）/ SoftAP 兜底 | ✅ |
| 协议 | MQTT over TLS 1.2+ | 🔒 |
| **模组建议** | **ESP32-C2-MINI-1（首选，最小）** / ESP32-C3-MINI-1（备选）；均为 WiFi+BLE 一体 | ⚠️ 待选型 |
| 天线 | 板载/外置，**净空区禁金属** | ✅ |

### 2.3 设备端功能（功能需求 A）

采集与预处理 · 边缘事件判定 · 配网 · 联网通信（断网 ≥24h 缓存）· 设备管理与 OTA · 安全（一机一密/签名）。同 v0.1，不赘述。

### 2.4 小程序

- **物业端（值班，核心）**：多床看板、告警列表与详情、接单/上门处理、照护提醒、交接班、通知设置
- **家属端**：绑定+知情同意、实时状态、告警列表与响应、周报、我的（含**短信手机号**）

### 2.5 后台管理（Web）

项目后台（多床看板/告警流转/报表/资产层级管理/批量导入）· 设备管理 · 三层存储 · 规则告警 · 通知推送（小程序+订阅消息+**短信**）· 报表 · RBAC/多租户 · 运维后台 · **计费订阅（采购/租赁）**。同 v0.1。

## 三、采集板（硬件板卡）规格

### 3.1 位置（V0.2 改：床头端，回应 Josan 第 5 问）

> **Josan 约束**：**不接受床尾** —— 租户/校区用户**床尾插线会绊脚**，且**插座通常不在床尾**。

| 项 | v0.2 建议 | 理由 | 状态 |
|---|---|---|---|
| **首选：床头端（头端）侧边外挂采集盒** | 采集盒置于**床头一端、床体侧边**（床架/床头柜侧），**不进入躺卧受力投影区** | ① **电源插座普遍在床头**；② 走线不经过通道、不绊脚；③ 离开躯干/头部受力区；④ 便于取电与维护 | ✅ |
| 采集盒尺寸 | **≈ 120 × 80 × 25 mm** | 容纳板卡 + Type-C + 按键 + 天线净空 | ✅ |
| 引出与走线 | 传感阵列 IO 汇到**头端**，经 **FPC / 扁平排线沿垫体侧边**走到床头采集盒 | 不横穿躺卧面；**应变释放**防拉扯 | ✅ |
| 固定方式 | **魔术贴 / 卡扣** 固定于床架或床侧，可拆卸 | 免打孔、便于检修 | ✅ |
| 备选 | 床侧**长边靠头端中部**外挂 | 若床头无固定位 | ⚠️ |
| 明确避免 | 床尾端、头枕正下方（受压投影区内） | — | ✅ |

### 3.2 按键与结构预留（V0.2：去掉物理电源开关）

| 项 | 建议 | 状态 |
|---|---|---|
| 多功能键（1 个） | **短按**=状态查询；**长按 3s**=BLE 配网；**长按 10s**=恢复出厂/复位 | ✅ |
| 复位孔 | **隐藏式**（针孔） | ✅ |
| **物理电源开关** | **不要**（V0.2 按 Josan 确认） | ✅ |
| 指示灯 | 电源 / 联网 / 配网 / 告警（多色 LED + 导光柱） | ✅ |
| 结构预留 | 按键开孔+按键帽、导光柱孔、隐藏复位孔、Type-C 开孔、**天线净空区** | ✅ |
| 固定 | 魔术贴 / 卡扣，可拆卸 | ✅ |

### 3.3 防水与防护（V0.2：确认 IP54/IPX4 足够）

| 项 | 建议 | 状态 |
|---|---|---|
| PCB 防水 | **三防漆**（防潮/防霉） | ✅ |
| 采集盒 | **IP54**（防尘防溅，非浸水） | ✅ |
| Type-C 口 | 防水型 或 **防尘防水塞** | ✅ |
| 织物接缝 | 防水处理（胶条/热合） | ✅ |
| 线缆 | FPC + **应变释放** | ✅ |
| ESD | 电极接口 **TVS ±8kV** | ✅ |
| 过流/温升 | 保险丝/限流；温升 ≤ 20K | ⚠️ |

### 3.4 板卡要点

MCU 与模组同芯（ESP32-C2/C3 一体）或分离 · 阵列 32 行+32 列接口 · ADC 12-bit 🔒 · Flash ≥ 4MB（断网队列）· 接口：Type-C / FPC / 按键 / LED。
