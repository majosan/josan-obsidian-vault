# 织序智慧感知守护平台 · 云平台 UI 设计大纲（范围）

> **性质**：这是 **UI 大纲 / 范围定义**，只定**基调、布局逻辑、组件范围与规则**；**具体视觉样式由 dhs 实现**。
> **参考**：Josan 提供的参考图（`智慧感知守护平台-材料/eb7a9d0ae59222505d3497c60c838631.jpg`）——极简清爽、卡片式、有层次。
> **目标**：**简洁清爽 · 银白主调 · 卡片式（不用胶囊） · 大卡 + 小卡的主次层次**。

---

## 1. 设计基调（Tone）

- **极简、清爽、留白**：少边框、多留白，靠间距与层次区分，不靠线条。
- **配色**：**银 / 白 / 浅灰为主**（银白科技感），**单一品牌色**做点缀；强调色克制。
- **卡片化**：所有内容块 = 卡片（圆角、轻阴影、悬浮）。**状态不用"胶囊 pill"，用卡片/小卡/色块表达**。
- **层次**：**大卡（主视角） + 小卡（辅助）** 混排，一屏能一眼抓住重点。
- **专业可信**：面向物业/家属/投资人，稳重不花哨。

> 📌 明确要求：**不用胶囊（pill）** 作状态标签 —— 改用**小卡片 / 色块 / 角标**。

---

## 2. 布局骨架（Layout）

```
┌──────┬───────────────────────────────────────────────┐
│      │  顶栏：面包屑 · 搜索 · 通知 · 用户              │
│ 侧栏 ├───────────────────────────────────────────────┤
│(深色)│  ┌─────────────── 主视角大卡 ───────────────┐  │
│      │  │ （KPI 总览 / 地图 / 核心图）              │  │
│ 图标 │  └───────────────────────────────────────────┘  │
│ +文字│  ┌── 小卡 ──┐ ┌── 小卡 ──┐ ┌── 小卡 ──┐        │
│      │  │          │ │          │ │          │        │
│      │  └──────────┘ └──────────┘ └──────────┘        │
└──────┴───────────────────────────────────────────────┘
```

- **侧栏**：图标 + 文字导航；选中态有明确反馈；深色或浅色皆可（建议**深色**，衬银白主区）。
- **顶栏**：面包屑 / 全局搜索 / 通知 / 用户。
- **内容区**：**银白背景 + 卡片网格**；每页遵循「**1 个主视角大卡 + 若干小卡**」的节奏。
- **响应式**：以桌面宽屏为主；关键页兼顾平板；正文支持大字。

---

## 3. 设计变量（范围，具体值 dhs 定）

| 维度 | 范围/取向 |
|---|---|
| 主色 | 银白/灰为主；**一个品牌点缀色**（冷暖各选一） |
| 语义色 | 正常=绿 · 提示=L1（低饱和）· 警告=L2（琥珀）· 紧急=L3（红）· 离线=灰 |
| 圆角 | 卡片大圆角 · 控件中圆角（**比胶囊更"方"**） |
| 阴影 | 极轻、扩散型（靠阴影分层，不靠边框） |
| 字体 | 系统无衬线；标题加粗、正文常规、辅助灰 |
| 间距 | 大留白，8pt 栅格 |
| 图标 | 线性图标（统一一套） |

---

## 4. 组件范围（只列范围，不细化样式）

1. **侧栏导航**（图标 + 文字，分组、选中态）
2. **顶栏**（面包屑 / 搜索 / 通知 / 用户）
3. **主视角大卡**（一屏视觉焦点：KPI 总览 / 地图 / 核心图）
4. **KPI 小卡**（大数字 + 小标签 + 趋势指示 + 迷你图）
5. **内容卡**（标题 + 描述 + 内容/表单）
6. **状态标记**（**卡片/色块/角标式，非胶囊**；含 L1/L2/L3 与在线/离线）
7. **数据表格**（你重点强调 ⭐）：无竖线、行高舒适、表头弱化、hover 反馈、状态列用色块、操作图标按钮、分页、可展开行、空状态
8. **图表**（ECharts：折线 / 柱 / 环形 / 面积；统一色板）
9. **压力热力图卡**（2D 热力 + 人体轮廓）
10. **地图卡**（项目→楼栋→楼层分布；先示意后接地图）
11. **设备/床位卡**（房号 + 守护对象 + 状态 + 迷你热力图 + 快捷操作）
12. **通用**：空状态 / 加载骨架 / Toast / 确认弹窗 / 表单控件

---

## 5. 状态与告警视觉规则

- **分级必须一眼可辨**：L1 轻（低饱和）< L2（琥珀）< L3（红，最醒目）——但**克制、不刺眼**。
- **在线/离线/在床/离床**：用**色块 + 文字**（非胶囊）。
- **数据异常**：仅高亮关键项，避免满屏红。

---

## 6. 页面模板（5 类）

| 模板 | 用于 | 结构 |
|---|---|---|
| **总览页** | 数据看板 | 大卡（主图/地图/KPI）+ 小卡组 |
| **列表页** | 设备/告警/守护对象/售后 | 筛选区 + 主表格卡 + 统计小卡 |
| **详情页** | 设备详情/对象详情 | 左：主视角大卡（热力图/状态）；右：信息小卡组 |
| **表单页** | 新增/编辑/规则配置 | 分区卡片 + 步骤/说明 |
| **报表页** | 数据分析 | 筛选卡 + 图表卡组 + 明细表卡 |

## 7. 交付要求（给 dhs）

- 先出 **1 张"设计基调样例页"**（如数据看板）定调，Josan 确认后再铺开全部页面。
- 统一**组件库**（表/卡/图/状态块），全程复用，禁止每页各写各的。
- 保证**一致性**（间距/字号/圆角/配色 → 用统一 token）。
- 页面**首屏突出重点**（主视角大卡），符合"有主次、有层次"。
- 兼容**大字 / 无障碍**（老人/家属场景）。

---

## 8. 反面清单（不要出现）

- ❌ 胶囊状状态标签
- ❌ 重边框、密集线条、表格竖线
- ❌ 多彩花哨、霓虹色、过度渐变
- ❌ 每页风格不一、组件各写各的
- ❌ 一屏塞满、无主次
