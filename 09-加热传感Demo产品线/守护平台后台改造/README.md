## 一句话口径

- **平台名**：织序智慧感知守护平台
- **被监测对象统一称谓**：**守护对象**（`subject`，`subjectType = 老人 / 宠物`）；拥有/付费账号 = **用户/业主**；家属亲友 = **关系人**
- **位置**：仅做**首次台账登记**（项目→小区→楼栋→单元→楼层→房号→设备），非实时定位；后续更换由用户在小程序换绑，系统只更新记录
- **物业**：**轻集成**（公告/资讯 + 组织 + 标签；**不做工单派发**，不给物业加活）
- **售后**：归**我方**（物业仅可能转达）
- **文案红线**：用「**预警 / 风险 / 提醒**」，**禁用**「报警 / 监护 / 诊断」；心率、体重一律「**估计 · 非医疗**」
