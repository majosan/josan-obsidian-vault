# 织序智慧感知守护平台 · 云平台（Web 后台）功能结构（文字整理稿）

> **用途**：供 Josan 更新 PDF 大纲 / 功能图使用。层级 = 模块 → 子模块 → 功能点。
> **口径**：端 = Web 后台；小程序下一步；不含商业模式。文案统一用「预警 / 风险 / 提醒」。

---

## 一、数据看板（驾驶舱）

### 1. 运营态势（默认视图）
- 核心 KPI 卡：在线设备 · **设备数**（原"在床数"）· 告警中 · 待处理 · 在线率 · 平均响应时长
- 实时告警概览（按 **L1 提示 / L2 警告 / L3 紧急** 分级）
- 故障 / 离线设备
- Top 风险守护对象（重点看护）
- 设备运行状态

### 2. 经营增长（可切换 / 可折叠视图）
- 设备数量与增长趋势（累计 / 本月新增）
- 覆盖：项目数 · 小区数 · 楼栋覆盖 · **覆盖楼层比例**
- 服务人数（守护对象数）
- 付费床位 / 续约（预留）
- 设备分布地图（见 3）

### 3. 设备分布地图
- 层级：**项目 → 小区 → 楼栋 → 单元 → 楼层 → 房号 → 床位/设备**
- 展示：分布热力 / 覆盖楼层比例 / 定位气泡

### 4. 后续服务场景包（入口 / 标签）

---

## 二、告警中心

### 1. 实时告警
- 分级：L1 提示 · L2 警告 · L3 紧急
- 类型：坠床风险、离床超时未回、久卧不动、压力异常、体位异常、设备离线、低电量

### 2. 告警处置
- 接单 → 处理 → 归档；处理人 / 备注 / 照片
- 升级链（超时自动升级）

### 3. 通知与响应
- 渠道：小程序订阅消息 · 短信 ·（语音外呼 · 可选）· Webhook
- 响应策略：**家属优先**；**家属不在 → 再联系物业上门服务**

### 4. 免打扰与静默
- 免打扰时段；静默期（可配置、有审计、到期自动恢复）

---

## 三、设备管理

### 1. 设备台账
- 列表：设备 ID · 型号 · 类别 · 固件版本 · 在线状态 · 绑定守护对象 · **归属项目-小区-单元-房号** · 最近上报
- 筛选 / 导出 / 批量导入

### 2. 设备类别
- 压力床垫 / 宠物垫（可扩展）

### 3. 设备型号
- 型号参数、规格、固件版本

### 4. 设备绑定 / 解绑
- 绑定守护对象 + 归属房号；换绑（过户）与**变更记录**（**用户主动上报 或 小程序更改 → 后台更新**）

### 5. 设备详情
- 实时状态、**压力分布状态**、压力热力图、实时压力数据

### 6. 预警设置（自定义逻辑）
- 规则：**生效时段（开始时间 / 结束时间）**、离床超时未回时长（如 30 分钟）、久卧时长、翻身时长、坠床阈值、离线超时
- 三级配置：全局 / 项目 / 床位

### 7. 设备功能开关（按类别）
**压力传感垫**
- 体重变化趋势（估算 · 非医疗）
- 卧床时长统计（当日卧床总时长 / 单次卧床总时长）
- 体位变化 / 姿态检测
- 体动状态（多/少、稳不稳）
- 在床 / 离床状态
- 实时告警：坠床风险、久卧不动、离床通知、压力异常、体位异常
- 压力热力图 / 守护记录
- 呼吸趋势（非医疗）
- 睡眠报告
- **心率（估计 · 非医疗）**——不准则隐藏，**保留位置**

**宠物垫**
- 在垫 / 离垫检测
- 压力热力图
- 呼吸趋势
- **活跃度 / 安静度**（原"情绪"改为活跃度）
- （心率估计 · 可选）

### 8. OTA 与远程诊断

## 四、守护对象管理

### 1. 守护对象档案
- 名称 · 类型（老人 / 宠物）· 年龄/品种 · 性别 · 备注 · 标签 · 知情同意状态

### 2. 类别与标签
- 人群标签 / 宠物标签（分组）

### 3. 绑定关系
- 守护对象 ↔ 设备 / 床位

### 4. 关系人
- 家属 / 亲友 / 紧急联系人（联系方式、通知顺位）

### 5. 归属
- 项目 → 小区 → 楼栋 → 单元 → 楼层 → 房号

### 6. 服务 / 场景包
- 已购服务 / 场景包（预留）

## 五、物业管理（轻量）

### 1. 小区 / 项目组织
- 项目 → 小区 → 楼栋 → 单元 → 楼层 → 房号（增删改查）

### 2. 公告 / 资讯
- 发布 / 编辑 / 删除 / 推送（物业内部通知、资讯新闻）

### 3. 物业人群标签
- 标签 / 分组（用于分层通知）

### 4. 物业服务 / 安全报告
- 系统**自动生成**月度"守护报告"（覆盖多少户、告警、处置率）——零额外工作

> ✂️ **去掉**：工单派发。物业**不登录、不操作**，只在微信 / 短信收告警。
