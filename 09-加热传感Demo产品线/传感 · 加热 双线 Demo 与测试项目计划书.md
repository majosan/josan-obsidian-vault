## 一、目的：为什么要做这些 demo 和测试数据

### 1.1 背景与问题
主路已定：
**第一目标 = 回笼现金止血**
路径 = **以"技术资产包 + 战略合作"对外出售**（不做对赌性质融资）

但现有资产"**有图纸、无数据、演示不完整**"，买家一看就显单薄：**看不出我们做什么、解决什么、未来有什么**。

**做这些 demo 和测试，就是用最小成本补上这个缺口**：证明有效 → 支撑定价 → 过尽调 → 能对外展示。

## 二、行业观察：展会一线 + 海外对标

### 2.1 展会整体：刚性是主场，柔性仍是少数派

> 2026-09-17 · 中国（上海）国际传感器技术与应用展览会 参展后记录：

- 参展主体**绝大多数是头部刚性传感器厂商**，集中在**气体 / 液体 / 压力**等成熟、已批量应用的品类；
- **做柔性传感参展的仅约 5 家** → 柔性仍处在"少数派"位置。

### 2.2 同行一线实况（我们的可比对象）

|     厂商     | 展位规模 |                 展出内容                 |       技术路线        |        现场观感         |
| :--------: | :--: | :----------------------------------: | :---------------: | :-----------------: |
|  **矩侨工业**  |  最大  | 自适应座椅、鞋垫、手套、压力垫/床垫；**新增宠物监测（带后台软件）** |   全柔性织物（还是之前技术）   |   产品线最全、最接近"完整方案"   |
|  **尧乐科技**  |  小   |     汽车坐垫、织物手套、离床传感器、人体姿态识别模块      |       全柔性织物       | 器件为主、手套演示效果差，但是完整性高 |
|  **汉威科技**  |  大   |            数据手套、传感衣服、压力垫             | 薄膜 + **织物涂敷导电银浆** |     大厂，柔性仅为其一条线     |
| **深圳模量科技** |  小   |            1 只手套 + 1 块织物             |     织物 / 视触觉      |      **演示效果差**      |
| **湖北祥源新材** |  小   |          压阻 + 压电两类柔性薄膜<br>           |      材料 / 薄膜      |       柔性玩家偏材料       |

### 2.3 三点判断

- **全织物路线，认真在做的就2家**（矩侨、尧乐）→ 我们的差异化空间机会仍在；
-  **现场演示普遍一般**，部分"织物手套"的采集效果不好 → 感觉技术及产品完整性不是那么高（也有可能展会未必是各家最好的状态）；
-  **"方案化、可完整展示"是其中一种方案趋势**（矩侨从器件 → 自适应座椅 / 床垫 / 宠物 + 后台软件）→ **印证我们需要选择一个方向做闭环完整性：不做散件，做一个能从头演示到尾的完整 DEMO 产品**（垫 → 后台 → 小程序）。

*总结：传感赛道很大，但**柔性传感这条细分线还没真正卷起来**；我们有机会做出**针对行业场景的较完整产品**。*

### 3.1 总体范围（工作包+FA结构一起整理评估）

| :---: | :-----: | :-----------------------------: | :--------: |

| **B** |  测试与数据  |       执行 T1–T10，产出《测试报告》        |     P2     |
| **C** | FTO 分析  |      竞品专利检索 + 侵权风险 + 差异化建议      |     P1     |
| **D** | 场景 demo |   传感垫 → PC 网关 → 云 → 后台 → 小程序    |     P1     |

| **F** |   加热线   | CNT 纱线加热产品（眼罩等）：资产化 + 测试 + demo | **P2（后置）** |

### 3.2 为什么纳入加热线

- **技术差异化**：加热我们用的是 **CNT（碳纳米管）纱线**，**市面上这种方案很少** → 目前工艺不成熟待测试验证
-  **盘活经编机的价值**：经编机的一个定位就是**编织加热布**——加热线产品一旦做成，就给经编机一个**未来价值锚点**，<font color="#00b050">把这块历史投入**衔接**到可见的产品线上</font>。
-  **投资者看得懂**：加热**市场大且成熟**（服饰/家纺/汽车/医疗热敷都有现成需求），**投资人容易理解**； 对外增加"一条讲故事的线。

### 3.3 明确不做（划边界，防摊大饼）

- ❌ 不做新研发、不做新工艺、不做新材料
- ❌ 不做呼吸/心率/姿态等需要新算法的功能--看具体情况
- ❌ 不做过多传感场景（针对一两个场景锚点做完整）


### 3.4 场景落地（我的新想法）：自有物业试点 × 房产加持 ⭐ 作为**灯塔试点 / 样板工程**

> A–D 解决的是"**把资产做出来、证明出来**"；但买家/投资人最后一定会追问一句——**"真有人用吗？真的能解决实际场景问题吗？有市场吗？"**。要回答这句，最稀缺的是**真实场景 + 真实数据**。

**我们是否可以结合资源：房产 + 物业**

- **楼盘 + 物业公司**→ **无需外求客户，即有现成部署场景**；
- 也踩中**房企转型**的天然方向：**社区养老 / 适老化**——同时是**物业增值服务**与**楼盘差异化卖点**；
- **结合上面提到的国外养老看护场景**。


**同时也能解决一些根本性问题：**

|       原来的困境        |           自有物业试点            |
| :----------------: | :-------------------------: |
|      没有市场需求方       |       **现成部署场景**，不用求人       |
|      拿不到真实数据       | 实验室数据 << **真实老人 24 小时使用数据** |
|       没有落地案例       |    **真实楼盘 + 真实住户 = 硬样板**    |
| 卖技术没底气（"只是个 demo"） |  变成"**已在 X 个楼盘、Y 户真实运行**"   |

**⚠️ 但必须分清中间还有模式待跑通环节**

|        ✅ 能证明         |          ❌ 不能证明          |
| :------------------: | :----------------------: |
| 产品**能用、有用**（真实场景跑得通） | 市场**有人愿意买**（内部部署 ≠ 市场购买） |
|    有真实运营数据与场景 SOP    |        有可复制的商业模式         |
|     有落地案例（对外极加分）     |           有营收            |
> **试点规模建议**：以 1 个项目 / 几户起步；前期先做一轮**付费意愿与功能需求**的市场调研。

## 六、投入产出分析（这钱为什么该花）

### 6.1 核心逻辑

> **不再是简单的"花钱做研发"，是"投入可控资金把资产从'卖不掉'变成'能卖'、从'没底价'变成'有依据'"。**

## 附录 B：术语表（供非技术同事阅读）

| 术语 | 含义 |
|---|---|
| **柔性压力传感阵列** | 一张"电子皮肤"，由许多压力感应点组成，能测出受力的大小和分布 |
| **全织物路线** | 传感器整个用纺织品工艺做出来（vs 用塑料薄膜/印刷电路做） |
| **单层一体织** | 一层布织出来即含传感器（vs 多层贴合），是本项目核心差异化 |
| **FTO**（Freedom to Operate） | "自由实施"分析——查清产品会不会侵犯别人的专利，是尽调必问项 |
| **尽调**（DD） | 买方在成交前对技术、财务、法律做的全面核查 |
| **技术资产包** | 打包在一起可转移的技术资产：图纸、硬件、软件、数据、专利 |
| **对赌** | 投资方与公司约定业绩目标的条款（本项目明确不接受） |
| **POC / Demo** | 原理验证样机，用于证明技术可行性 |
