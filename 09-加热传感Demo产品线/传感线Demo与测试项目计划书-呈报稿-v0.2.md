> **副标题**：把已有的技术资产，变成"**可尽调、可演示、可交易**"的资产
> **呈报对象**：老板 ｜ **编制**：Josan / 传感前锋 ｜ **日期**：2026-09-16

|---|---|

> **一句话**：这不是"再投入研发"，是**"把已经花掉的钱，变成能卖回钱的东西"**。

## 一、目的：为什么要做这些 demo 和测试数据

### 1.1 背景（主路已定）
老板已明确：当前**第一目标 = 回笼现金止血**。对应路径 = **以"技术资产包 + 战略合作"对外出售**（不卖公司股权、不接受对赌）。

### 1.2 现在的问题：我们有资产，但**"卖相"不够**

| 现状 | 买家的反应 |
|---|---|
| 有设计图、有硬件、有软件 | 认，但会问"能跑成什么样？" |
| **没有测试数据** | ❌ "怎么证明它有效？" → 无法定价 |
| 演示不完整、只有一块 demo 垫 | ❌ "这只是个 demo，不是方案" |
| 结构是否借鉴竞品**未做 FTO** | ❌ 尽调一问就卡，**不能对外展示** |

**结论**：资产**存在**，但**不"可交易"**——缺的是"证明"和"包装"，不是"发明"。

### 1.3 demo 和测试数据的四个作用

1. **证明技术是真的**：实物 + 数据，堵住"PPT 公司"的怀疑
2. **支撑报价**：有量化指标，才有估值依据；没数据只能按"团队+意愿"贱卖
3. **通过尽调**：买家尽调最怕的三样——**权属、FTO、量化指标**——一次补掉
4. **给 FA/产业方一个钩子**：让他们有东西可展示、可转发、可内部推动

### 1.4 这笔钱的性质（**与经编机投入的本质区别**）

| | 经编机投入 | 本项目投入 |
|---|---|---|
| 性质 | 研发探索 | **资产包装 / 尽调准备** |
| 方向 | 不确定 | **明确**（补三个已知缺口） |
| 验收 | 模糊（"跑通"） | **明确**（有报告、能演示） |
| 结果 | 至今未成果 | **做完就能拿去卖** |

> **对外表述建议**：这叫"**把资产从'纸面'变成'可交易'的费用**"，金额可控、目标明确、有验收标准。

## 二、市场机会与竞争格局（为什么是现在做）

### 2.1 赛道在爆发

| 数据 | 数值 |
|---|---|
| 全球电子皮肤市场 | **2024 ≈ $63 亿 → 2034 > $300 亿**（17%+ CAGR） |
| 人形机器人电子皮肤 | **2030 ≈ ¥90.5 亿**（64.3% CAGR），约占机器人价值量 **10%** |
| 康养场景 | 老龄化 + 压疮/离床监测**刚需**；欧洲 Texible **Wisbi** 智能床垫插层已验证同类产品存在（需求被证明） |

### 2.2 竞争格局：我们在哪一格

- 全行业 **30+ 家**在做电子皮肤，主流路线是**薄膜 / 印刷 / 涂覆**（福莱新材、华威科、晶智感等）
- 走**"全织物"路线的只有约 3 家**（**我们 + 尧乐 + 矩侨**）→ 差异化空间尚未被充分竞争
- 已量产/已定点的：华威科（灵巧手电子皮肤下线 2000 只）、晶智感（月产 5000 只手）、福莱新材（中试量产）、尧乐（理想/岚图定点）
- **我们的位置**：早期，但卡在"**被验证过、且尚未被充分竞争**"的路线上

### 2.3 时间窗口：为什么必须现在做

- 头部公司已从"资本驱动"切换到"**市场驱动**"（有量产、有订单）
- **窗口期判断：1–2 年**
- 含义很直接：**现在拿着资产包去谈，还能讲"卡位"；再晚，买方只会问"你和已量产的差多少"**

### 2.4 对老板的意义

> 这不是"赌未来"，是**在窗口关闭之前，把一条已验证的技术路线，变成可交易的资产**。

## 三、做什么：范围与优先级

### 3.1 总体范围（五个工作包）

| 包 | 工作包 | 内容 | 现金成本 |
|---|---|---|---|
| **A** | 资产文档化 | 设计/硬件/软件/专利清单 → 整理成可尽调资产包 | 0（内部） |
| **B** | 测试与数据 | 执行 T1–T10，产出《测试报告》 | 小 |
| **C** | FTO 分析 | 竞品专利检索 + 侵权风险 + 差异化建议 | 中 |
| **D** | 场景 demo | 传感垫 → PC 网关 → 云 → 后台 → 小程序 | 小（内部） |
| **E** | 加热眼罩 | 仅保留设计文档；**本阶段不做** | 0 |

### 3.2 优先级与理由

| 优先级 | 工作包 | 理由 |
|---|---|---|
| **P0** | A 资产文档化 | **不花钱**，且是所有对外材料的地基 |
| **P0** | B 测试 | **补唯一缺口**；没有它前面资产都打折 |
| **P0** | C FTO | **对外展示的前提**（未完成不得展示） |
| **P1** | D 场景 demo | 让买家"看得见"，支撑演示与讲故事 |
| **P2** | E 加热眼罩 | 资源集中，暂不并行 |

### 3.3 明确不做（划边界，防摊大饼）

- ❌ 不做新研发、不做新工艺、不做新材料
- ❌ 不做呼吸/心率/姿态等需要新算法的功能
- ❌ 不做第二个场景（只做康养床垫一个锚点）
- ❌ 不做加热线产品化
- ❌ 不做经编机任何投入

## 六、投入产出分析（这钱为什么该花）

### 6.1 核心逻辑

> **不是"花钱做研发"，是"花钱把资产从'卖不掉'变成'能卖'、从'没底价'变成'有依据'"。**

### 6.2 三种情形的对比

| 情形 | 资产状态 | 买家的看法 | 可能结果 |
|---|---|---|---|
| **不投入** | 有图纸、无数据、演示不完整 | "这只是个想法" | 谈不成，或按"团队+意愿"极低价 |
| **投入后** | 完整资产包 + 测试报告 + FTO + 可演示 | "有真东西、能尽调" | **具备报价依据，可进入实质谈判** |

### 6.3 同类交易的锚点（证明赛道有真金白银）

| 公司 | 交易 | 说明 |
|---|---|---|
| 尧乐科技 | Pre-A / Pre-A+ 融资 | 投资方 **小米 + 科沃斯** |
| 矩侨工业 | 种子→天使→Pre-A→Pre-A+→Pre-A++ | 多轮融资，**20 万片车规产能** |
| 他山科技 | 2025-12 被**柯力传感**战略入股 | A++ 轮成熟公司 |
| 禹山传感 | 被柯力传感全资并购 | 有营收的成熟公司 |

> ⚠️ **说明**：以上是"赛道有资本真金白银投入"的证据。但织序**零融资、无营收**，**不能直接套用上述公司的估值**——本项目是**"技术资产包"交易**，价值锚定在可验证的 demo 与可转移资产上。

### 6.4 价值杠杆（提升的是"概率"和"依据"，不是承诺金额）

| 维度 | 不投入 | 投入后 |
|---|---|---|
| 成交概率 | 极低（不可尽调） | **可谈** |
| 报价依据 | 无 | **有（有数据、有报告）** |
| 展示能力 | 只有一块 demo 垫 | **完整演示闭环** |
| 风险状态 | 只有图纸，无量化 | **FTO 有结论，可对外** |

### 6.5 风险上限（对老板最重要的数字）

| 项 | 数值 |
|---|---|
| 最大现金风险 | **≈ ¥1.5–5 万**（可控） |
| 时间风险 | 8–10 周（不占用主营） |
| 贬值风险 | **极低**——资产不是消耗品，做出来的东西仍在，可用于后续合作或自用 |

> **一句话**：**这是用一笔小钱，验证"这套资产到底能不能卖、能卖多少"。** 相比经编机的历史投入，风险量级完全不同。
