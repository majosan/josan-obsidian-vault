# 智能床垫压力监测垫系统 · 场景与角色（V1.0）

> **一句话**：一套**面向物业/养老机构**的柔性压力监测床垫系统 —— 自动识别**坠床风险、离床、久卧不动**等异常，实时推送告警给护理人员与家属，并以数据报表辅助护理决策。
>
> **架构口径（本版关键变化）**：**不再用 PC 做网关**。采集板加装 **WiFi 模组**，实现 **手机端 → 云端 → 设备端** 直连。PC 仅作为开发/调试工具，**不是链路必需**。

## 1. 产品定位与价值主张

### 1.1 一句话定位
**装在床垫下的一张"压力感知层"**：不说话、不拍视频、不接触皮肤，就能知道老人**在不在床、动不动、有没有往床边滑**，把风险提前几分钟告诉护理员。

### 1.2 对四方价值

| 对象 | 痛点 | 本系统价值 |
|---|---|---|
| **老人** | 夜起摔倒、久卧压疮、无人知晓 | 无感监测，无需佩戴设备，隐私友好（**无摄像头、无穿戴**） |
| **家属** | 不在身边、心里没底、怕出事担责 | 手机随时看状态、收告警、看周报 |
| **护理员/护工** | 一人看几十张床，跑不过来，靠耳朵听 | 一屏看多床，**先救谁一目了然**，减少无效巡房 |
| **物业/机构** | 人难招、责任重、事故赔偿高、缺乏服务抓手 | 降低事故率与赔付风险、**可量化护理质量**、形成增值服务卖点 |

### 1.3 差异化卖点（对客户讲）
1. **无感无侵入**：不佩戴、不拍摄、不接触皮肤 —— 老人接受度远高于手环/摄像头。
2. **柔性织物传感**：可裁剪/可折叠、贴身合体，不是硬质床垫条。
3. **风险前置**：不是"事后知道掉下床了"，而是**坠床风险预警**（重心持续贴边即报）。
4. **一张床一套价**：硬件+云服务按床订阅，物业/机构决策成本低。

## 3. 场景地图

### 3.1 场景分类维度

| 维度 | 取值 |
|---|---|
| 场所 | 机构养老院 / 护理院、社区日间照料中心、**居家**、医院陪护（后续） |
| 居住时长 | 长住（失能）、短期（术后康复）、日托（白天/午休） |
| 自理能力 | 自理、半失能、失能、**认知症（阿尔茨海默）** |
| 时段 | 夜间（高风险）、午休、白天活动 |

### 3.2 核心场景清单

> 格式：**场景 → 痛点 → 系统行为 → 成功判据**

#### SC-01 机构夜间离床未归（最高频风险）
- **痛点**：老人夜里起身上厕所，长时间未回床，护理员靠巡房发现，中间可能已摔倒。
- **系统行为**：`离床` 事件 → 生效时段（默认 21:00–06:00）内计时 → 超时（可配 5/10/15/30 min）→ **升级为告警**推护理端小程序 → 值班手机响。
- **成功判据**：护理员**在老人离床前 0 秒、回床前**已获知；超时告警 ≤ 设定阈值 + 10s 送达。

#### SC-02 坠床风险（贴边/滑落）
- **痛点**：老人翻身习惯性往床边靠，硬质护栏又不愿用；真正掉下去才发现。
- **系统行为**：在床时检测**压力重心持续贴近/越出床沿带**（`edgePct` 超阈值并持续 T）→ 发 **`坠床风险`（L3 紧急）**；若"贴边后 3s 内离床"也判为高风险。
- **成功判据**：贴边持续 ≥ 设定 T 秒即报；风险事件**响应率 100%**（必须有处理记录）。
- **合规口径**：对外称"**坠床风险预警**"，**不称"坠床报警/跌倒报警"**。

#### SC-03 失能长期卧床 · 防褥疮（久卧/翻身）
- **痛点**：长期卧床需每 2h 翻身，护理员忙起来就忘；压疮一旦形成极难处理。
- **系统行为**：`久卧不动`（重心变化低于阈值持续 > 2h）与`翻身提醒`（距上次翻身 > 设定时长）→ 生成**护理任务**，写入护理端待办，完成需回执。
- **成功判据**：任务生成到完成有闭环记录；周报可统计**翻身依从率**。

#### SC-04 居家独居老人 · 家属远程看护
- **痛点**：子女在外地，父母独居；打电话怕打扰，装摄像头老人抵触。
- **系统行为**：家属端小程序看实时在床/离床、收告警、看周报；异常时微信订阅消息直推子女。
- **成功判据**：家属可在 3 次点击内看到"现在在不在床"。

#### SC-05 社区日间照料中心 · 午休监测
- **痛点**：白天集中午休，房间多、人手少。
- **系统行为**：多床看板总览，告警按床位高亮；午休时段阈值单独配置。
- **成功判据**：一屏覆盖全部床位，告警刷新 ≤ 5s。

#### SC-06 认知症老人 · 频繁离床/游走
- **痛点**：认知症老人无目的起身走动，易走失或摔倒。
- **系统行为**：离床事件**高频聚合并统计趋势**，异常频繁（如夜间多次离床）时向护理主管推送"行为异常提示"。
- **成功判据**：可查看单人离床次数/时段分布图。

#### SC-07 术后/康复短期卧床 · 依从性监测
- **痛点**：医嘱要求卧床/限动，患者不自觉下床。
- **系统行为**：按床位配置"限制离床"规则，离床即提醒陪护。
- **成功判据**：离床记录可与护理记录对账。

#### SC-08 告警响应闭环（贯穿所有场景）
- **痛点**：告警发了没人看、看了没处理、处理了没记录 —— 出了事故无法举证。
- **系统行为**：告警 → 通知（微信/短信/语音外呼）→ 护理员**接单** → **处理+备注** → **归档**；全程留痕、可导出。
- **成功判据**：每条告警都有状态流转与处理人；报表可统计响应时长。

#### SC-09 交接班 / 巡房
- **痛点**：班次交接靠嘴说，风险老人信息传递失真。
- **系统行为**：交接班视图（当前告警、待办任务、重点老人）；巡查打卡（可选）。
- **成功判据**：交接记录可追溯。

#### SC-10 家属探视/远程安心
- **系统行为**：家属授权看实时状态与周报；可设置只看汇总看板，不看明细。

#### SC-11 机构运营数据（管理视角）
- **需求**：床位数/在线率、告警总数与类型分布、响应时长、翻身依从率、异常高发床位与时段。
- **用途**：排班优化、护理质量考核、事故举证、向家属/监管展示服务能力。

#### SC-12 集团/多机构 SaaS 管控（商业化）
- **需求**：租户隔离、跨机构汇总看板、统一规则模板下发、账号与权限集中管理、按床计费。

### 3.3 场景优先级

| 优先级 | 场景 |
|---|---|
| **MVP 必须** | SC-01、SC-02、SC-03、SC-04、SC-05、SC-08 |
| 商业化迭代 | SC-06、SC-07、SC-09、SC-10、SC-11、SC-12 |

## 4. 角色定义

### 4.1 角色卡

#### 【R1】老人（被照护者）
- **目标**：不被折腾、被尊重、有安全感
- **痛点**：抵触穿戴/摄像头；夜里起夜最危险
- **关键任务**：正常睡觉、起夜、翻身（**无操作**）
- **关心**：无感、不打扰
- **系统触点**：床垫（被动）

#### 【R2】家属 / 子女
- **目标**：随时知道老人状态，出事第一时间知道
- **痛点**：不在身边、信息不对称、怕担责
- **关键任务**：看实时状态、收告警、看周报、设定通知人
- **关心**：及时性、准确性、别误报骚扰
- **系统触点**：微信小程序·家属端、订阅消息

#### 【R3】护理员 / 护工（一线响应者 · 最高频用户）
- **目标**：快速知道"该去谁那"，少跑冤枉路
- **痛点**：一人管几十床、靠听靠看、疲惫
- **关键任务**：看多床看板、接单、处理告警、完成翻身任务、交接班
- **关心**：告警准确（别老误报）、操作快（手机上一两步）、不增加额外文书
- **系统触点**：小程序·护理端（**核心端**）、语音/短信提醒

#### 【R4】护理主管 / 护士长
- **目标**：护理质量可控、事故可预、排班合理
- **痛点**：看不到过程数据，只能靠事后追责
- **关键任务**：查看告警与响应统计、分配任务、复核高风险老人、导出报表
- **系统触点**：机构后台 Web

#### 【R5】机构/物业管理员（购买方执行人）
- **目标**：部署简单、成本可控、能对外讲价值
- **关键任务**：建机构/房间/床位、绑定设备与老人、开通账号、查看运营大屏
- **关心**：**部署是否省事**、售后是否靠谱
- **系统触点**：机构后台 Web、物业看板

#### 【R6】集团 / 多机构管理员（SaaS 租户管理员）
- **关键任务**：多机构切换、统一规则模板、账号权限、用量与账单

#### 【R7】平台运营 / 我方（客服、实施、运维）
- **关键任务**：设备生命周期管理、远程诊断、OTA 发布、租户开通、告警监控、数据导出支持
- **系统触点**：平台运营后台（内部）

#### 【R8】系统角色 · 床垫设备（WiFi 直连）
- **关键任务**：采集压力 → 边缘判定 → 经 WiFi 上行云端 → 断网缓存续传 → OTA
- **关心**：网络稳定、低功耗、升级不砖

#### 【R9】第三方系统（可选）
- 机构 HIS / 养老管理平台、物业系统、呼叫中心（对讲/紧急呼叫）、监管平台
- 通过**开放 API / Webhook** 对接

## 5. 关键用户旅程

### 5.1 机构夜间告警闭环（最核心旅程）
```
凌晨 02:14  老人起身离床
   │ 设备 3s 内判定「离床」→ WiFi 上行云端
   ▼
02:14:03   云端规则：生效时段内 + 计时开始
   ▼
02:24:03   超时 10 分钟未回床 → 生成 L2「离床超时」告警
   ▼
02:24:05   护理端小程序订阅消息推送到值班护理员手机 + 看板该床变红
   ▼
02:25:10   护理员点「接单」→ 到床边协助 → 点「已处理」+ 备注
   ▼
02:31:00   老人回床 → 自动生成「回床」事件，告警自动归档
   ▼
次日       主管在后台看到：响应时长 1 分 07 秒、处理人、备注
```
- **关键指标**：告警送达 ≤ 10s（P95）；响应率 100%；响应时长可统计。

### 5.2 家属开通旅程（物业代开）
```
物业管理员后台录入老人档案 → 扫码绑定设备/床位 → 邀请家属（微信分享）
        ▼
家属点开小程序 → 授权（知情同意）→ 看到实时状态 → 开启订阅消息
        ▼
收告警 / 每周一自动收到周报
```

### 5.3 物业批量部署旅程（决定成单效率）
```
到货 → 管理员后台批量导入房间/床位（Excel）→ 逐个扫码绑定设备
     → 小程序扫码配网（WiFi）→ 设备上线自检 → 试铺一张床做阈值校准
     → 批量复制规则模板 → 全楼层铺开
```
- **要求**：**单床配网 ≤ 3 分钟**，支持批量模板，配网失败有明确指引（这是能否规模化落地的关键）。

## 6. 告警闭环与升级机制

### 6.1 告警分级

| 级别 | 类型 | 通知渠道 | 要求 |
|---|---|---|---|
| **L1 提示** | 翻身提醒、久卧提醒 | 小程序消息中心 + 看板黄色 | 可批量处理，不强制留痕 |
| **L2 重要** | 离床超时、回床异常、设备电量低 | 微信订阅消息 + 看板橙色 | 需接单处理 |
| **L3 紧急** | **坠床风险**、设备离线、SOS（可选硬件） | 订阅消息 + 短信 + **语音外呼**（可配） | **必须处理+留痕**，支持升级 |

### 6.2 升级规则（Escalation）
```
L3 告警发出 → 5 min 未接单 → 通知护理主管
            → 10 min 未处理 → 通知机构管理员 + 家属
L2 告警发出 → 30 min 未接单 → 通知护理主管
```

### 6.3 告警去重与静默
- 同一床位 + 同一类型，在**事件窗口**内只报一次（避免刷屏）。
- 支持"**静默期**"（如已知老人下床如厕，可临时静音 N 分钟）。
- 支持**免打扰时段**（默认 22:00–06:00 仅 L2/L3 推送）。

### 6.4 通知渠道矩阵

| 渠道 | L1 | L2 | L3 | 备注 |
|---|---|---|---|---|
| 小程序消息中心 | ✅ | ✅ | ✅ | 兜底，必到 |
| 微信订阅消息 | — | ✅ | ✅ | 需用户订阅 |
| 短信 | — | — | ✅ | 商业化 |

## 7. 业务规则与假设

| # | 规则 | 默认值 | 可配置层级 |
|---|---|---|---|
| 1 | 离床判定 | 无压力持续 **3s** | 全局/机构 |
| 2 | 离床超时告警 | **30 min** | 床位级 |
| 3 | 久卧不动 | 重心变化 < 阈值，持续 **2h** | 床位级 |
| 4 | 翻身提醒间隔 | **2h** | 床位级 |
| 5 | 坠床风险边沿阈值 | `edgePct` > 阈值持续 **2s** | 床位级（需标定） |
| 6 | 生效时段 | **21:00–06:00** | 机构/床位 |
| 7 | 设备离线判定 | 无上行 > **2 min** | 全局 |
| 8 | 状态上行间隔 | **5s**（可 10/30s） | 机构 |
| 9 | 事件即时上报 | 立即 | 固定 |
| 10 | 阈值逐床校准 | 首次铺床校准流程 | 床位级 |

**关键假设**：
- 一张床垫 = 一位老人（不处理同床两人场景，MVP 不做）。
- 设备需 2.4GHz WiFi 覆盖（物业 WiFi 或自建热点）。
- 老人/家属**知情同意**后方可开通。

## 8. 术语表

| 术语 | 含义 |
|---|---|
| 在床 / 离床 | `inBed` 状态，由总压力阈值判定 |
| 压力重心 | 全床压力的加权质心坐标（越小越靠边） |
| `edgePct` | 边沿带压力占全床压力比例，坠床风险核心指标 |
| 坠落风险预警 | 重心持续贴边/快速离床的高风险事件（**非医疗报警**） |
| 久卧不动 | 长时间无明显体动，压疮风险 |
| 事件 vs 告警 | 事件 = 客观发生（离床）；告警 = 需人响应的通知（离床超时） |
| 租户 | 一个机构/物业项目的数据与配置隔离单元 |
| 配网 | 将设备连入 WiFi 并绑定到云端账号的过程（BLE/SoftAP） |
