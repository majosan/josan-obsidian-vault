## 一、结构与面料（机械 / 材料规格）

### 1.1 尺寸

| 项 | 规格 | 说明 | 状态 |
|---|---|---|---|
| 整垫尺寸（长 × 宽） | **1700 × 900 mm** | 适配单人床（1.9/2.0m 床板，可铺放）；四角 **R30** 圆角 | ✅ |
| 整垫厚度 | **≤ 8 mm（目标 6 ± 2 mm）** | 平铺于床垫上、床单下；卷曲半径 ≥ 50 mm（可折叠收纳） | ✅ |
| 有效传感区（长 × 宽） | **≈ 1550 × 775 mm** | 四周各留 **≥ 60 mm** 封边/走线带（走 FPC 与封合） | ✅ |
| 床边信号引出 | **床尾（脚端）中线** | 见 §三 采集板位置 | ✅ |
| 重量 | **≤ 2.5 kg**（目标 ≤ 2.0 kg） | 需单人可铺床 | ⚠️ |

> 传感区取 **1550 × 775 mm**：覆盖躯干 + 一定余量，满足离床/坠床边缘检测；不建议做满垫（封边与走线必须留空间）。

### 1.2 阵列与传感点

| 项 | 规格 | 说明 | 状态 |
|---|---|---|---|
| 阵列规模 | **32 × 32 = 1024 点** 🔒 | 与《设备通信协议 v1.0》《功能需求》一致（1024B 帧、8×8 缩略图）；**不建议改** | 🔒 |
| 点间距（长向 / 宽向） | **50 mm / 25 mm** | 由 1550×775 覆盖 32×32 反推；长向密度略低（人体轮廓以宽向分辨） | ✅ |
| 单传感点尺寸 | **4 × 4 mm** | 沿用现有镀银纱 × 压敏纱正交交点工艺 | ✅ |
| 电极走线 | 刺绣锯齿形走线（沿用现有工艺） | 正交交叉点成传感单元；IO 全部汇到床尾引出区 | ✅ |
| 最小可检测压力 | 目标 **≥ 20 g / 点** | 养老场景不需手套级灵敏度，优先**一致性**与**耐久** | ⚠️ |
| 串扰要求 | 相邻点串扰 ≤ 邻点信号 10% | 沿用电路隔离结构（现有优势） | ✅ |

### 1.3 面料与封装（含舒适性 / 对传感层影响 / 防静电）

**三层结构（自上而下）：**

| 层 | 材料建议 | 作用 | 关键要求 | 状态 |
|---|---|---|---|---|
| **① 表层（亲肤接触层）** | **针织纯棉 / 竹纤维 / 莫代尔**（160–220 g/㎡） | 舒适透气、亲肤、可接触皮肤 | **可拆洗外套**（拉链/魔术贴），机洗 ≤ 40℃、≥ 30 次不失效；**不使用涤纶**（易起静电、易吸附） | ✅ |
| **② 传感核心层** | 镀银纱电极 + 压敏纱（尼龙+碳黑）三层织物 | 压力感知本体 | 封装**不可水洗**，仅表面擦拭；整体做**三防（防潮/防霉/防污）**处理 | ✅ |
| **③ 底层（防滑/防水层）** | **TPU 防水膜 + 点塑防滑颗粒** | 防滑、阻断液体上行（防尿湿/渗液） | 防水膜完整不破；防滑面摩擦 ≥ 床单 | ✅ |
| 四边封合 | 高频热合 / 包边缝合 + 防水胶条 | 封边强度 + 防水 | 接缝**不可渗液**进入传感层 | ✅ |

**舒适性与传感层影响（关键权衡）：**

- 表层**越厚越软 → 压力衰减越大、灵敏度越低**。建议：表层压缩后 ≤ 1.5 mm，保证 20 g 级检出。
- 表层**必须可拆洗**：老人场景不可避免汗渍/污渍；采用"外套可洗 + 核心层封装"方案，兼顾卫生与寿命。
- 表层**避免硬挺/厚重绗缝**（会在点间形成预压力，压低一致性）。
- 底层防水膜可**阻隔液体**，但也**略增刚度**——选软质 TPU（≤ 0.15 mm）。

**防静电（ESD）—— 必须考虑：**

| 措施 | 说明 | 状态 |
|---|---|---|
| 面料选型 | 表层选**棉/竹纤维**（吸湿、低静电），**禁涤纶**；可选**抗静电整理** | ✅ |
| 织物接地路径 | 传感层**银镀纱本身导电**，需在引出区做**统一参考地**，避免电荷积累 | ✅ |
| 板级防护 | 采集板每个电极接口加 **TVS（ESD 保护）**，耐受 ±8 kV 接触放电 | ✅ |
| 漏电安全 | 系统 **5V SELV 安全低压**；如日后引入市电务必隔离 | 🔒 |
| 测试要求 | 通过 **接触放电 ±8kV / 空气放电 ±15kV** 静电测试（IEC 61000-4-2 参考） | ⚠️ |

### 1.4 舒适/安全合规

| 项 | 要求 | 状态 |
|---|---|---|
| 亲肤安全 | 面料参照 **OEKO-TEX Standard 100**（或等同） | ⚠️ |
| 阻燃 | 可选（机构招标常要求）；家用可暂不要求 | ⚠️ |
| 防水等级（整垫） | 表面防溅 **IPX4**（非浸水） | ✅ |
| 承重/耐久 | 静载 ≥ 120 kg 长期不损坏；疲劳 ≥ 5 万次翻转（模拟） | ⚠️ |

## 二、硬件规格

### 2.1 供电与功耗

| 项 | 规格 | 说明 | 状态 |
|---|---|---|---|
| 供电方式 | **DC 5V（Type-C 接口）** | 标配 **5V/1A** 适配器（建议 **5V/2A** 留 WiFi 峰值余量） | ✅ |
| 是否需适配器 | **需要**（Demo / 试点有线常供）；随箱配 1 个 + 1.5 m 线 | 电池版列为 P2 | ✅ |
| 板载电压域 | 5V 输入 → **3.3V**（LDO/Buck）供 MCU 与模组 | WiFi TX 峰值电流 ≤ 500 mA | ✅ |
| 整机功耗 | 待机 < 0.3 W；工作典型 < 0.5 W；**峰值 < 1.5 W** | 按 5s 上报 + 事件即时估算 | ✅ |
| 电池版（P2） | 3.7V 可充锂电，**续航 ≥ 30 天** | 降频 + 深休眠 | ⚠️ |
| 安全 | 5V SELV 低压，**不外露市电** | 🔒 |

### 2.2 WiFi 与通信

| 项 | 规格 | 状态 |
|---|---|---|
| 频段 | **2.4 GHz**（802.11 b/g/n）；**不支持 5G** | 🔒 |
| 配网蓝牙 | **BLE 5.0**（BLE 配网首选 / SoftAP 兜底，帧见协议 §11） | ✅ |
| 协议 | MQTT over **TLS 1.2+**（8883），KeepAlive 30s | 🔒 |
| 模组建议 | **ESP32-S3 / ESP32-C3**（WiFi+BLE 一体，生态好、成本低）；或涂鸦/移远成品模组 —— **⚠️ 待 Josan 选型** | ⚠️ |
| 天线 | 板载/外置天线，**净空区禁金属**；采集盒内预留天线净空 | ✅ |

### 2.3 设备端功能（对应功能需求 A）

1. **采集与预处理**：32×32 @ ≥15Hz；滤噪、基线校正、坏点补偿；算总压力/重心/峰值/edgePct/8×8 缩略图/在床判定（A1）。
2. **边缘事件判定**：离床/回床/坠床风险/久卧/翻身，本地兜底 + 云端复核（A2）。
3. **配网**：BLE 优先 / SoftAP 兜底；一键重置；单床 ≤ 3 分钟（A3）。
4. **联网通信**：MQTT over TLS；事件 QoS1、状态 QoS0；**断网缓存 ≥ 24h**、seq 补传去重（A4）。
5. **设备管理与 OTA**：上报版本/电量/信号/在线/自检；A/B 分区、差分、灰度、回滚（A5）。
6. **安全**：一机一密/一机一证书；固件签名校验；量产关调试口（A6）。

### 2.4 小程序功能

**A. 物业端（值班）— 核心（C1）**
- 多床看板（在线/在床/告警一屏总览，按级别高亮）
- 告警列表与详情（时间线/级别/房间床位/老人/触发条件）
- 接单 → 上门处理 → 备注 → 传照片
- 照护提醒（久卧/翻身待办）· 交接班 · 通知/免打扰设置

**B. 家属端（C2）**
- 绑定与知情同意
- 首页实时状态（在床/离床大图标 + 最近告警）
- 告警列表与响应 · 周报（在床时长/离床次数/翻身/告警趋势）
- 我的（绑定管理/订阅设置/**短信手机号**/通知人）

### 2.5 后台管理功能（Web）

| 模块 | 功能 | 状态 |
|---|---|---|
| 项目后台（C3） | 多床实时看板、告警流转、历史查询、报表导出；楼栋/房间/床位/老人/设备管理、批量导入 | ✅ |
| 设备管理（B1） | 注册/激活/绑定/解绑/停用、设备影子、批量导入与一机一密烧录信息 | ✅ |
| 数据存储（B2） | 状态覆盖写 + 事件追加 + 统计聚合（**严禁存原始 15Hz 帧**） | 🔒 |

| 通知推送（B4） | 小程序消息 + 微信订阅消息 + **短信**；L3 升级链；响应策略（默认物业兜底） | ✅ |
| 报表（B5） | 时/日聚合、日/周/月报、导出 | ✅ |
| 账号权限多租户（B6） | RBAC + 租户数据强隔离 | ✅ |
| 运维后台（B8） | 设备监控、远程诊断、日志、OTA 发布、租户开通 | ✅ |
| 计费订阅（E6） | 按床采购 / 按年租赁；续费提醒；到期策略（不做突然断服） | ✅ |

## 三、采集板（硬件板卡）规格

### 3.1 位置（放在传感垫哪里最合适）

| 项 | 建议 | 理由 | 状态 |
|---|---|---|---|
| **首选：床尾（脚端）居中，独立采集盒** | 采集板**不放进躺卧区**，置于床尾外侧/床尾下方口袋 | ① 头/躯干是**最高负载区**，避开板卡受压；② 脚端走线最短、最隐蔽；③ 便于取电（床尾一般有插座）与维护 | ✅ |
| 采集盒尺寸 | **≈ 120 × 80 × 25 mm** | 容纳板卡 + Type-C + 按键 + 天线净空 | ✅ |
| 引出方式 | 传感阵列 IO 汇到床尾中线，经 **FPC（柔性排线）** 入盒 | 需要**应变释放**（防拉拽） | ✅ |
| 备选（垫内方案） | 若必须内置：置于**床尾中线偏侧**，避开躯干投影区 | 内置需加强保护（见 3.3） | ⚠️ |

> **结论：采集板做成"床尾外置采集盒 + FPC 引线"**，不埋在躺卧区。这样结构、散热、维护、防水都最省事。

### 3.2 按键与结构预留

| 项 | 建议 | 说明 | 状态 |
|---|---|---|---|
| 多功能键（1 个） | **短按** = 状态查询（LED 反馈）；**长按 3s** = 进入 BLE 配网；**长按 10s** = 恢复出厂/复位 | 一键多用，避免面板复杂 | ✅ |
| 复位孔 | **隐藏式**（针孔），防误触 | 与软件复位区分 | ✅ |
| 电源开关 | 可选物理开关（有线版可不加） | ⚠️ | ⚠️ |
| 指示灯 | **电源 / 联网 / 配网 / 告警**（多色 LED + 导光柱） | 现场排障靠 LED | ✅ |
| 结构预留 | 按键开孔 + 按键帽、导光柱孔、隐藏复位孔、Type-C 开孔、**天线净空区** | 结构设计必须一次性预留 | ✅ |
| 挂点/固定 | 魔术贴 / 口袋式，可拆卸 | 便于取放与检修 | ✅ |

### 3.3 防水与防护

| 项 | 建议 | 说明 | 状态 |
|---|---|---|---|
| PCB 防水 | **三防漆（防潮/防霉/防盐雾）涂覆** | 老人环境湿度大、易尿湿，必做 | ✅ |
| 采集盒防护 | **IP54**（防尘 + 防溅），**不做浸水级** | 非水下使用，IP54 足够；IPX4 亦可 | ✅ |
| Type-C 口 | 选**防水型**或加**防尘防水塞** | 接口是最大进水点 | ✅ |
| 织物接缝 | 缝线处做**防水处理**（胶条/热合） | 防液体渗入传感层 | ✅ |
| 线缆 | FPC + **应变释放**，防拉扯断线 | — | ✅ |
| ESD | 电极接口加 **TVS**，耐受 ±8kV | 见 §1.3 | ✅ |
| 过热/过流 | 加保险丝/限流；温升 ≤ 20K | — | ⚠️ |

### 3.4 硬件板卡要点

| 项 | 规格 | 状态 |
|---|---|---|
| MCU | 建议与 WiFi 模组同芯（ESP32-S3/C3 一体），或 MCU + 模组分离 | ⚠️ |
| 阵列接口 | 32 行 + 32 列 IO（或行列扫描 + 多路复用），接传感阵列 | ✅ |
| 采集 ADC | 12-bit（与现有产品线一致，255 归一） | 🔒 |
| 存储 | Flash ≥ 4 MB（**断网 24h 事件队列**） | ✅ |
| 接口 | Type-C（供电/调试）、FPC（阵列）、按键、LED | ✅ |
