# 智能床垫压力监测垫系统 · 产品规格书（V1.0 · 定稿）

> **用途**：养老传感垫**结构 / 面料 / 电气 / 采集板 / 防护**设计参数的**唯一输入依据**（Josan 结构设计与硬件设计专用）。

> **V0.2 → V1.0**：① 模组**定为 ESP32-C2-MINI-1**；② 阻燃**家用版不做要求**（机构版另议）。至此全部参数冻结。

## 一、结构与面料

### 1.1 尺寸
| 项 | 规格 |
|---|---|
| 整垫尺寸（长×宽） | **1700 × 900 mm**，四角 **R30** |
| 整垫厚度 | **≤ 8 mm（目标 6 ± 2 mm）**，卷曲半径 ≥ 50 mm |
| 有效传感区 | **≈ 1550 × 775 mm**（四周留 ≥ 60 mm 封边走线带） |
| 信号引出端 | **床头端（头端）** |
| 重量 | ≤ 2.5 kg（目标 ≤ 2.0 kg） |

### 1.2 阵列与传感点
| 项 | 规格 |
|---|---|
| 阵列规模 | **32 × 32 = 1024 点** 🔒 |
| 点间距（长向/宽向） | **50 mm / 25 mm** |
| 单点尺寸 | **4 × 4 mm**（镀银纱 × 压敏纱正交） |
| 走线 | 刺绣锯齿形；IO 汇到头端 |
| 最小可检测压力 | **≥ 20 g / 点** |
| 串扰 | ≤ 邻点信号 10% |

### 1.3 面料与封装（四层）
| 层 | 材料 | 要求 |
|---|---|---|
| ① 表层（可拆洗） | 针织纯棉 / 竹纤维 / 莫代尔 160–220 g/㎡ | 机洗 ≤ 40℃、≥30 次；**禁涤纶** |
| ② 传感核心层 | 镀银纱电极 + 压敏纱三层织物 | 仅擦拭；整体**三防** |
| ②b 核心保护封装 | **超薄无纺布 ≤ 0.2 mm**（医用级） | 保护表面纱线；灵敏度衰减 **≤ 10%** |
| ③ 底层 | **TPU 防水膜 ≤ 0.15 mm** + 点塑防滑颗粒 | 膜完整不破 |
| 封边 | 高频热合 / 包边 + 防水胶条 | 接缝不渗液 |

### 1.4 防护 / 安全 / 合规
| 项 | 规格 |
|---|---|
| 整垫防水 | **IPX4**（防溅，非浸水） |
| 亲肤 | 参照 OEKO-TEX Standard 100（建议） |
| **阻燃** | **家用版不要求**；机构版另议（GB/T 17591 / B1） |
| 漏电安全 | 5V SELV 低压 🔒 |
| ESD | 电极接口 TVS **±8 kV** |
| 承重/耐久 | 静载 ≥ 120 kg；疲劳 ≥ 5 万次（待验证） |

## 二、硬件 / 通信 / 功能

### 2.1 电气与供电
| 项 | 规格 |
|---|---|
| 供电 | **DC 5V / Type-C（通用）** |
| 适配器 | **5V/1A，线长 2 m**，随箱配 |
| 逻辑电压 | 3.3V（LDO/Buck）；WiFi TX 峰值 ≤ 500 mA |
| 功耗 | 待机 < 0.3 W；典型 < 0.5 W；峰值 < 1.5 W |
| 电池版（P2） | 3.7V 可充，续航 ≥ 30 天 |

### 2.2 通信
| 项 | 规格 |
|---|---|
| 频段 | **2.4 GHz**（802.11 b/g/n），不支持 5G 🔒 |
| 蓝牙 | **BLE 5.0**（配网首选）/ SoftAP 兜底 |
| **模组** | **ESP32-C2-MINI-1**（≈11×14 mm，WiFi+BLE 一体）✅ |
| 协议 | MQTT over **TLS 1.2+**（8883），KeepAlive 30s 🔒 |
| 天线 | 板载/外置，净空区禁金属 |

### 2.3 设备端功能
采集与预处理（32×32 @≥15Hz、滤噪/基线/坏点、算总压力/重心/峰值/edgePct/8×8 缩略图）· 边缘事件判定（离床/回床/坠床风险/久卧/翻身）· 配网（BLE 优先）· 联网（断网缓存 ≥24h、seq 补传去重）· 设备管理与 OTA（A/B 分区、差分、回滚）· 安全（一机一密、固件签名、量产关调试口）。

### 2.4 小程序
- **物业端（值班，核心）**：多床看板、告警列表/详情、接单→处理、照护提醒、交接班、通知设置
- **家属端**：绑定+知情同意、实时状态、告警列表与响应、周报、我的（含短信手机号）

### 2.5 后台管理（Web）
项目后台（多床看板/告警流转/报表/资产层级/批量导入）· 设备管理 · 三层存储（状态覆盖写+事件追加+聚合，**不存原始帧**）· 规则告警（三级阈值+时段）· 通知推送（小程序+订阅消息+**短信**）· 报表 · RBAC/多租户 · 运维后台 · **计费订阅（采购/租赁）**。

## 三、采集板与结构
| 项 | 规格 |
|---|---|
| 位置 | **床头端（头端）侧边外挂**（不走床尾） |
| 采集盒 | **≈ 120 × 80 × 25 mm** |
| 引出/走线 | 阵列 IO 汇到头端，**FPC 沿垫体侧边**入盒；应变释放 |
| 固定 | 魔术贴/卡扣，可拆卸 |
| 按键 | **1 多功能键**（短按=状态 / 长按 3s=配网 / 长按 10s=复位）+ **隐藏复位孔** |
| 电源开关 | **无** |
| 指示灯 | 电源 / 联网 / 配网 / 告警（多色 LED + 导光柱） |
| 结构预留 | 按键帽、导光柱孔、隐藏复位孔、Type-C 开孔、**天线净空区** |
| 防护 | PCB **三防漆**；采集盒 **IP54**；Type-C 防水塞；接缝防水 |
| 板卡 | MCU 与模组同芯（ESP32-C2）；ADC 12-bit 🔒；Flash ≥ 4MB |

## 五、增补与优化（2026-10-08 增补）

> 本节为 2026-10-08 增补，作为 V1.0 的**补充规格**。⚠️ **标"建议/待验证"的数值为待测试标定确认的候选值，确认后方可作为验收依据**；标 🔒 仍为受约束不可改。
> 增补背景：为「床边/卫生间场景包」扩展与量产验收做准备（见 [[织物传感空间化与场景包概念 v0.1]]）。

### 5.1 跨点一致性、整垫标定与漂移（🆕 新增规格）
- **跨点一致性允差**：同一负载下各点输出相对均值偏差 **建议 ≤ ±20%（待测试标定确认）**。这是当前"三层封装导致一致性差"的**管理口径**——靠**逐点标定 + 允差**控制，不苛求硬件一致。
- **整垫标定方法**：出厂标定 + 安装引导标定；测试项目参考触觉手套 `test-protocol-v1.md` 的 T1（一致性）/T2（响应曲线）/T3（重复性）。
- **漂移**：连续 8h 基线漂移 ≤ 5%（与《功能需求 v1.1》A1 的 AC 对齐）。

### 5.2 温湿度影响与补偿（🆕 新增规格）
- **工作温湿度范围**：建议 **5–40 ℃ / 20–85 %RH（待验证）**。
- 压敏纱（尼龙+碳黑）对温湿敏感；床垫贴身，**汗液/体温/湿度会造成漂移**。须给出**温湿度基线补偿策略 + 漂移上限**，否则夜间误报/漏报无法解释。

### 5.3 分辨率与精度权衡（🆕 新增说明）
- 床垫用 **50 mm / 25 mm 稀疏阵列**（非手指级 3–4 mm）。须显式说明：**分辨率↓ → 重心/边沿(edgePct)精度↓**，并给出 **32×32 能否支撑姿态识别（D2 ≥85%）的验证依据**。

### 5.4 洗护边界与寿命（🆕 补充）
- 现状：**整垫不可水洗**（核心层仅擦拭）+ 整垫 **IPX4** 防溅；表层可拆洗。
- **对比警示**：Wisbi 为 **95 ℃ 可洗 100 次、3×AA 半年续航**——这是**明确的体验差距**。
- 建议：强化「**可拆洗面层 + 防渗核心**」分体设计；对**汗液/尿液**的防渗等级写清；**对外口径避免用"可洗"**。

### 5.5 首次铺床校准流程（🆕 规格化）
- 步骤：**空载基线 → 铺床朝向（头端识别）→ 负载标定 → 阈值生成 → 下发验证**（与《设备通信协议与数据规范 v1.0》标定流程一致）。

### 5.6 无线合规与型号核准（🆕 新增）
- 2.4 GHz WiFi 需按销售区域取得 **SRRC（中国型号核准）/ CE-RED（欧盟）/ FCC**；增加一节合规清单（Wisbi 走 868 MHz 属 EU SRD，是另一套认证）。

### 5.7 边界条件（🆕 补充）
- **同床两人：不支持**（显式写入规格）；**宠物上床过滤**；相邻多床 2.4 GHz 互扰 → 需信道规划。

### 5.8 线缆 / 接口耐久（🆕 补充）
- FPC 沿侧边入盒 + 床头外挂：牵拉 / 清洁喷溅 / 宠物咬 → **应变释放的疲劳要求须量化**（次数/力值/允差）。

### 5.9 电池版续航落差（🆕 提示，不改本轮协议）
- WiFi 电池版（目标 ≥30 天）与 Wisbi（3×AA ≈半年）差距根因是 WiFi。当前通信协议**已定 2.4 GHz WiFi**（锁定），**低功耗/备份通道列为"待评估项"，不纳入本轮**。
