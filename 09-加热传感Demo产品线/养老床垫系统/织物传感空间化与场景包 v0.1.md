# 织物传感空间化与场景包（功能定义 · 卖点话术）V0.1

> **一句话**：在床垫之外，把同一套柔性织物传感铺到**卫生间、床边、活动区等关键点位**，用"**停留时长 + 活动节奏**"识别**久留预警、跌倒、游走、规律变化**，形成可分场景售卖、可分阶段落地的「**场景包**」。
>
> **口径前提**：通信沿用 **2.4 GHz WiFi + MQTT**（不改协议）；**不做"连续轨迹"，只做"关键点位 + 行为事件"**（技术现实）。

---

## 1. 定位与基本口径

| 项 | 口径 |
|---|---|
| 产品形态 | 关键点位（地垫 / 扶手 / 墙面板）传感 + 复用现有采集板 / 云 / 小程序 |
| 核心指标 | **区域停留时长、停留次数、时段分布、区域体动/倒伏** |
| 不承诺 | ❌ 连续运动轨迹 ❌ 精确"在哪一格" ❌ 医疗诊断 |
| 传感选型 | 地垫 = 压力织物阵列；**扶手 / 墙面 = 电容式触摸/接近**（非压力） |
| 通信 | 2.4 GHz WiFi + MQTT（**保持不动**） |
| 数据模型 | 现有 项目→楼栋→房间→床位 之下扩展 **区域(zone)→点位(point)** |

---

## 2. 场景包清单（可独立售卖 / 可组合）

| 场景包 | 点位 | 传感 | 主打功能 | 优先级 |
|---|---|---|---|---|
| **卫生间包** ⭐ | 马桶前地垫、淋浴区地垫、扶手、门口 | 地垫=压力；扶手=电容 | 久留预警、跌倒、如厕规律 | **P0（旗舰）** |
| **床边包** | 床侧地垫 | 压力阵列 | 下床→落地→离开/返回、床边久站 | P0（与床垫配套首发） |
| **活动包** | 沙发/座椅垫、常走位地垫 | 压力阵列 | 久坐、起坐困难、活动量趋势 | P1 |
| **整屋包** | 地面整片 + 多点 | 压力 + 电容混合 | 区域级位置、步态、跌倒 | P2（远期） |

> **为什么"卫生间包"是旗舰**：① 跌倒/晕厥/突发疾病**风险密度最高**；② 空间小、点位少 → **少量点位 + 事件推断**就能显著覆盖风险；③ **摄像头做得到但没人愿意装** → 隐私友好是差异化；④ Wisbi 只覆盖"床"，我们天然延伸到"**床边→卫生间**"最危险的动线。

## 3. 核心功能定义

> 说明：所有功能输出均为**事件/状态**（非轨迹）；告警分级沿用系统 L1/L2/L3。

### F1 · 久留预警（Dwell Alarm）★旗舰
- **定义**：为每个区域设"**正常最长停留时间**"，超时即分级告警。
- **数据**：区域占用状态 + 连续停留计时（离开即清零）。
- **触发**：停留 > 阈值（卫生间建议 **15 min**，可配）→ **L2**；再超（如 30 min）或伴随"倒伏"→ **L3（短信+小程序）**。
- **价值**：覆盖**跌倒/晕厥/突发疾病/被困**——"**不用等摔倒，进去太久就有人问一句**"。
- **卖点一句话**：**"不是等他摔倒才报警，而是他进去太久没出来就提醒你。"**

### F2 · 区域跌倒 / 异常倒伏
- **定义**：区域内压力面**瞬间铺开 + 长时间低体动** → 判"倒伏"；结合"由站到躺/无起身"签名。
- **触发**：区域内检测到倒伏 → **L3**。
- **价值**：**定位到区域**（"在卫生间/在走廊"），缩短救援时间。
- **口径**：对外称"**跌倒风险/倒伏提示**"，避用"跌倒报警"。

### F3 · 夜间起夜安全闭环（组合故事）★
- **动线**：床垫（离床）→ 走廊点位 → 卫生间（滞留/倒伏）→ 返回床。
- **逻辑**：离床后计时，若"离床 → 触发卫生间久留 → 未按时返回"任一环节异常 → 逐级升级。
- **价值**：**一条动线讲完，风险全覆盖**；把床垫与场景包**捆绑成一个方案**卖。
- **卖点一句话**：**"从下床到回床，这一整段路，我们都盯着。"**

### F4 · 生活规律画像 / 趋势（健康向）
- **定义**：按区域统计**停留时长、次数、时段分布**，出行/周/月趋势。
- **触发**：偏离个人基线（如夜间起夜次数连续↑、如厕时长↑）→ **L1 提示**（非告警）。
- **价值**：**"作息变化本身就是信号"**（泌尿/感染等早期提示——**只做趋势提示，不涉诊断**）。
- **卖点一句话**：**"看不见的时候，也能知道爸妈的作息有没有变。"**

### F5 · 区域久坐 / 久卧
- **定义**：座椅/沙发等区域长时间无体动 → 提醒（久坐；久卧防压疮已有）。
- **触发**：> 2h（可配）→ **L1**。
- **价值**：预防久坐/压疮，配合照护提醒待办。

### F6 · 认知症游走 / 走失倾向
- **定义**：**多点位在夜间被频繁触发 + 床垫高频离床** → 判"游走/无目的活动"。
- **触发**：夜间跨区域触发频次超阈 → **L2 提示**（配合门岗可升级）。
- **价值**：对接**认知症照护**刚需。

### F7 · 区域占用 / 在离（基础状态）
- **定义**：各点位"有人/无人、在离时间"——**所有上层功能的基础数据**。
- **输出**：实时 zone 状态 + 事件流。

## 4. 卖点话术库

### 4.1 对家属（子女）
- 一句话版：**"父母的卫生间和夜间起夜，我们帮你盯着——不用装摄像头。"**
- 30 秒版：老人最怕的两件事——"**出事没人知道**"和"**身体悄悄变差**"。装摄像头老人抵触、请保姆太贵。我们的传感垫铺在卫生间/床边，**无感、不拍人**：进去太久没出来会提醒你；夜间起夜路线异常也会提醒；每周给你一份作息趋势。
- 异议应对：
  - "和摄像头比？" → **隐私**（不拍照、不视频），老人易接受。
  - "和手环比？" → **不用戴、不用充电**，老人不会忘戴。

### 4.2 对物业 / 小区
- 一句话版：**"把风险最高的卫生间和洗浴区守住，出事有据、服务有说法。"**
- 价值：增值服务卖点（可量化、可宣传）+ **事故举证材料** + 降低担责风险；值班室一屏看风险老人。

### 4.3 对机构（养老院/护理）
- 一句话版：**"护理员不用整晚巡房，系统告诉你去哪一间、哪一刻。"**
- 价值：减少夜间例行巡房、降低褥疮与跌倒后果、把人力放到"有需要的时刻"。

### 4.4 差异化（对外口径）
| 对比 | 短板 | 我们的差异 |
|---|---|---|
| 摄像头 | 隐私差、老人抵触 | **无画面、无穿戴** |
| 手环/雷达 | 要戴、要充电 / 贵 | **铺好即用、无感** |
| Wisbi 等床垫 | 只覆盖"床"，**二值报警** | **延伸到床边→卫生间动线 + 连续压力分布 + 停留时长** |

## 5. 产品组合与售卖

- **售卖形态**：床垫（基础）+ **场景包（可选）**；或整包按"**房间/户型**"报价。
- **计费**：沿用现有 **按床/按点位采购 + 按年租赁** 两种口径；场景包按点位/区域计价。
- **推荐组合**：`床垫 + 卫生间包`（旗舰组合，一晚动线闭环）；机构可加 `活动包`。

---

## 6. 技术实现要点（复用为主）

- **传感**：地垫复用现有**压力阵列 + 采集板**（按场景改尺寸/密度）；**扶手/墙面另需电容式传感**（另一条技术栈）。
- **通信 / 云 / 小程序 / 告警 / 报表**：**全部复用**，新增点位即新增设备/子设备。
- **数据模型**：新增 `zones` / `zone_events`（区域→点位层），不影响既有床垫业务。
- **算法**：以"**占用状态机 + 停留计时 + 倒伏签名 + 基线偏离**"为主，不依赖高精度定位。

| 阶段 | 内容 | 时机 |

## 8. 风险与边界（对外红线）

1. **不承诺"轨迹/精确位置"**——统一说"关键点位 + 行为事件"。
2. **不涉医疗诊断**——趋势只做"提示"。
3. **地面/卫生间耐久是最大风险**：踩踏、拖洗、高湿；我们床上耐久尚未测（规格书疲劳 ≥5 万次待验证）。
4. **供电/走线**：多点位需解决供电/通信；协议已定 WiFi，**电池版续航受限**（专门评估）。
5. **不要现在铺开**——全屋是第二产品线/远期，当前集中"床垫 MVP 跑通付费闭环"。
