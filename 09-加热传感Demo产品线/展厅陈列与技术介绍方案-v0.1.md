# 南烯 · 织序 — 展厅陈列与技术介绍方案

> **一句话**：让参观的人在 15 分钟内形成四个判断——**产品做得出来、技术有门槛、场景想得清楚、市场正在爆发**。
>
> 本文档 = 「叙事主线」+「分区规划」+「展品卡」+「讲解脚本」+「物料清单」+「口径红线」。
> 三类人各取所需：管理层看第 1·9 节定调；讲解人看第 3·7 节背话术；布展执行看第 3·8 节列清单。

---

## 0. 先想清楚：展厅到底"演"什么

展厅不是仓库，不是把产品摆出来就完事。它是一场**被设计过的叙事**。

参观者（投资人 / 客户 / 产业方）进门时心里的默认剧本是："又一个做柔性传感器的，大概率是 PPT 公司。" 我们要做的，就是用**实物 + 数据 + 体验**把这个默认剧本改写成："这家是真把东西做出来了，而且卡在一个正在爆发的位置。"

四种要建立的感觉，各有对应手段：

| 要建立的感觉 | 靠什么建立 | 对应展区 |
|---|---|---|
| ① 产品做得出来 | **实物样品**（摸得到、按得动、看得见响应） | 产品阵列区 |
| ② 技术有门槛 | **工艺实物对比 + 指标墙 + 专利/产学研** | 技术原点区 |
| ③ 场景想得清楚 | **场景化 demo + 后台/小程序真实界面** | 场景体验区 |
| ④ 市场正在爆发 | **赛道数据墙 + 对标 + 时间窗口** | 市场蓝图区 |

> **布展第一原则**：**能摸到 > 能看见 > 能听到**。任何一区，只要能用"实物体验"代替"文字说明"，就换掉。
> **第二原则**：全程围绕一个核心记忆点打——**「单层一体织」**。所有分区都要为这五个字做注脚。

## 1. 全场统一口径（一句话定位 + 电梯演讲）

### 1.1 主定位（对外统一，勿改）

> **南烯·织序 —— 把「压力感知」与「智能发热」直接织进布里的柔性智能材料平台。**

拆成三个支撑词，反复讲、到处讲：

1. **全柔性织物** —— 不是薄膜、不是芯片，是布；透气、可折叠、可水洗。
2. **单层一体织** —— 一层布织出来，区别于行业主流"多层贴合/层压"方案（**技术代差，全场王牌**）。
3. **软硬件闭环** —— 自研采集硬件 + 软件 + 数据链路，不是只卖一块布。

### 1.2 电梯演讲（30 秒口播，讲解人必须背熟）

> "机器人和智能穿戴，都需要一种能弯折、能水洗、能大面积生产的压力传感器。现有方案——薄膜脆、芯片硬、涂覆没精度。我们走的是第三条路：**用纺织工艺，把传感器和发热层直接织进布料里**，一层布成型，透气、耐折、可水洗。
> 现在，1024 点的压力传感阵列、124 点的触觉手套、碳纳米管发热布，**demo 都已跑通、可现场演示**。我们切入的是机器人电子皮肤和康养这两个正在爆发的市场——这是个十年十倍级的赛道，我们卡在最有价值的那一环。"

### 1.3 两套侧重（投资人 vs 客户，讲解词要换挡）

| | 投资人 / FA / 产业方 | 客户（养老机构 / 机器人厂 / 品牌方） |
|---|---|---|
| 最关心 | 赛道多大、壁垒在哪、团队能不能交付、怎么退出 | 功能对不对、参数够不够、能不能定制、什么时候供货 |
| 主打内容 | 市场数据 + 技术代差 + 团队背景 + 卡位逻辑 | 场景 demo + 实测参数 + 后台界面 + 交付能力 |
| 动线重点 | 技术原点区 → 市场蓝图区 → 洽谈区 | 产品阵列区 → 场景体验区 → 数据软件区 |
| 结束动作 | 递《技术资产包》/ BP + 约尽调 | 递样品参数表 + 约送样试用 |

## 2. 展厅叙事主线（七幕剧）

整个展厅按一条"问题 → 答案 → 证据 → 想象"的线走，参观动线 = 七幕：

| 幕 | 主题 | 参观者心里的问题 | 我们要给的感觉 |
|---|---|---|---|
| 一 | **序厅** | 这是家什么公司？ | 有主线的公司，不是杂货铺 |
| 二 | **技术原点** | 别人做不出来吗？ | 有真工艺、有真材料、有门槛 |
| 三 | **传感产品阵列** | 东西到底做出来没有？ | 真做出来了，而且不止一款 |
| 四 | **加热产品阵列** | 还能干别的？ | 两条腿走路，技术可复用 |
| 五 | **场景体验** | 卖给谁？怎么用？ | 场景想清楚了，后台都做好了 |
| 六 | **量产与生态** | 做得出来≠造得出来 | 有装备底座，产业化不是空话 |
| 七 | **市场与蓝图** | 这生意大不大？ | 赛道爆发 + 清晰路线图 |

> **动线设计**：单向回形，从序厅进、洽谈区出，**不走回头路**。参观者脚步不停，情绪不断升级，最后落在"可以坐下来谈"的洽谈区。

### 3.1 ① 序厅 / 品牌定位墙

- **位置**：入口正对
- **展示物**：
  - 主标语墙：**"把触觉与温度，织进布里"**
  - 三个支撑词灯箱：全柔性织物 · 单层一体织 · 软硬件闭环
  - 一块**会发光的织物**（传感或发热布，通电即亮/即响应）作为"第一眼震撼"
- **讲解要点**（60 秒）：公司定位 + 30 秒电梯演讲
- **互动**：请参观者用手按一下墙上那块织物，旁边屏幕立刻出现压力响应曲线
- **目的**：**第一秒建立"这公司在做真东西"的印象**，把"PPT 公司"的默认剧本直接掐掉

> 💡 **关键技巧**：序厅不要放公司简介文字墙（没人看）。放一块**能按出反应的布**，胜过一万字。

### 3.2 ② 技术原点区 —— "我们凭什么是我们"

- **位置**：序厅之后整面墙（情绪从"这是什么"切换到"这不容易"）
- **展示物**：
  1. **材料实物台**：镀银纱线 / 碳纳米管(CNT)纱线 / 压敏纱线 / 普通纱线，各一小卷 + 标签（线电阻 ρ、直径、用途）。旁边放放大镜或微距屏。
  2. **结构剖面墙（核心）**：**单层一体织 vs 多层贴合**的实物剖面 / 显微图对比。
     - 我们：**一层布** → 更薄、更透气、可折叠、可水洗
     - 竞品：多层压合、涂覆 → 分层、厚重、易剥离、不透气
  3. **工艺演示**：刺绣走线样片 / TFP 定点铺纱示意（可用一块带锯齿形/平行走线的半成品展示"纱线怎么变成电路"）
  4. **指标墙**：把冷参数做成大字（见 §5.2）
  5. **专利 & 产学研墙**：专利受理/申请清单 + 东华大学合作（预氧丝镀铜课题等）
- **讲解要点**：从"沙线"讲到"传感器"，讲清三件事——**材料选型是我们的、电路设计是我们的、采集软硬件是我们的**
- **互动**：让参观者拉扯、对折、揉搓单层织样品，感受"折了还能用"
- **目的**：建立**技术门槛**。这是全场最需要"讲知识"的一区，也是最能劝退"我们也能做"的怀疑。

### 3.3 ③ 传感产品阵列区（中央岛台）

- **位置**：展厅中央，绕行走，四面可看
- **展示物**（见 §4.1 展品卡）：
  - **单层一体织传感布**（工艺展示件，重点）
  - **1024 点压力传感垫**（SKU-1，500×500mm，站着按/踩）
  - **压力传感床垫**（SKU-2，1400×700mm，可局部陈列）
  - **柔性触觉手套**（124 点，可佩戴）
- **中央大屏**：**实时压力热力图**——参观者按下去，屏幕上颜色实时变化
- **讲解要点**：讲清"1024 点 / 15Hz / 5g 最小可测 / 3-4mm 微小传感点 / USB 即插即用"
- **互动（核心）**：
  - 手掌按传感垫 → 大屏出现完整手印热力图
  - 手指轻戳 → 5g 灵敏度可视化
  - 戴手套握拳/捏物 → 实时看到握力分布
- **目的**：**"产品做得出来"的最强证据区**。热力图的视觉冲击力是销售利器（对标文档里自己写的：织物阵列的"视觉冲击力"是销售利器）。

### 3.4 ④ 加热产品阵列区

- **位置**：传感区之后（叙事转折："同一套织物技术，还能做加热"）
- **展示物**（见 §4.2 展品卡）：
  - **加热眼罩**（已定稿，可通电体验真实发热）
  - **暖宫包 / 发热护膝**（可体验）
  - **加热坐垫 / 加热床垫**（可坐/可躺）
  - **红外热像对比屏**：我们的**面加热均匀** vs 竞品"单根电热丝"的**点/线加热热点**
- **讲解要点**：技术同源（都是把导电/发热纱织进布）→ **验证了平台化能力**；加热线比传感线更容易先商业化（更快见收入）
- **互动**：摸温度、看热像、比均匀性
- **目的**：证明**不是单点产品，是一个可复用的技术平台**；同时给"更快落地"的商业信心。

> 💡 加热 vs 传感两条线并置的意义，要在讲解里点破：**"同一根纱，加热时是发热体，传感时是传感器"**——这是平台化的最好证明。

### 3.5 ⑤ 场景体验区（最能打动客户的一区）

按终端场景分四个"小剧场"，每个都是"坐进去/躺上去/玩一下"的沉浸式：

| 场景 | 体验形式 | 展示核心 | 叙事钩子 |
|---|---|---|---|
| **康养 · 养老** | 可躺/可坐的**压力传感床垫 + 轮椅传感垫**，旁边屏幕显示在床/离床、翻身、姿态 | 褥疮预防、离床报警、翻身提醒 | 老龄化刚需 + 织物透气性刚需 |
| **机器人 · 电子皮肤** | **触觉手套** + 机械臂/灵巧手抓取演示（抓到鸡蛋/易碎物，实时握力反馈） | 抓取力闭环、遥操作数采 | 人形机器人最后一块短板 |
| **汽车 · 智能座舱** | 传感坐垫（乘员识别/体压） | 座椅体压、乘坐状态感知 | 智能座舱电子皮肤兴起 |
| **智能穿戴** | 加热眼罩/护膝/暖宫包试用 | 穿戴舒适 + 精准控温 | 消费级更快变现 |

- **后台 + 小程序真实界面**（重点，别用 mock）：机构端多床位看板 / 家属端小程序 / 告警推送，**真机投屏演示**
- **讲解要点**：不是"我们也能做养老"，而是"**功能清单 + 后台 + 小程序都规划好了，可以和你一起定档**"
- **目的**：把"产品"升级成"**解决方案**"，让客户看到"我能怎么用"。

> ⚠️ 场景功能状态（在床/离床✅、姿态/坠床/呼吸心率⚠️需算法）：**对外只宣称已验证项，算法类讲成"迭代中/可定制"**，别把未验证的说成已有。

### 3.6 ⑥ 量产与生态区 —— "做得出来 ≠ 造得出来"

- **位置**：体验区之后，通往洽谈区
- **展示物**：
  1. **装备底座墙**：清梳棉机（苏拉）、进口并条机 / 粗纱机、经编装备研发样机的**照片 + 参数卡**（🔴 见 §9 红线：只讲"纤维处理到织造的制造配置"，**不宣布经编量产成功**）
  2. **供应链合作墙**：纱线/材料供应商（表述为"**战略合作材料商**"，见 §9）
  3. **专利墙**：已申请/受理清单
  4. **质量与测试墙**：内部测试协议、验收 SOP（眼罩已建立完整验收 SOP，可展示方法论）
- **讲解要点**："很多团队停在实验室，我们有从纤维处理到织造的完整制造配置 + 一套自己的测试标准"
- **目的**：把"demo 公司"的疑虑，转化为"**有产业化底座**"的信任。

### 3.7 ⑦ 市场与蓝图区 / 洽谈区

- **市场数据墙**（大字 + 图表，见 §6）：
  - 全球电子皮肤 **$63 亿(2024) → $300 亿+(2034)**
  - 人形机器人电子皮肤 **¥90.5 亿(2030)**，占机器人价值量 **~10%**
  - 全织物路线**仅约 3 家** → 差异化空白
  - 时间窗口：**1-2 年卡位期**
- **对标坐标图**：把 Tekscan / 尧乐 / 矩侨 / 捷迪纳米 放在一张"技术路线 × 成熟度"坐标上，我们标在**"全织物·单层一体织·早期但差异化"**的位置——**强调差异化，不藏着掖着**
- **路线图**：3 / 6 / 12 / 24 个月里程碑
- **洽谈区**：沙发 + 大屏（放演示视频/BP）+ 资料袋
- **目的**：把技术故事收口成**一个"大且有你的位置"的市场故事**，正好落座谈生意。

### 5.3 三方工艺对比（印成对照卡，随手发）

| 维度 | 薄膜/涂覆路线（福莱/华威科/捷迪） | 多层织物路线（尧乐/矩侨） | **我们（单层一体织）** |
|---|---|---|---|
| 结构 | 薄膜/印刷层 | 多层贴合 | **单层织造** |
| 透气 / 可水洗 | ✗ 差 | 一般 | **✅ 优** |
| 可折叠 | 受限 | 一般 | **✅ 优** |
| 功率/电阻可调 | ✗ 锁死 | 部分 | **✅ 按需设计** |
| 大规模织造 | 卷对卷涂布 | 复合工艺 | **✅ 梭织/刺绣可量产** |
| 量产成熟度 | **领先**（需诚实面对） | 较领先 | 早期（demo 验证） |

> **讲法**："我们不回避——论量产进度，薄膜路线走得更早；但论**织物结构本身**，我们走的是另一条更贴近'布'的路。**这不是追赶，是换道。**"
