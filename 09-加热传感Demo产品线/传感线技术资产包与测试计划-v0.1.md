## 二、功能场景定义（做哪些 / 不做哪些）

> **原则**：demo 不是产品，只做"能证明能力"的功能，砍掉一切需要新算法/新研发的。

### 主场景：康养（压力传感床垫 / 轮椅垫）

| 优先级 | 功能 | 说明 | 做不做 |
|---|---|---|---|
| **P0** | 在床 / 离床检测 | 压力阈值判定，纯阈值即可，无需算法 | ✅ 必做 |
| **P0** | 实时压力分布可视化 | 已有 | ✅ 必做 |
| **P1** | 离床超时告警 | 15/30/60 分钟分档，计时器逻辑 | ✅ 做 |
| **P1** | 后台看板（多床位）+ 小程序 | 见 [[传感数据上云与养老后台小程序技术方案-v0.1]] | ✅ 做 |
| P2 | 翻身 / 久卧提醒 | 需简单算法（重心变化），可迭代 | ⚠️ 迭代 |
| P2 | 姿态识别（仰/侧/俯） | 需算法 | ⚠️ 迭代 |
| P3 | 呼吸 / 心率（BCG） | 需算法 + 标定，难度大 | ❌ 暂不做 |
| P3 | 坠床预测 | 需算法 | ❌ 暂不做 |

> **对外口径**：P0/P1 说"已有"，P2 说"迭代中/可定制"，P3 不主动提。

## 三、测试计划（可照着测）

> **目标**：把"做出来了"变成"证明有效"。产出 = **《传感阵列测试报告》**（含曲线图），补上资产包唯一的缺口。

### 3.1 测试条件与设备（低成本）

| 设备 | 用途 | 说明 |
|---|---|---|
| 标准砝码组（5g / 10g / 20g / 50g / 100g / 200g / 500g / 1kg / 2kg / 5kg） | 定量加载 | 核心工具，低成本 |
| 均匀受力板（硬质平板 + 软垫） | 把砝码载荷均匀压到阵列上 | 简易自制 |
| 数字万用表 | 电气检查 | 已有 |
| 温湿度计 | 环境记录 | 低成本 |
| 恒温恒湿条件 | 温湿度漂移测试 | 空调房初测；精确测试可外包 |
| 秒表 | 响应时间 | — |
| 数据记录 | 用现有采集软件导出 JSON | 已有 |

### 3.2 测试项目表

| # | 测试项 | 方法 | 记录 | 参考目标（待对标锁定） |
|---|---|---|---|---|
| T1 | **静态一致性（均匀性）** ⚠️已知短板 | 同一砝码、同一受力面积，逐点/分区加载，比较各点读数 | 各点读数 → 偏差分布图 | 先测**基线**，再定改进目标 |
| T2 | **重复性** | 同一位置、同一载荷，加载/卸载 10 次 | 10 次读数 → 变异系数 CV | CV < 5% |
| T3 | **压力-ADC 标定曲线** | 分档砝码逐级加载，记录读数 | 压力-读数曲线（每点或分区） | 单调、可拟合 |
| T4 | **最小可检测压力** | 从最小砝码起逐步加载，找响应阈值 | 阈值（g） | ≤ 10g（标称 5g） |
| T5 | **响应 / 恢复时间** | 加载瞬间起，记录读数上升到稳定值的时间 | 时间（ms/s） | 记录即可 |
| T6 | **迟滞** | 加载曲线 vs 卸载曲线差异 | 迟滞环 | < 10% |
| T7 | **串扰（相邻点隔离）** | 单点加载，看相邻点读数变化 | 相邻点响应占比 | < 5% |
| T8 | **耐久 / 疲劳** | 反复加载（人工踩踏/简易机构）N 次后复测 | 灵敏度漂移 | 漂移 < 10% |
| T9 | **温湿度漂移** | 不同温湿度下基线 / 灵敏度变化 | 漂移曲线 | < 10% |
| T10 | **长时稳定性** | 连续通电数小时，基线漂移 | 漂移曲线 | 记录，作为改进依据 |

> **方法提示**：柔性织物的"一致性问题"是行业共性，测试结果可能不好看——**没关系，这正是要量化的东西**。先拿基线数据，才有"改进前 vs 改进后"的对比，也才有诚实对外讲的依据。
