## 一、认识 WorkBuddy（AI Agent）

### 1. 什么是 AI Agent

我们常用的 DeepSeek、豆包是"对话式 AI"——你问它答，它给你一段文字。**AI Agent（智能体）更进一步：不仅能回答问题，还能自己动手完成一整件事。**

> 你告诉它"把这份销售数据整理成周报，生成图表，做成 PPT 放到桌面"，它自己拆解步骤、读取文件、制作成品、交付给你。**AI Agent 帮你"把事做完"。**

### 2. WorkBuddy 是什么

**WorkBuddy 是腾讯云推出的企业级 AI 智能体工作台**，2026 年 3 月正式发布，定位"全场景 AI 办公工作台"。

| 定位                | 说明                                                   |
| ----------------- | ---------------------------------------------------- |
| **7×24 小时"数字员工"** | 云端或本地随时待命，面向人力、财务、法务、销售、采购、运营等十类岗位提供数字助手能力           |
| **能真正"干活"**       | 自然语言下任务 → 自主拆解步骤、调用工具、操作本地文件 → 交付可验收成品（报告/表格/PPT/视频） |
| **企业级平台**         | 企业管理后台、权限管控、审计日志，支持公有云/专有云/私有化部署                     |
|                   |                                                      |

**一句话：把重复性工作交给它，它交付成品，你做审核和把关。**

### 3. 它和办公软件有什么不同

| 对比项  | 传统办公软件       | WorkBuddy     |
| ---- | ------------ | ------------- |
| 谁干活  | 你自己          | AI 替你干，你是"指挥" |
| 怎么用  | 手动操作每个功能     | 说人话下指令        |
| 产出速度 | 一份周报写 1-2 小时 | 几分钟生成，你只需审核   |
| 学习能力 | 不学习          | 沉淀技能模板，越用越懂业务 |
| 多任务  | 一次一件         | 多任务并行         |
| 知识面  | 你会什么才能做什么    | 内置技能市场收录上万种技能 |

### 4. 一个真实的体验（物业公司员工分享）

腾讯云开发者社区一位物业综合部员工（负责公文起草、合同签订、文件管理）的分享：

> **法规文件整理**：把物业管理条例、房产局整治文件按统一格式整理成干净文档，以前至少一个下午，现在"喝杯水的功夫就完成了"。
>
> **Excel 统计表**：把原表直接发给 WorkBuddy，自动读取数据、生成规整新表。中途改了几次需求——加标题、去底色、姓名电话分列——"每次说一句话，它就改一版，全程没有理解偏差"。
>
> **她的评价**："它不是'回答一下就算了'的工具，能读文件、改文件、写公式、查信息，任务交下去能拿到成品，不是给你一堆建议让你自己做。"

## 二、为什么选 WorkBuddy（与其他 AI 的区别）

### 1. 本质区别：对话工具 vs 执行工具

| 对比维度   | 豆包 / DeepSeek / Kimi（对话式） | WorkBuddy（执行式）               |
| ------ | ------------------------- | ---------------------------- |
| 定位     | "你问它答"                    | "你让它做它就做"                    |
| 操作本地文件 | 不能，只能复制粘贴                 | 能，授权后直接读写 Word/Excel/PPT/PDF |
| 产出     | 一段文字建议，需手动落地              | 可直接使用的成品文件                   |
| 联动办公软件 | 不能                        | 打通腾讯文档、企业微信、邮箱               |
| 自动化    | 不能                        | 可设定时任务（如每周五自动生成周报）           |
| 多任务并行  | 单任务                       | 多 Agent 并行                   |
| 数据安全   | 数据上传第三方，无企业管控             | 本地沙盒 + 权限管控 + 审计日志           |
| 组织沉淀   | 个人使用，不沉淀                  | 团队模板、技能、知识库可共享               |

### 2. 用房产场景感受一下

**给 20 户欠费业主发催缴通知**
- **用豆包**：它给你一段模板，你还要打开 Excel 逐个看房号金额，逐条改、逐条发。**AI 写了模板，活还是你干。**
- **用 WorkBuddy**：把欠费名单 Excel 交给它，说"按欠费时长分 3 档生成 20 条催缴文案，含房号金额缴费方式"。它读取名单 → 生成文案 → 输出成品。**你只负责审核和发送（甚至这一步也能自动化调用接口完成）。**

**写销售日报**
- **用豆包**：你告诉它几个数字，它写一段分析文字。数据汇总、制表、排版还是你手动做。
- **用 WorkBuddy**：导出销售数据交给它，它直接读取、分析、生成完整日报，**还能设成每天定时自动生成。**

### 3. 企业版 WorkBuddy 的优点

| 企业关心的点 | 个人用豆包/DeepSeek | WorkBuddy 企业版                   |
| ------ | -------------- | ------------------------------- |
| 数据安全   | 无管控            | 企业级沙箱、权限管控、审计日志、支持私有化，符合集团数据红线  |
| 账号管理   | 各人各账号          | OneID 统一登录，部门统一管理               |
| 知识沉淀   | 个人对话，无法共享      | 团队共享上下文，技能模板沉淀为组织资产             |
| 自动化    | 无法定时执行         | 定时任务，周期工作自动完成                   |
| 对接系统   | 无法连接           | 可对接 OA、CRM、ERP 及腾讯文档（经企业 IT 授权） |
| 成本     | 不可控            | 后台统一用量统计、成本分析                   |

> **豆包/DeepSeek 不是不用了**：日常灵感、知识搜索、创意发散仍可用它们；重复办公任务、文件处理、流程自动化交给 WorkBuddy。**它们互补，不冲突。**

## 三、为什么房产行业需要 AI

### 1. 每天正在发生的真实困境（可能场景会有不同）

**销售的一天**：早上 1 小时整理来访登记表 → 中午搜竞品报告 2 小时 → 下午写带看记录和跟进表 → 会后 1 小时整理纪要 → 睡前憋半小时朋友圈文案。**一天真正见客户只有 2 小时，其余 6 小时全在写东西、填表格。**

**物业管家的一天**：早上 8 条报修逐条登记派单 → 中午 3 起投诉写回复 → 下午给 20 户欠费业主逐一编辑催缴短信 → 月底整理问卷 3 天才出报告。**大量重复劳动，业主体验也上不去。**

### 2. AI 能改变什么

| 传统方式                | 用 AI Agent 之后          |
| ------------------- | ---------------------- |
| 客户登记手动录入 → 1-2 小时   | 拍照/语音 → 自动整理 → 10 分钟   |
| 竞品报告网上搜+拼 → 1-2 小时  | 生成结构化初稿 → 人工补充 → 20 分钟 |
| 催缴短信逐条编辑 → 1 小时以上   | 导出名单 → 批量生成 → 5 分钟     |
| 会议纪要手动整理 → 30-60 分钟 | 录音上传 → 自动出纪要 → 5 分钟    |
| 朋友圈文案憋半天 → 30 分钟    | 输入卖点 → 生成多版 → 1 分钟     |

**核心价值：不是替代人，而是把人从重复劳动中解放出来，去做更有价值的事——见客户、维护关系、解决复杂问题。**

## 四、房产行业真实落地案例

> 以下案例来自腾讯云官方渠道公开信息，证明 WorkBuddy 在物业、投拓等房产细分领域已跑通。

### 案例 1：金碧物业 × 盈绰数科（来源：腾讯云 WorkBuddy 实战库）

| 场景   | 传统方式                            | 用 WorkBuddy         | 效果         |
| ---- | ------------------------------- | ------------------- | ---------- |
| 工单处理 | 7-12 步操作、最长 120 秒               | 口述需求，3 秒完成识别/分类/派单  | 效率提升 80%   |
| 业绩统计 | "广东省所有项目上月业绩明细"手动做 20-30 分钟     | 一句话自动聚合数据+生成图表      | 缩短至 5 分钟以内 |
| 品质分析 | "上海项目本季度 vs 上季度服务指标"人工分析 30 分钟+ | 自动拉历史数据环比分析，输出趋势+异常 | 压缩至 1-2 分钟 |

### 案例 2：地产投拓人的"地块周边配套分析"（来源：腾讯云开发者社区）

拿地前要查地块周边地铁/学校/商场/医院，截图标注进 PPT。
- 传统：手动逐个搜索，一块地 30-60 分钟，换块地全部重来
- WorkBuddy：安装"周边配套分析"技能，输入坐标，自动调用地图 API 生成交互式地图
- **耗时从 30-60 分钟/块缩短到 1 分钟以内**

> 说明：WorkBuddy 的"技能（Skill）"可针对专业工作流定制，做一次、反复用、可共享。

### 案例 3：物业综合部员工（来源：腾讯云开发者社区）

公文起草、合同签订、文件管理岗员工的真实体验，详见"一、认识 WorkBuddy"第 4 节。

### 案例 4：行业渗透与量化成效（来源：行业调研公开信息）

- 金碧物业、中建国际用 WorkBuddy 后，工单耗时从 120 秒缩至 3 秒，效率提升超 80%
- 合景悠活（物业）上云后运维成本下降 30%，巡检效率提升 85%，累计降本超 200 万元

> 以上为公开披露的第三方数据，本集团实际效果以试点实测为准。

### 从案例学到的三件事

1. **物业、投拓这些场景已有真实先例**，我们不是第一个吃螃蟹，风险可控
2. **效果是"分钟级"提效**：30 分钟的事变 5 分钟，2 分钟的事变 3 秒
3. **关键是"把工作流程整理清楚，再交给 AI"**——这正是以后 AI 智能部要陪大家做的事

## 五、市场部赋能场景

> 市场调研、竞品监测、品牌推广、媒体关系、市场策略

### 场景 1：竞品动态周报
- **痛点**：每周踩盘+搜新闻花 1-2 天，信息零散易遗漏
- **怎么做**：指令"搜集山水阳光周边 5 公里 3 个竞品楼盘本周动态（价格、优惠、开盘、推广），整理成周报表格+分析建议"
- **提效**：1-2 天 → 30 分钟（关键数据人工核实）

### 场景 2：市场调研报告
- **痛点**：区域调研报告搜集整理+排版写 3-5 天
- **怎么做**：指令"生成 XX 区域市场调研报告框架（区域概况/土地市场/新房供需/客群画像/未来预判），数据留空待填"
- **提效**：3-5 天 → 1 天（AI 搭框架，数据人工核实）

### 场景 3：品牌推广文案
- **痛点**：朋友圈文案、公众号文章半天写不出
- **怎么做**：指令"写 3 版朋友圈文案，分别面向刚需（学区+价格）/改善（户型+配套）/投资（升值潜力），每版 150 字"
- **提效**：30-60 分钟 → 5-10 分钟

### 场景 4：媒体软文 / PR 稿
- **痛点**：找广告公司代写，一篇 2000-5000 元、3-7 天
- **怎么做**：给素材要点，指令"写 800 字新闻稿初稿，主题品质交付年，风格正式"
- **提效**：3-7 天/2000-5000 元 → 1-2 小时/0 元

### 场景 5：节假日活动策划
- **痛点**：每个节日想方案，创意枯竭
- **怎么做**：指令"策划中秋业主活动方案框架（主题/流程/物料/预算/风险），预算 3 万、100 户参与"
- **提效**：1-2 天 → 1-2 小时

### 场景 6：市场数据周报
- **痛点**：每周收数据手动录入制图
- **怎么做**：给原始数据，指令"整理成周报表格+环比分析+生成图表+列 3 个异常点"
- **提效**：3-4 小时 → 15-30 分钟

## 六、营销策划部赋能场景

> 项目定位、营销方案、推广策略、物料制作、活动执行

### 场景 1：项目营销方案
- **痛点**：新项目方案写 1-2 周，每次从头开始
- **怎么做**：提供项目信息，指令"写营销推广方案初稿（SWOT/客群/价格/推广节奏/渠道/预算/物料），数据留空待填"
- **提效**：5-10 天 → 1-2 天

### 场景 2：售楼部物料文案
- **痛点**：户型单页、楼书、卖点卡等每盘 10 几种物料，外包周期长费用高
- **怎么做**：

| 物料 | 指令示例 |
| --- | --- |
| 户型单页 | "120 平 3 室 2 厅南北通透，写一页纸户型卖点说明" |
| 卖点卡 | "学区/地铁/现房/通透，每条卖点写 2-3 句话术卡" |
| 海报文案 | "周末加推 10 套特价房 95 折，写主副标题各 3 版" |
| 楼书大纲 | "生成楼书大纲：概况/区位/规划/户型/景观/物业/品牌 7 章" |

- **提效**：文案 1-2 周 → 1-2 天（设计排版仍需专业团队；价格面积人工核对）

### 场景 3：推广排期表
- **痛点**：Excel 手动填，节点渠道多易漏
- **怎么做**：指令"做 8 周推广排期（蓄客/预热/开盘/持销），每阶段列渠道/物料/预算/KPI"
- **提效**：半天-1 天 → 10-30 分钟

### 场景 4：竞品对标分析
- **痛点**：对标表手动整理，维度多
- **怎么做**：指令"做 3 个竞品对标表（均价/户型/容积率/绿化率/车位/交付/学区/地铁），竞品数据留空我来填"
- **提效**：3-4 小时 → 30 分钟（竞品数据人工核实）

### 场景 5：活动策划执行方案
- **痛点**：开盘、暖场、答谢方案每次从头写
- **怎么做**：指令"开盘活动方案（流程/布置/分工/物料/选房流程/应急预案/预算）"
- **提效**：1 天 → 30 分钟

## 七、售楼部（案场）赋能场景

> 客户接待、需求挖掘、房源推荐、价格谈判、签约促单

### 场景 1：客户画像与意向分级
- **痛点**：登记表手动填，意向分级靠主观判断
- **怎么做**：指令"这 8 组客户（已脱敏）生成画像 + A/B/C/D 四级分级（30/60/90 天）+ 每组 3 条跟进建议"
- **提效**：1-2 小时/天 → 10-20 分钟
- ⚠️ 客户姓名电话必须脱敏，严禁上传原始信息

### 场景 2：销售话术生成
- **痛点**：新人上手慢，竞品/逼单/异议话术没沉淀
- **怎么做**：

| 话术   | 指令示例                                 |
| ---- | ------------------------------------ |
| 竞品对抗 | "客户说 XX 府便宜，我们有学区+现房，生成 3 套应对话术"     |
| 异议处理 | "客户说再考虑，生成 5 种应对（价格/竞品/家人/周期/投资）"    |
| 逼单   | "客户看 3 次、价格到底线，生成 3 套逼单话术"           |
| 电话邀约 | "周末 10 套特价房，生成针对刚需/改善/投资 3 类客户的邀约话术" |

- **价值**：新人上手更快，话术沉淀为团队资产
- ⚠️ 话术须符合《广告法》，由销售主管审核

### 场景 3：日报/周报/月报
- **痛点**：每天手动整理销售数据写报告
- **怎么做**：导出系统数据，指令"生成周报：数据汇总+环比分析+个人排名+异常提醒+下周建议"
- **提效**：30-60 分钟/天 → 5-10 分钟

### 场景 4：政策解读与客户沟通
- **痛点**：房贷利率、限购政策看不懂，客户问起来答不上
- **怎么做**：把政策文件发给它，指令"用大白话解释 + 分析对首套二套影响 + 生成客户沟通话术 + 朋友圈文案"
- **提效**：30-60 分钟 → 5-10 分钟（省钱计算需按揭专员核对口径）

### 场景 5：带看路线与讲盘词
- **痛点**：带看路线和讲盘词靠老带新口口相传，不标准
- **怎么做**：指令"设计售楼部到样板间 20 分钟带看路线（沙盘→品牌→户型→工法→样板间→洽谈区），每个停留点写 3-5 句讲盘词"
- **价值**：新人首日即可参考带看，讲盘标准统一

### 场景 6：签约材料与按揭指引
- **痛点**：签约材料清单、按揭流程反复手动整理
- **怎么做**：指令"生成签约材料清单+流程指引（材料/签约流程/按揭流程/FAQ 10 条），生成可发给客户的《购房签约须知》"
- **价值**：减少重复答疑，客户少跑腿

## 八、项目部赋能场景

> 工程进度管理、质量验收、成本控制、施工协调、安全监管

### 场景 1：工程周报
- **痛点**：每周收各施工方数据→整理→制图→写分析，格式不统一
- **怎么做**：给进度数据，指令"生成工程周报：各楼栋进度表+本周vs上周对比+滞后预警+下周安排"
- **提效**：2-4 小时/周 → 15-30 分钟

### 场景 2：施工合同审查（辅助）
- **痛点**：总包/分包/采购合同几十页，法务人手有限，重点条款易漏
- **怎么做**：上传合同，指令"梳理工期违约/质量标准/付款节点/安全责任/变更签证/结算/争议解决，输出条款位置+内容摘要"
- **价值**：帮法务快速定位重点条款
- ⚠️ AI 审查≠法律意见，最终以法务审核为准；合同涉密注意使用渠道

### 场景 3：安全隐患排查与整改通知
- **痛点**：巡检问题手写整改单，台账手动维护
- **怎么做**：语音/文字录入问题，指令"生成整改通知单（期限/责任人/复查要求）+更新安全隐患台账"
- **提效**：30 分钟 → 5-10 分钟

### 场景 4：签证变更记录
- **痛点**：现场签证手写说明，格式不统一，月底对账头疼
- **怎么做**：指令"生成签证单（原因/变更内容/工程量/预估费用/附件/审批流程），费用留空待核"
- **提效**：20-30 分钟 → 5-10 分钟

### 场景 5：项目会议纪要与任务追踪
- **痛点**：周协调会多方参会，纪要整理费时
- **怎么做**：上传文字记录，指令"生成纪要（议题/结论）+待办清单（责任人/时间/标准）+争议项"
- **提效**：30-60 分钟 → 5-10 分钟

### 场景 6：材料验收与台账
- **痛点**：材料进场验收记录手动填，台账手动维护
- **怎么做**：拍照+语音，指令"生成验收记录单（规格/数量/供应商/批次/结论）+更新台账"
- **提效**：15 分钟 → 3-5 分钟

## 九、物业公司赋能场景

> 客服接待、报修维修、巡检保养、费用收缴、业主关系、社区活动
> **本部分与"案例 1 金碧物业"高度重合，是验证最充分的领域。**

### 场景 1：报修工单智能分类派单（已有真实案例）
- **痛点**：手动登记→分类→派单，一单 7-12 步、最长 120 秒
- **怎么做**：语音/文字录入报修，指令"分类工单+生成工单表+匹配班组+生成业主回复话术"
- **真实效果**（金碧物业）：3 秒完成识别分类派单，效率提升 80%

### 场景 2：物业费催缴
- **痛点**：每月逐户编辑短信，话术生硬，不同欠费时长策略不同
- **怎么做**：导出欠费名单（脱敏），指令"按欠费 3/3-6/6 个月以上分 3 档生成个性化催缴文案，含房号金额缴费方式"
- **提效**：1-2 小时/月 → 5-10 分钟
- ⚠️ 业主姓名电话房号必须脱敏

### 场景 3：巡检报告
- **痛点**：设备/卫生/安全巡检记录手动填，异常易漏
- **怎么做**：拍照+语音，指令"生成巡检报告：巡检表+异常项清单+报修建议"
- **提效**：30 分钟 → 5-10 分钟（行业参考：合景悠活巡检效率提升 85%）

### 场景 4：业主群运营与公告
- **痛点**：停水停电通知、节日问候、活动通知每个都要写
- **怎么做**：

| 场景 | 指令示例 |
| --- | --- |
| 停水通知 | "明早 8-12 点 1-5 栋停水，生成群通知（范围/时间/应急/管家电话）" |
| 节日问候 | "生成中秋业主群祝福文案，温馨风格 120 字" |
| 活动通知 | "周六亲子运动会，生成活动通知+报名接龙文案" |
| 投诉回应 | "业主投诉电梯常坏，生成回应：道歉+排查维修+时间承诺" |

- **提效**：15-30 分钟/条 → 1-3 分钟

### 场景 5：业主满意度分析
- **痛点**：问卷数据量大，手动统计写报告费时，只停留在"满意度 XX%"
- **怎么做**：导出问卷数据，指令"统计各维度分数+按楼栋/入住时长交叉分析+找最低 3 项及原因+改进建议+可视化报告"
- **提效**：2-3 天 → 半天

### 场景 6：物业知识库（员工内部问答）
- **痛点**：新人不清楚制度、收费、流程，翻文件问同事
- **怎么做**：把制度/收费/服务标准导入知识库，员工直接问"车位管理费多少""装修申请流程"
- **价值**：新人上手更快，客服响应更及时

### 场景 7：物业费数据分析
- **痛点**：收缴率、欠费分析、催费效果数据分散
- **怎么做**：导出缴费数据（脱敏），指令"分析收缴率排名+欠费原因+催费效果追踪+收缴提升建议"
- **提效**：半天-1 天 → 30 分钟

## 十、财务部赋能场景

> 资金管理、成本核算、预算管理、税务管理、财务报表
> ⚠️ 财务数据涉密，严格守集团数据红线，仅限企业版内使用。

### 场景 1：经营日报/月报
- **痛点**：每天导数据手动填日报，月报数据量大加班常态
- **怎么做**：导出数据，指令"生成经营月报：签约/回款/未回款统计+环比同比+回款率排名+异常预警+建议"
- **提效**：日报 1-2 小时 → 15-30 分钟；月报 1-2 天 → 半天

### 场景 2：预算执行分析
- **痛点**：预算 vs 实际对比手动做，差异分析浅
- **怎么做**：指令"分析各部门预算执行率排名+超预算清单+节余分析+Q4 调整建议"
- **提效**：1-2 天 → 半天

### 场景 3：财务制度文件起草
- **痛点**：报销、费用、资金审批制度从头写
- **怎么做**：指令"起草差旅费管理制度初稿（审批流程/交通住宿餐补标准/报销流程/违规处罚），标准数值留空由财务核定"
- **提效**：2-3 天 → 半天

### 场景 4：税务申报材料准备
- **痛点**：各类税申报说明材料费时
- **怎么做**：指令"整理增值税预缴材料清单（依据/计算公式框架/申报材料），具体金额我来填"
- ⚠️ 税务计算必须人工完成复核，AI 仅提供框架，**绝不可直接用于申报**

### 场景 5：合同付款审核（辅助）
- **痛点**：付款节点需逐条对照合同核查
- **怎么做**：上传合同+付款申请，指令"梳理付款审核要点：付款节点/是否到期/金额计算/前置条件（验收/发票）"
- **价值**：帮财务快速定位重点，减少遗漏；审核结论财务确认

## 十一、内勤行政部赋能场景

> 公文管理、会议组织、档案管理、办公用品、来客接待、后勤保障

### 场景 1：公文/通知/通报起草
- **痛点**：通知、通报、纪要、计划从头写，格式不规范
- **怎么做**：指令"起草安全大检查通知（目的/范围/时间/分工/重点/要求），正式公文格式"
- **提效**：30-60 分钟 → 5-10 分钟
- ⚠️ 公文以集团名义发布，须领导审核签发

### 场景 2：会议组织与会务
- **痛点**：通知、签到表、议程、座次、纪要每项手动做
- **怎么做**：指令分别生成会议通知+议程、签到表、座次图；上传文字记录生成纪要+待办
- **提效**：会务 1-2 小时 → 10-30 分钟；纪要 30-60 分钟 → 5-10 分钟

### 场景 3：档案与台账管理
- **痛点**：档案目录手动建立，找文件靠翻
- **怎么做**：指令"建立行政档案目录框架（集团文件/会议/合同/人事/项目档案），含编号规则"
- **提效**：半天 → 10-30 分钟

### 场景 4：办公用品采购清单
- **痛点**：采购计划/清单/比价手动做
- **怎么做**：指令"生成 9 月办公用品采购清单（按品类列规格/数量/预估单价/总计），最终以供应商报价为准"
- **提效**：1 小时 → 10-15 分钟

### 场景 5：来访接待方案
- **痛点**：重要来宾接待方案每次从头写
- **怎么做**：指令"生成住建局领导考察接待方案（流程/陪同/路线/讲解/会务/用餐/注意）"
- **提效**：1 小时 → 10-15 分钟

### 场景 6：工作总结与计划
- **痛点**：周/月/季度总结写半天
- **怎么做**：把完成事项要点给它，指令"生成周总结（完成/进行中/下周计划），不要编造事项"
- **提效**：30-60 分钟 → 10-15 分钟

## 十四、落地实施路径

1. **先用起来**：开通 WorkBuddy 个人账号，先自己试用，后期统一开启企业账号
2. **做试点**：选 1 个部门（建议物业或售楼部）+ 3-5 个高频场景，召集相关人员跑通
3. **每周反馈**：收集好用的、不好用的、想加的场景
4. **记录数据**：每个场景记录"原来多久 → 现在多久"，用实测数据说话
5. **沉淀模板**：好用的指令沉淀为团队模板

### 推广节奏

| 批次    | 部门              | 推广场景                 |

## 十五、使用困难与应对

### 困难 1："我不会用，感觉很难"

| 问题 | 应对 |
| --- | --- |
| 不知道怎么下指令 | 提供指令模板库，照着改关键词 |
| 担心搞错 | 不满意让 AI 重做，不会"搞坏" |
| 觉得不如手写快 | 新工具都有学习期，1-2 周后效率就上来 |

### 困难 2："AI 生成的内容不够准/不够好"

| 原因 | 应对 |
| --- | --- |
| 指令太模糊 | 补充项目名、目标对象、字数、风格 |
| AI 不了解业务 | 补公司/项目背景资料，让它"懂行" |
| AI 编造数据 | 涉及数字必须人工核实 |

**原则：AI 产出 = 初稿，人工审核 = 定稿。**

### 困难 3："担心数据安全"

| 顾虑 | 应对 |
| --- | --- |
| 客户信息泄露 | 姓名/电话/身份证用占位符（"客户 A"）代替 |
| 财务数据外泄 | 仅限企业版内使用，AI 做框架，敏感数据人工处理 |
| 公司机密外泄 | 未公开楼盘、成本利润不输入外部工具 |

**红线：客户个人信息、业主信息、员工隐私严禁进未授权外部 AI 工具。不虚构销售数据。企业版账号部门统一管理。**

### 困难 4："指令写不好"

**万能公式：角色 + 任务 + 背景 + 要求 + 格式**

| 要素 | 示例 |
| --- | --- |
| 角色 | "你是房产营销策划专家" |
| 任务 | "写一份楼盘推广方案初稿" |
| 背景 | "山水云景湾，XX 区，120 套，均价 13000" |
| 要求 | "800 字，含 SWOT 和推广节奏，数据留空待核" |
| 格式 | "以方案报告格式输出，含表格" |

### 困难 5："不同人用出来效果差别大"

- 沉淀标准指令模板，团队共享
- AI 智能部定期更新"指令模板库"
- 每月办"好用的指令分享会"

## 十六、培训计划建议

### 培训目标

> 结束后每位员工能独立用 WorkBuddy 完成 3 个以上本岗位相关场景。

## 重点传递的信息

1. **AI 是工具不是万能**：帮你省 80%"从 0 到 1"的时间，最后 20%"从 1 到 100"还得人把关
2. **不用怕搞错**：不满意就让 AI 重做
3. **越用越好用**：指令模板沉淀，团队越用越熟练
4. **重点是场景思维**：不是"学 AI 功能"，而是"想我的工作哪些环节能用 AI"
5. **数据和事实要核实**：涉及数据、金额、政策必须人工核实
6. **团队一起用才有效**：模板共享、经验共享，资产越用越厚

## 总结

WorkBuddy 带来的价值：

1. **省时间**：重复性、有套路的文档/表格/文案交给 AI，人去做更有价值的事
2. **提质量**：产出快且格式标准，团队统一，新人上手快
3. **沉淀资产**：指令模板、技能沉淀为组织资产，不因人员流动流失


**关键原则**：
- AI 是工具，业务是目的——一切落到真实场景
- 先试点后铺开，用实测数据说话，不夸大效果
- AI 产出需人工复核，涉及数据、金额、政策必须核实
- 客户隐私、财务数据不进外部工具，安全合规是红线
