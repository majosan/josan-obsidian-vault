## 二、待收集资料清单（开会安排人，逐项落实）

> 每项标注「收集什么」+「做什么用」，收集齐后反馈给我定稿。

### A. 创始人 / 核心成员履历
**收集什么**（每人一页）：
1. 姓名、职位
2. 学历：学校、学院、专业、学位
3. 现任职称（如东华大学研究生导师 / 教授，如有）
4. 研究方向与技术专长
5. 关键经历时间线（哪年到哪年、在哪、做什么、有何成果）
6. 代表性成果（论文 / 专利 / 获奖 / 主导项目）
7. 在本项目中的角色与贡献

**做什么用**：填充 Teaser「团队与背书」段；确认"创始人东华大学研究生导师"这一公开信息的准确性。

### B. 东华大学产学研合作
**收集什么**：
1. 合作形式（联合实验室 / 横向课题 / 技术顾问 / 学生培养基地）
2. 合作教授 / 课题组：姓名、职称、方向
3. 有无正式协议，能否对外披露（决定能否写进对外材料）
4. 合作成果（论文 / 专利 / 样品）
5. **电极纱线材料课题（预氧丝镀铜）**：是哪个课题组做的、具体方案、进展状态、有无成果——作为产学研合作的具体证据

**做什么用**：作为对外"学术背书"的硬证据；预氧丝镀铜课题是"东华合作"落地的具体例子。

### C. 团队规模与分工
**收集什么**：
1. 团队总人数
2. 分工：软硬件 / 算法 / 材料纺织 / 工程 各几人
3. 核心人员是否全职、是否愿随资产转移或提供过渡技术支持

**做什么用**：买方最关心"团队可转移性"，用于 IM（完整备忘录）阶段，Teaser 不展开。

### D. 知识产权清单
**收集什么**：
1. 已申请专利：数量、类型（发明 / 实用新型）、法律状态（受理 / 公开 / 授权）
2. 正在申请的方向
3. 软著、商标（如有）
4. **哪些是自研 / 改良的**（用于强调差异化、规避"借鉴竞品"风险）

**做什么用**：支撑"技术资产可转移"与"差异化"叙事，规避 FTO 风险表述。

### E. demo 展示素材
**收集什么**：
1. 1024 阵列传感垫：照片 / 视频 + 一句参数说明
2. 触觉手套（124 点）：照片 / 视频
3. 加热布：照片 / 视频
4. **单层一体织传感布：照片 / 视频 + 一份技术说明**（重点：单层 vs 多层、工艺优势、性能）

**做什么用**：对外"可面谈演示"的实物证据；单层一体织技术说明是最大卖点，需单独写一份能对外讲的版本。

### F. 装备资产清单（用于 IM 阶段，Teaser 已一句话带过）
**收集什么**：
1. 各设备品牌 / 型号 / 数量 / 购置时间
2. 设备当前状态（可用 / 待调试 / 闲置）与大致残值
3. 清梳棉机（苏拉）、并条机、粗纱机、经编机、设备样机分别说明

**做什么用**：Teaser 里只写"装备基础"一句话；完整设备清单放完整备忘录（IM），作为"制造底座"的量化证据。注意：对外不强调"失败/闲置"，只写"装备配置与基础"。
