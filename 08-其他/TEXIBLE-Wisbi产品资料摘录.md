# TEXIBLE Wisbi 产品资料摘录（欧洲同题竞品）

> **用途**：养老床垫（压力/离床传感）的**欧洲同题对标物**。证明"织物传感做养老"是**已被验证的真实需求**，且**居家场景成立**。
> **摘录自官方样册**（PDF 原文提取，2026-09-16）。

---

## 一、产品是什么

**TEXIBLE Wisbi®** — 智能传感织物**床垫插层**（bed insert / bed pad），由奥地利 **Grabher 集团**旗下品牌 **Texible** 出品。
- 定位：**护理场景生活辅助**（非医疗级起步），slogan "Care with focus"
- 起源：**2014 年**"Network Washable Sensor Textiles"（可水洗传感织物）跨学科研究项目
- 联合开发方：**养老院 + Fussenegger Textil（床品厂）+ Berendsen（洗衣服务商）**
- 官方定位原话："为住院护理与**居家护理**创造创新实用的产品"

## 二、核心功能

| 检测 | 说明 |
|---|---|
| **离床（bed exit）** | 人离开床时自动报警 |
| **体液（湿）** | **尿、血、呕吐物、粪便**接触传感织物即报警 |

- 报警方式：接入**现有护理呼叫系统**；无呼叫系统则用 **Eldat 插座接收器（无线 868.3MHz）** 或 **WLAN**
- 可设**报警延时**

## 三、产品矩阵（一套主品牌 + 场景后缀）⭐

| 版本 | 场景 |
|---|---|
| **Wisbi CLASSIC** | 湿检测基础版 |
| **Wisbi PLUS** | **机构护理**：湿检测 + 占用/离床检测（"all-round package for caregivers"） |
| **Wisbi HOME** | **居家护理**：WLAN + **手机 App** 报警 |
| **Wisbi PRO** | 急性场景，需实时监测 |
| **Wisbi KIDS** | 儿童夜遗尿 |
| **Wisbi WHEELCHAIR** | 轮椅 |
| **Wisbi DIALYSIS** | 透析 |

> **对我们的意义**：这就是"一个主品牌 + 场景后缀"的**现成命名范式**——机构版（PLUS）/ 居家版（HOME）。

## 七、对我们的四点意义（提炼）

1. **需求已验证**：织物传感做养老，欧洲有人做了、卖了、客户在夸——不是我们臆想
2. **居家/社区场景成立**：Wisbi 有 **HOME 版本 + App**，且 71% 需求在居家
3. **命名可参考**：主品牌 + 场景后缀（PLUS / HOME / PRO / KIDS / WHEELCHAIR / DIALYSIS）
4. **路径可复制**：先做**非医疗级**报警（离床/尿湿），**医疗认证后置**（其集团 24sens 的心电产品走的是 EU 认证 + €249 服务）

## 八、我们的差异化空间（对标要点）

| 维度 | Wisbi | 我们 |
|---|---|---|
| 核心功能 | 离床 + 湿（体液） | **压力分布（体压/姿态）**，功能不同层 |
| 传感原理 | 织物传感（湿 + 占用） | **压阻阵列（32×32=1024 点）**，可出体压分布图 |
| 数据价值 | 报警（二值） | **连续压力分布**（重心/姿态/呼吸潜力） |
| 我们可讲的故事 | — | "不只是报不报警，还能**看见**压力分布" |

> ⚠️ 注意：Wisbi 是**已验证的商业化产品**，我们是早期 demo；对标时**讲差异、不讲超越**。
