# FA（财务顾问）对接名单 — 南烯/织序出售与资产重组

> 整理：2026-09-07 ｜ 用途：逐家对接咨询（卖方/并购顾问 + 硬科技精品 FA）
> 背景口径：**早期技术资产包出售 / 战略合作，不接受对赌，交易体量小**
> 选 FA 三个硬指标：①有**卖方/并购**团队（不是只会做股权融资）②愿接**小体量**交易 ③有**硬科技/新材料/机器人**产业方资源
> 优先级：**T1 并购/卖方对口 → T2 新材料/具身智能活跃 FA → T3 杭州/浙江本地渠道 → T4 补充**

## 对接建议（结合《南烯公司出售与资产重组策略》第七节）

1. **先内部准备再对外**：BP + 资产包清单 + demo 素材没定稿前，先别大规模投递，避免"打草惊蛇"且信息不一致。
2. **不签独家**：先拿 BP 探 2-3 家反应，谁有产业方资源、谁愿接小体量用谁。
3. **首轮接触顺序**：易凯资本 → 义柏资本 → 高鹄资本（投 BP）→ 云岫资本 → 势能资本 → 一苇资本（补联系方式后）。
4. **兜底渠道**（头部 FA 嫌小体量时）：区招商投促部门、已投柔性传感/电子皮肤方向的 VC 引荐、行业活动个人 FA。
5. **投 BP 话术要点**：一句话讲清——"全柔性织物压力传感阵列，东华团队，自研软硬件+工程文档可转移，寻找产业方出售/战略合作，无对赌"，先问对方是否承接**卖方/并购**业务再深聊。
