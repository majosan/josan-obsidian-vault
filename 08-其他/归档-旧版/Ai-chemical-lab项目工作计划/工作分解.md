**LabVLA 本身并不依赖 Isaac Sim。** 模型推理是 WebSocket 协议，换仿真器只需要写一个 MuJoCo 客户端。真正依赖 Isaac Sim 的是**RoboGenesis（数据生成引擎，还没开源）** 和 **LabUtopia（评测环境，也是 Isaac Sim）**。

所以你的路线完全可行。下面是详细分解计划👇

这一步**完全不涉及仿真器**，就是先让模型能跑通接收输入→输出动作。

pip install flash_attn==2.8.3 --no-build-isolation

# 装 LabVLA 所有依赖
pip install -r requirements.txt
```

**第 2 步：下载模型**

Copy

```bash

pip install huggingface-hub

# 下载预训练模型（约 10GB）
huggingface-cli download zjunlp/LabVLA-5B-Base --local-dir LabVLA-5B-Base
```

**第 3 步：写一个伪造的客户端测试推理**

然后写一个 `test_client.py`，发送伪造的观测数据看服务端有没有动作输出返回。这个 Claude Code 可以帮你写。

原版 LabUtopia 场景 = Franka 机械臂 + 桌面 + 烧杯/试管等化学器具。

**你需要做一个 MuJoCo 版的：**

Copy

场景组件：

├── 试管 (细长圆柱)
└── 试剂瓶 (方体 + 小口径)
```

📝 **给 Claude Code 的提示词（阶段 2a — 场景搭建）：**

> 请帮我用 MuJoCo Python 绑定创建以下场景 XML 文件：
> 
> 1. 从 `mujoco_menagerie` 加载 Franka Emika Panda 机械臂的模型
> 2. 在桌面上放置：
>     - 一个烧杯（圆柱体，半透明材质，内径 40mm，高 80mm）
>     - 一个试剂瓶（box + 小 cylinder 瓶颈）
>     - 一个试管架（简单 box 结构 + 几个细圆柱试管）
> 3. 添加 3 个虚拟摄像头：
>     - camera_1：正上方俯视视角，分辨率 224x224
>     - camera_2：45度侧视角，分辨率 224x224
>     - camera_3：机械臂腕部视角，分辨率 224x224
> 4. 保存为 `scene_franka_lab.xml`
> 5. 写一个 `test_scene.py` 启动 Mujoco Viewer 确认场景加载正确

📝 **给 Claude Code 的提示词（阶段 2b — WebSocket 客户端）：**

> 基于阶段 1 完成的 LabVLA 推理服务，请写一个 MuJoCo WebSocket 客户端 `mujoco_client.py`：
> 
> 1. 加载阶段 2a 的 `scene_franka_lab.xml`
> 2. 每步执行：  
>     a. 从 MuJoCo 渲染 3 个摄像头图像 → 转为 uint8 (H, W, C)  
>     b. 读取机械臂关节位置（7个 joint）+ 夹爪状态 → 拼成 8-dim state

>     d. 接收 action 输出 → 写入 MuJoCo 的关节控制输入

> 3. 启动时接受一个 `--language_instruction` 参数
> 4. 循环运行直到用户按 Ctrl+C
> 
> 参考 LabVLA 的 `labsim_transforms.py` 中 LabUtopiaInputTransform 的数据格式

### 阶段 3：原子技能实现 + 数据生成（7-10天）

原版 RoboGenesis 定义了 11 种原子技能。你需要先在 MuJoCo 里实现 pick/pour/press 这 3 个核心技能。

📝 **给 Claude Code 的提示词（阶段 3a — 原子技能）：**

> 基于阶段 2 的 MuJoCo 场景，请为 Franka 机械臂实现以下原子技能：
> 
> 1. **pick(obj_name)** — 计算目标物体的抓取位姿 → 规划运动学路径 → 闭合夹爪 → 抬起
> 2. **pour(src_obj, dst_obj)** — 抓起源容器 → 移动到目标容器上方 → 旋转倾倒 45度 → 保持 1秒 → 回正 → 放下
> 3. **press(obj_name, force)** — 移动到目标上方 → 下降直到接触 → 施加指定力 → 抬起
> 
> 实现方式：用 MuJoCo 的正向/逆向运动学（mj_kinematics），不用 RL。  
> 为每个技能写一个演示脚本：
> 
> - `demo_pick.py`
> - `demo_pour.py`
> - `demo_press.py`  
>     输出每个技能的执行过程为 GIF/视频

📝 **给 Claude Code 的提示词（阶段 3b — LeRobot 格式数据导出）：**

> 基于原子技能，请实现数据导出管道：
> 
> 1. 运行每个原子技能，逐帧记录：
>     - 3路摄像头图像（作为 .mp4 视频文件或逐帧 PNG）
>     - 关节状态（7 joints + gripper）
>     - 动作（delta 格式：下一个状态 - 当前状态）
>     - 语言指令文本
> 2. 用 LeRobot 的 dataset 格式打包（参考 lerobot 的 `Dataset` 类）
> 3. 输出结构：
> 
> Copy
> 
> ```
> data/my_first_dataset/
> ├── meta/        # 统计数据
> ├── data/        # 实际帧数据（chunk 格式）
> └── README.md
> ```
> 
> 参考 LabVLA 的 `data_process` 命令和 LeRobot 的数据格式规范

## 关键架构图：接口协议

Copy

```
MuJoCo 场景 (你的代码)
┌──────────────────────────────────────────┐
│  mujoco_client.py                        │
│                                          │
│  Loop:                                   │
│    render 3 cameras → uint8 (H,W,C)     │
│    read joint pos + gripper → state[8]  │
│    send via WebSocket:                   │
│      {                                   │
│        "camera_1_rgb": ndarray,          │
│        "camera_2_rgb": ndarray,          │
│        "camera_3_rgb": ndarray,          │
│        "state": ndarray[8],              │
│        "prompt": "pick up beaker"        │
│      }                                   │
│    receive: {"action": ndarray[8,50]}    │
│    apply action → mj_step()             │
└────────────────┬─────────────────────────┘
                 │  WebSocket (msgpack)
                 ▼
┌──────────────────────────────────────────┐
│  serve_labvla.py  ⬅ 不 用 改             │
│  └─ LabVLA-5B-Base 模型推理              │
└──────────────────────────────────────────┘
```

**核心要点：** 你只需要写 `mujoco_client.py` + MuJoCo 场景，模型推理服务端原封不动。
