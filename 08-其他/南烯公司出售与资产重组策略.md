## 一、背景与目标

南烯公司已持续投入数千万元，核心资产为经编机及相关研发。经编机路线历经两次打样失败，目前最新样机尚未完成整机带载联调，预估成功概率很小。

**既定目标**：以南烯公司为主体，在10个月内形成可被产业方尽调、合作或收购的交易标的，优先回笼现金。织序科技公司承担技术赋能角色。

**关键要求**：
- 不接受带对赌的融资；
- 期望回笼金额越高越好，可以接受"只能回笼一些"的现实预期；
- 愿意在明确用途、目标和时间计划的条件下追加可控投入。

#### 2.2.4 并购案例

**例一：他山科技 —— 被"战略入股"，不是被收购**

**他山科技：触觉传感器公司（机器人触觉/电子皮肤方向）
柯力传感（603662，称重传感器龙头）**战略入股**（少数股权）；[融资信息](https://news.pedaily.cn/202511/557958.shtml)

**为什么是"入股"而不是"收购"**：

- 柯力的动机 = 从"称重传感器"这个成熟但天花板有限的品类，**切入"机器人触觉"这个极具未来方向新赛道卡位**；
- 主要还是用于技术更新迭代，以"芯片-传感器-算法-场景"全栈闭环能力，<font color="#00b050">推动触觉感知技术从实验室原型走向规模化商用落地</font>。
- 柯力用"**少数股权入股 + 未来优先权**"的方式，先占坑卡位技术升级。

**被入股时的状况**：他山科技技术有、方向对（机器人触觉），同时也能看出他山对产业公司要求对口。

**例二：禹山传感 —— 被"全资并购"**  

**禹山传感：水质传感器公司（溶解氧、pH、浊度等）。**
**买方**：同样是柯力传感。

**为什么这家能被"全资并购"**：
- 水质监测是**成熟赛道**，禹山**已经有成熟产品、稳定客户和真实营收**；
- 柯力并购它是为了**直接补上一个成熟品类**（水质/环境监测），不是"赌未来"，所以能直接全资买。
**被并购时的状况**：**有成熟产品 + 有营收 + 有客户**（从市场成熟度是高于他山科技的）。

**结论**：
   **南烯公司的出售价值短期不能建立在"产品商业化规模化"之上（但必须有可验证的 demo 与测试数据，作为技术资产的存在证明），而应建立在三根支柱之上：**
- **技术资产**：自研采集硬件、软件、数据链路及完整工程文档（原理图 / PCB / 代码 / BOM）——这是可转移、可尽调、真正能落价的资产；
- **方向（应用场景）卡位**：进入"全织物压阻阵列"这一已被尧乐、矩侨验证过的细分路线，至少具备被资本驱动的价值，但需要在技术专利上具备 IP 独立性以及场景验证性。
- **团队能力**：纺织工艺学术背景（东华大学）+ 工程落地能力，可随交易一并交付。

## 四、出售路径

### 路径一：战略买家（优先）
**卖点定位**：早期卡位 + 自研技术链路 + demo 能力，而非成熟产品。出售价值建立在"可转移的技术资产 + 已验证的细分路线卡位 + 团队工程落地能力"之上，而非产品商业化规模。

目标买家类型：
- 希望进入柔性传感赛道、但不愿从零研发的公司；
-  具有纺织/材料主业、希望向智能化延伸的传统企业；
-  明确场景痛点、愿意为"买时间"付费的产业方——买现成的采集链路 + 工程文档 + 团队，而非买营收。

注：我们的技术和场景，最好围绕买家去研发拓展，或按资源优先级来排列。
### 路径二：政府/国资背景项目
智能纺织、柔性电子、新材料均属国家支持方向。政策窗口期正在打开："并购六条"(2024.9) 出台后，2025 年新设并购基金 29 只、目标募集约 1050 亿元，数量同比增 70%、规模增 200%；上半年上市公司并购中国资央企占比超 60%；上海已设 100 亿集成电路 + 100 亿生物医药并购基金，深圳打造万亿级并购基金矩阵。

但需注意：地方国资并非"对技术成熟度要求相对宽松"，其真正诉求是**落地实体**（税收/就业/产线），抓手是"以投招商"把项目落进本地园区，而非收购纯技术资产包。零营收、无车规、demo 级的纯技术资产包，国资同样难以直接收购。

国资路径更适合作为"产业落地的配套补充"（以合资/项目落地/承接中试方式参与），而非主要出售对象。
### 实施方式
优先通过**并购型 FA** 接触战略买方，但需注意：主流 FA 多以股权融资为主业，真正承接"早期技术资产包出售"的并购型/卖方 FA 很少，需先筛选确认其是否愿意承接本项目体量。可重点关注明确覆盖并购重组业务的机构（如义柏资本、汉理资本、高鹄资本等）。

**实施路径优先级**：**产业方直连 ＞ 并购型 FA ＞ 券商并购部 ＞ 并购基金**。

## 五、资产包核心定位（推荐架构：一个主体、两条技术线、三层融合）

技术线 A/B 及各项专利、技术资产，最终统一打包并入 NX 主体名下；下文分开表述仅为厘清来源与操作路径。
### 5.1 一个交易主体（NX）+ 一个技术载体（ZX） 

**NX 公司（交易主体）负责：**

- 对外品牌和商务；
- 客户合同和 POC；
- 经编机、专利和功能织物相关资产；
- 最终股权出售、控股权转让或业务出售。

**ZX 科技公司（技术载体）负责：**
- 传感采集硬件；
- 软件、算法和数据系统；
- 合规重构后的传感 DEMO 产品闭环（根据调研反馈）；
- 研发交付。

**资产整合与交割条件**：交易前将 ZX 技术资产（传感采集硬件、软件/算法/数据系统、专利、工程文档）全部划转至 NX 主体名下，权属清晰、可转移、无遗留授权/质押/共有或职务发明争议，核心研发人员随交易绑定。此为交割前置条件。

**估值锚点**：NX 是交易主体（壳 + 历史投入背书），ZX 是价值载体（可转移技术资产）。估值只锚定在 ZX 传感资产的"可验证 demo"，经编资产成熟度低于传感资产，作为未来量产壁垒/衍生方向。

### 5.2 两条技术线并行（B 先行、与 A 解耦）

> 技术线 B（传感）不依赖经编机即可独立验证——传感层为纬编+刺绣工艺，与经编无工艺耦合。B 独立推进、A 并行验证但降级定位，两者互不等待。

#### 技术线 A（NX）：经编机与加热布

按工业要求逐级验收：
1. 完成设计和独立技术评审；
2. 明确剩余 BOM、预算、责任人和工期；
3. 完成整机装配；
4. 完成空载连续运行；
5. 织出普通基准织物；
6. 织造功能纱线；
7. 做出加热织物样品；
8. 完成三批重复生产；
9. 测算产能、良率、成本和故障率；
10. 完成第三方检测（最终复验，而非首次）。

> 若项目失败或不达标，则降级为"技术储备 / 未来量产壁垒的并行验证"，不作为出售卖点，仅作估值中的远期增值项。

#### 技术线 B（ZX）：合规传感产品

1. 将当前复制型 demo 降级为内部基准样品；
2. **选定一个终端应用场景/方向（建议优先确定）**，据此明确功能边界与 demo 交付目标；
3. **对竞品专利做 FTO 和规避分析（前置：未完成 FTO 前不得对外展示 demo）**；
4. 重新设计织物结构和走线，形成差异化 V2；
5. 固化硬件、PCB、BOM、软件和版本资料；
6. 建立内部测试协议；
7. 做出可交给客户测试的场景化 DEMO。

> 场景决策是 B 线的关键路径：场景不定，第 7 步场景化 demo 即为空转。需先瞄准一个场景点/方向，再据此构思功能、完成 demo，目标与交付才清晰。

### 5.3 三层融合路线

#### 第一层：系统级复合

```text
NX 的经编加热层
+
技术重构后压力传感层
+
ZX 的采集硬件与软件
=
压力感知 + 温度控制的功能织物系统
```

两个功能层通过层压、缝合、模块化安装等方式复合。**注意：传感层为纬编+刺绣工艺，非经编；本层为物理复合，非工艺一体化。**

#### 第二层：工艺协同，中期

让经编机生产：

- 织物基底；
- 导电电极层；
- 压敏结构；
- 加热层；
- 或适合后续刺绣、印刷、涂覆、复合的结构层。

传感能力通过其他成熟工艺加入。

#### 第三层：经编一体化传感加热，远期

研究多层经编、导电纱、压敏结构、阵列寻址和加热控制的一体化工艺。这可以成为未来专利和壁垒，但不能作为短期技术实现路径。

---

### 5.4 以 ZX 技术路径主导框架，NX 技术作为后期拓展衍生

**主角：大面积柔性织物压力传感系统**
- 多阵列点，大面积，纯柔性
- 自研采集硬件 + 软件 + 数据链路完整
- 实时压力分布热力图可视化

**叙事框架**：具身智能 + 柔性电子 + 大面积体表传感方向卡位（对应电子皮肤 2030 约 ¥90.5 亿、机器人价值量占比约 10% 的市场叙事）。

**触觉手套定位（附带）**：已完成两套样品与平面状态采集验证，穿戴动态采集列为后续研发方向——暂不夸大。

**后期**：NX 经编技术作为量产、高效、多样性的角色定位，作为拓展衍生方向讲述。


**红线**（作为未来可持续发展计划目标）：

- 不宣称"全链路自研"；
- 不宣称经编机已成功或具备量产能力；
- **未完成 FTO 前，不对外展示复制型 demo**（避免自曝侵权风险）；
- 关键传感材料最好包装成战略合作；
- 专利统一表述为"已申请未授权，价值待评估"。

## 六、风险提示

以下风险为出售过程中买方尽调、技术审查将重点追问的事项，逐项给出应对方案。**其中「织物结构工艺借鉴」「IP 权属与转移」两项为"重要项"。**

### 一、技术与产品风险

1. **织物结构工艺借鉴风险**：现有刺绣结构借鉴其他公司产品，FTO/侵权隐患是技术审查必问项。**应对**：FTO 与规避分析前置到任何对外接触之前；未完成 FTO 前不对外展示复制型 demo；以"差异化 V2 重构"替代"复制型基准样品"作为对外的技术形象。
    
2. **关键传感材料外采风险**：压敏纱线等核心材料外采，非全链路自研，买方会质疑技术壁垒与供应链可控性。**应对**：将"材料选型+供应商合规"纳入技术线 B 固化的 BOM 资料，证明供应链可追溯、可复制，甚至可以是战略合作。
    
3. **DEMO 产品差异性**：作为面向资本与市场的差异点，我们的场景落地具有差异性，并针对场景行业具备相应的标准测试报告。
    
4. **耐久性与温湿度未验证风险**：寿命、温湿度漂移、重复性均未测，直接影响买方对"可用性"的判断。**应对**：纳入技术线 B 测试协议（第 6 步），至少给出实验室级耐久/温湿度初步数据，或如实标注为待验证项。
    
5. **经编技术线未跑通风险**：经编机两次打样失败、尚未跑通，技术线 A 成熟度最低。**应对**：设阶段门：不过即停不追加投入；失败则降级为"技术储备/远期量产壁垒"，不进估值基数，不对外作为卖点。
    
6. **经编一体化传感加热短期不可实现风险**：经编工艺当前无法实现压力传感，"一体化"是愿景而非现实。**应对**：报告明确三层融合的 一体化仅作远期专利壁垒。
    

### 二、知识产权与权属风险

1. **IP 权属与转移风险**：NX 与 ZX 组合方式下，专利/软著/代码/工程文档的登记主体、转移链路尚未固化。**应对**：交易前完成资产整合，将 ZX 技术资产全部划转至 NX 主体名下并完成变更登记，作为交割前置条件；逐项确认无遗留授权、质押、共有或职务发明争议。

### 三、商业与市场风险

1. **成熟度不足风险**：零融资、无营收、无车规，成熟度远未达到"被并购"门槛，买方不会按成熟公司估值。**应对**：明确定位为"早期技术资产包/战略合作"，卖"可转移技术+卡位+团队"，而非卖成熟公司；估值锚定在可验证 demo。
    
2. **竞品占位风险**：尧乐已进入车规量产交付（理想/岚图/保时捷等定点），矩侨已有订单/定点（第 1000 套人形皮肤下线、20 万片车规产能），赛道已出现领先者。**应对**：以"差异化路线 + FTO 规避"切入细分场景（如康养床垫），避免与尧乐的车规、矩侨的机器人正面竞争。
    

### 四、交易结构与执行风险

1. **卖方并购 FA 稀缺风险**：主流 FA 以股权融资为主业，早期技术资产包交易金额小，头部机构缺乏承接动力。
    
2. **核心人员绑定风险**：买方买的可能是"技术+人"，若核心团队不能随交易走，技术资产价值大幅折损。**应对**：在交易条款中明确核心研发人员的聘用/顾问/竞业安排，作为交易前提条件。

## 七、行动计划

**核心原则**：先"内部准备"再"对外接触"；轻资产试探、不做无方向技术投入；产业方直连为主、并购型 FA 为辅；全程坚守"无对赌、现金/资产交易"底线。

### 阶段 0：内部准备（交易前动作）

**目标**：做出"可交割的资产包"和"可展示的 demo"，堵住尽调最可能卡的三个口（权属、FTO、量化指标）。

1. 资产整合：将 ZX 技术资产（传感采集硬件、软件/算法/数据、专利、工程文档）划转至 NX 主体，并完成交割流程；
2. FTO + 竞品专利规避分析；
3. 整理《技术资产包》四部分——技术资产、知识产权、合作背书、公司信息（BP）；
4. 固化技术线 B 的硬件/PCB/BOM/软件/版本资料；
5. 选定首个场景落点，做出可交付的场景化 demo；
6. 建立内部测试协议，给出量化指标（一致性、耐久/温湿度实验室级初测）；

**产出**：可交割技术资产包 + 一个可展示的场景化 demo + 一版口径统一的材料。

### 阶段 1：渠道建立与买方长名单

**目标**：建立"产业方直连 + 并购型 FA"两条触达通道，输出买方名单。

1. 买方名单建库并标注优先级；
2. 产业方直连（第一优先级）：产业人脉 或者上市公司战略投资部；
3. FA 筛选（多渠道）：已投相关方向的 VC 引荐、区招商投促部门、行业活动个人 FA，前置确认其是否承接本项目体量，重点看有无并购/卖方交易经验。

**产出**：买方名单（分优先级）+ 2-3 家可合作的并购型 FA。

### 阶段 2：接触与试探（NDA 前非正式 → NDA 后技术审查）

**目标**：筛选出真正有购买意图的买方，进入实质谈判。

1. 非正式接触：先探意向，不急于给材料，避免信息过早扩散；
2. 签署 NDA 后再披露核心信息（含关键材料外采等敏感项）；
3. 技术审查：demo 演示（FTO 完成后）+ 数据链路展示 + 团队背景。

**产出**：短名单（2-3 家有真实意向的买方）。

**决策门**：若无买方进入短名单 → 回到阶段 0 补强 demo/场景，不追加无方向投入。

### 阶段 3：谈判与交易结构设计

**目标**：形成可执行交易方案，锁定交易结构。

1. 交易结构选择：优先"技术资产包出售 / 战略合作"，次选"战略入股+后续收购"，回避对赌/业绩承诺；
2. 定价锚定：以可验证 demo 为锚；
3. 条款要点：无对赌、现金/资产交割、核心人员绑定与竞业、交割前置条件（资产整合完成）。

**产出**：可执行交易方案 + 交易条款草案。

### 阶段 4：交割与后续

**目标**：完成交割，落实团队绑定。

1. 完成交割前置条件（资产整合、权属变更、职务发明确认）；
2. 核心人员聘用/顾问/竞业安排落地；
3. 政府/国资路径作为"产业落地配套补充"并行推进（合资/项目落地/承接中试），而非主要出售对象。

**产出**：交割完成 + 后续合作安排。
