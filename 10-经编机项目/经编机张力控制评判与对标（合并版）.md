## 1. 评判的底层逻辑（心法）

**张力控制系统不是"目的"，是"手段"。**

它存在的唯一意义，是让**难做的纱线（短纤、弹性、导电纱等）在高速下稳定编织**。因此评判只有两条链，无法绕开：

| 情形 | 结论 |
|---|---|
| 供方**给不出设计参数** | **根本没有经过设计的张力控制系统** → 问题不是"牛不牛"，而是"**有没有**" |
| 供方**给得出参数** | 逐条对账 + 实测 → **达不到 = 设计失败** |

任何"有难度、有价值、东华老师、江南大学组团"的说法，都绕开上述两条链，属于**转移话题**。

## 2. 硬锚点：150 转，以及"转速上限 = 最短那块板"

### 2.1 合同唯一硬指标
- 合同/项目计划中**唯一明确可量化的是"目标转速 150"**；现状 **50 转 = 仅达标 1/3**，且**织不出约定的发热布**。
- **无论张力控制系统如何包装，供方已构成客观违约。** 所有讨论都应回锚到"150 转 + 发热布"。
- 附加发现：合同中**无发热布规格、无纱线参数** → 供方**从未定义验收需求**（本身即失职）。

### 2.2 转速上限 = 各环节的"木桶"（关键）
一台经编机的转速，受限于以下环节中**最慢的那一个**：

1. 主轴 / 针床 / 机构动力学（机械极限）
2. **电子横移 / 梳栉横移系统（幅度、速度、加速度、时序）** ←—— 极易被忽略的短板
3. 送经 / 张力控制
4. 牵拉卷取
5. 纱线本身（张力、断纱）
6. 花型 / 工艺复杂度

**因此：张力系统再"牛"，只要别的环节卡住，转速就上不去；反之，若横移/机械卡住，张力系统再好也无用。**

### 2.3 时序约束（为什么"横移"会卡转速）
- 转速 n（转/分）→ **每横列时间 T = 60 / n 秒**。
- 每个横列内，导纱梳栉必须完成"**加速—横移—减速—回位**"。若横移系统的最大加速度 a、最大行程 s 决定了最短耗时 t_min，则必须 **t_min ≤ T**。
- 例：n=50 → T=1.2 s；n=150 → T=0.4 s；n=2500 → **T≈24 ms**。转速越高，留给横移的时间越短 → 横移系统的"速度/加速度/幅度"上限，直接决定转速上限。

### 2.4 由此得到的"两头堵"问法
- 若张力系统**不是**短板 → 它对"只跑 50 转"没有贡献 → **所谓牛技术在本项目中等于没用**；
- 若张力系统**就是**短板 → 说明该系统**本身没做好**；
- **必做**：要求供方**明确 50 转的限制来自哪一环节，并逐一举证其他环节不受限**。

## 附 3：什么是"张力控制数学模型"？（说明 + 判真伪标尺）

### 一句话定义
"张力控制的数学模型" = **把"张力"这个被控量，与"可操作量"（电机转速/扭矩、盘头半径、送经量、车速）之间的定量关系，用方程表达。** 控制系统要解决的就是：**为了让张力等于目标值，应给电机什么指令**；这套关系式即"模型"。

### 一套真正的经编机张力控制系统，至少应包含以下几组方程

**① 盘头半径变化模型（几何）**
`r = √( r₀² − L·h / (π·b) )`（r₀ 初始半径、L 已退绕长度、h 纱层厚、b 幅宽）
→ 即"盘头直径补偿"。同一送经量，盘头大时电机慢转、小时快转，不补偿张力就漂。

**② 经轴动力学 / 力矩平衡（力学）——核心**
`J · (dω/dt) = M_电机 − T · r − M_摩擦`
→ 电机力矩：一部分拉纱（张力 T × 半径 r = 力矩），一部分克服惯性与摩擦；转动惯量 J 还随剩余纱量变。
**最能看出真假**：没有它，就无法说明张力是如何被"产生"的。

**③ 纱线张力—应变关系（材料）**
弹性纱：`T = E · A · ε`（E 弹性模量、A 截面积、ε 应变）
短纤/弹性纱还须含**蠕变、松弛**（粘弹性：张力随时间和拉伸历史变化）。
→ **短纤纱难控的根子即在此，也正是供方吹的"针对短纤的独特性"必须落笔之处。拿不出这组 = 等于承认没针对短纤做设计。**

**④ 纱路摩擦（几何 + 摩擦）**
欧拉公式：`T₂ = T₁ · e^(μθ)`（μ 摩擦系数、θ 包角）
→ 纱经过导纱器/张力杆后张力会变，不建模则控不准。

**⑤ 控制律（控制系统本身）**
反馈 PID：`u = Kp·e + Ki·∫e dt + Kd·(de/dt)`，其中 `e = T目标 − T实测`
前馈：`u_ff = f(车速 v, 半径 r, …)`
合成：`u = u_ff + u_fb`

### 判真伪标尺

| 真的做过研发 | 糊弄 / 外包通用模块 |
|---|---|
| 能给 ②③⑤ 的公式（哪怕简化），说得出控制周期、Kp/Ki/Kd、前馈函数、半径补偿算法 | 只会说"用了伺服闭环""PLC 控制""行业领先算法"——**一个方程都拿不出** |
| 能说清 **短纤纱**在模型里怎么特殊处理 | 用"商业机密/核心技术"搪塞，或"专家看了就懂" |

**关键判据**：他们卖的是一套"针对短纤的定制系统"。既然是定制，**定制只能体现在模型里**（短纤的蠕变/摩擦如何补偿）。**模型说不出 = 没有定制 = 就是普通通用系统。**

> 公道话：通用工业系统确实常把算法当黑盒、不公开增益。但**普通系统不需要花大钱自研**，直接买即可。既然收了自研的钱、又声称独特，就**必须能讲出自己的模型**——此逻辑闭环，无法绕开。

## 附 4：张力控制系统工作原理要点（评判用）

> 白话逐条解释见《参数白话版（README）》"2.5 技术常识 Q&A"（Q1–Q15）。

### 1. 结构：4 层闭环
```
第0层 节拍/同步：主轴编码器 → 一圈 = 一横列
第1层 前馈(基准)：按"送经量/横列"× 主轴比例 → 基准转速
第2层 直径补偿：实时算盘头半径 r → 修正转速 ω=v/r
第3层 张力反馈：张力传感器 → 微调送经量（小修正）
第4层 电机闭环：编码器反馈 → 保真执行
```
每层在**同一个控制周期**内运行一遍 → 构成闭环。

### 2. 快慢分工（三层各管各的，互不打架）
| 变化快慢 | 谁负责 | 性质 |
|---|---|---|
| 圈内微观脉动（凸轮引起） | 纱线弹性 + 缓冲装置 | **被动吸收** |
| 宏观/圈间（随主轴、按花型） | 前馈 | 主动前馈 |
| 慢变漂移（直径/纱性能/温湿度） | **张力传感器反馈** | 主动反馈 |

### 3. 前馈 + 反馈
前馈保证大方向对、不滞后；反馈纠小偏差。**只靠反馈 → 提速滞后 → 波动大。**

### 4. 相位同步
一圈 = 一横列 = 一次成圈（纱被大量拉走集中在**某一相位窗口**；多把梳栉只是垫纱有先后）。相位同步 = 让送纱卡在该窗口。**转速越高窗口越短，越难对。**

### 5. 直径补偿
**电子推算**（数圈数 + 纱层厚，现代主流）或 **机械跟随臂**（滚轮贴盘头表面测直径，改造系统常见）。

### 6. 送经量测量
`纱长 = 盘头转角 × 盘头半径`：靠**编码器**数转角 + **直径补偿**算半径。

### 7. 多轴同步与解耦
- **同步**：主轴总基准 + 电子齿轮/凸轮 + 实时总线分布式时钟（微秒级）+ 前馈；
- **解耦**：每轴独立伺服闭环 + 扰动观测器/前馈补偿 + **分层控制**（送经量在前、张力微调在后）；
- **验收**：单轴扰动，观测其他轴波动（**耦合度测试**）。

### 8. 由此新增的"打点"
- 圈内脉动应靠**缓冲/弹性吸收**——若对方把一切都推给"传感器反馈"，即不专业；
- 盘头转速变化主要在**"随主轴"与"圈间（EBC 多速送经）"**两个层面，**不是圈内跟凸轮波形**（若对方这么讲，需追问）。
