## 0. 先守住 3 条铁律（其余都可以忘）

1. **一切要"数字"，不要形容词。** 对方说"很先进""行业领先""专家看了就懂"→ 你就问："**具体数值是多少？**"
2. **关键三问**（反复用）：
   - "你们这套，**比卡尔迈耶成熟方案强在哪**？"
   - "**50 转到底卡在哪一环**？"
   - "**拿短纤纱，替我把发热布织出来。**"
3. **拿不出参数 = 没做这套系统。**（不是"牛不牛"，是"有没有"）

## 0.1 万能三连问（对任何参数都适用）

1. **"这个数是多少？"**（要具体值）
2. **"行业正常值是多少？"**（逼他说标准，好做对比）
3. **"你怎么证明？"**（要数据 / 曲线 / 实测）

## 1. 逐条白话解释（按文档 A–G 顺序）

### A. 需求与输入定义

| 参数 | 大白话 | 为什么重要 | 好答案 / 危险信号 |
|---|---|---|---|
| 目标车速 (rpm) | 机器每分钟打多少"行"布，越快产量越高 | 这是合同唯一硬指标 | 好：明确 ≥150。⚠️ 只跑 50 = 违约 |
| 发热布规格 | 布要多重、多宽、什么结构、每英寸多少针（机号 E） | 不写清就无法验收"织出来没有" | ⚠️ 根本没写 = 没定义需求 = 失职 |
| 纱线规格 | 纱的粗细(纤度)、结实度(强度)、能拉多长(伸长)、短纤长度 | 决定好不好织、张力怎么控 | ⚠️ 一个参数不给 = 无法验证 |
| 张力目标与允差 | 纱该被拉多紧、允许多大误差 | 张力的"目标值" | ⚠️ 没有目标值 = 没法判断控得准不准 |

### B. 感知 / 检测层（机器的"眼睛"）

| 参数 | 大白话 | 为什么重要 | 好答案 / 危险信号 |
|---|---|---|---|
| 张力传感器 | 测纱线拉力的"秤" | 没它=闭眼开车，控不准 | 好：说得出型号/精度。⚠️ 答不出=没测 |
| 量程 / 精度 / 分辨率 | 能测多大范围 / 准不准 / 最小能分辨多少 | 决定测得多细 | 具体数值 |
| **采样频率** | 每秒测几次 | 测太慢就跟不上、控不准 | ⚠️ "不知道"= 基本没认真做 |
| 送经量 / 编码器 | 测"每次放多少纱""盘头转了多少" | 送经精度靠它 | 好：给分辨率 |
| 主轴相位同步 | 让送经跟主机"对表"，每次打针时纱量刚好 | 不同步就忽松忽紧 | 标准做法，应对答如流 |

### C. 驱动 / 执行层（机器的"手"）

| 参数 | 大白话 | 为什么重要 | 好答案 / 危险信号 |
|---|---|---|---|
| 送经电机 | 转盘头、放纱的电机 | 伺服=精确控制；变频=只粗调 | 好：明确是伺服。⚠️ 只敢说"电机" |
| 控制通道数 | 能**独立控几个**盘头 | 独立控得越多越精细 | 具体数量 |
| 功率 / 扭矩 / 惯量 | 力气多大 / 大不大 / 加减速快慢 | 决定能不能快速响应 | 具体数值 |
| 响应时间 | 从"发命令"到"动起来"多久 | 越快控得越准 | ⚠️ 答不出 = 没测过 |

### D. 控制算法层（机器的"大脑"）

| 参数 | 大白话 | 为什么重要 | 好答案 / 危险信号 |
|---|---|---|---|
| 控制策略 | 怎么算、怎么调：开环(只管发令)/闭环(边测边纠,好)/前馈(提前预判) | 决定控制水平 | 好：说得出闭环+前馈 |
| 控制 / 采样周期 | 大脑多久算一次 | 太快太慢都不行 | 具体 ms 值 |
| 环路带宽 | 反应速度的"范围"，越高越能应付快变化 | 决定高速下控不控得住 | ⚠️ 答不出 |
| **数学模型** | 见下面"附：模型白话"——把张力和电机指令的关系写成方程 | 定制的唯一体现处 | 好：给公式。⚠️ 只会形容=没做 |
| 多轴同步 / 解耦 | 多个盘头别互相打架、协同一致 | 多盘头机型的难点 | 好：说得出算法 |

### E. 电子横移 / 梳栉横移（梳栉的"左右移动"）——决定转速上限

| 参数 | 大白话 | 为什么重要 | 好答案 / 危险信号 |
|---|---|---|---|
| 电子横移 (EL) | 让导纱梳栉在针之间**左右移动**来绕线成花；以前靠机械花盘，现在靠电机 | 是 "转速" 的另一大瓶颈 | 好：电子横移 |
| **最大横移幅度 (shog)** | 一次最多能移多少针 | 花型复杂就得移得多 | 好：说得出针数。参考：Karl Mayer 四把地梳 2-inch shog |
| **横移速度 / 加速度** | 移得多快 | **转速越快，留给横移的时间越短**；移不够快，转速就上不去 | ⚠️ 答不出 = 卡转速的真凶可能在这 |
| 定位精度 | 移得准不准（差一针就织错） | 决定花型对不对 | 具体值 |
| 花型循环长度 | 一个完整花型多长、多久重复 | 影响能不能做复杂花型 | 具体值 |

> **关键逻辑**：转速越快，每一"行"的时间越短（150 转时每行仅 0.4 秒）。横移必须在这么短时间内移完并回位。**移不快 → 转速再高也没用。**

### F. 性能 / 验收指标（可验证的"成绩单"）

| 参数 | 大白话 | 为什么重要 | 好答案 / 危险信号 |
|---|---|---|---|
| 最高稳定转速 | 能稳定跑多快不坏事 | 直接对标合同 | 好：≥150。实测 50 = 不合格 |
| 稳态张力精度 | 张力控得准不准(±%) | 决定布的质量稳不稳 | 具体 % |
| 动态响应时间 | 张力乱了以后多快拉回来(ms) | 提速时最考验这个 | 具体 ms |
| 全幅张力 CV% | 整幅几百根纱，张力整齐不整齐（CV 越小越齐） | 决定布面均匀度 | 具体 % |
| 断纱率 | 织的时候断多少纱 | 直接关系能不能量产 | 实测数据 |

### G. 限速归因（最关键的一问）

| 项 | 大白话 |
|---|---|
| 50 转卡在哪一环 | 机器像"木桶"，转速由**最慢的那块板**决定：主轴机械 / 电子横移 / 送经张力 / 牵拉卷取 / 纱线 / 花型。**让供方明确指出是哪一环，并证明其他环节都不卡。** |

## 附：数学模型白话（对上"附 3"）

> 一句话：**把"张力"和"该给电机什么指令"之间的关系，写成方程。**
> - 打个比方：开车要"看车速→决定踩多少油门"，这里面"车速↔油门"的关系就是模型。
> - 张力控制要"看张力→决定电机转多快/多大劲"，被写下来的那套算式就是模型。
> - **定制的价值只能体现在这里**：短纤纱的"蠕变、摩擦"怎么补进模型。**模型说不出 = 没定制 = 就是普通通用系统。**

## 2.5 技术常识 Q&A（你问过的，随翻随用）

### Q1 盘头直径补偿是谁在做？
**动作由送经电机做，指令由送经系统（控制器）发。**
盘头越放越细，为保持每横列送出同样长度的纱，转速必须越来越快：`角速度 ω = 线速度 v ÷ 半径 r`。控制器实时算出盘头半径 r，再算出该给电机多快 → 这就是"直径补偿"。
两种实现：**电子推算**（数圈数+纱层厚，现代主流）或**机械跟随臂**（滚轮贴盘头表面测直径，改造系统常见）。

### Q2 是靠盘头"正转/反转"来控制吗？
**不是。** 正常织造时盘头只朝一个方向（退绕方向）转，控制量是**转速快慢**，且连续实时调整。
张力不是靠正反转调的，而是靠"送多送少"：送多了纱松（张力小），送少了纱紧（张力大）→ **用转速调张力**。
反向只在少数场合用（弹性纱回缩、重新张紧、穿纱回纱），属附加功能。
⚠️ 若对方说"靠电机正反转控制张力"——这句本身就不专业，可追问。

### Q3 张力传感器的数据去哪了？
**传给送经系统，形成闭环**：
张力传感器测 T 实测 → 控制器比较目标 T（误差 e = T目标 − T实测）→ 决定盘头该快还是该慢 → 送经量变 → 张力变 → 再测……如此循环。
方向：张力太大(纱紧)→送经加快(多放纱)→张力降；张力太小(纱松)→送经减慢(少放纱)→张力升。

### Q4 那怎么判断"是不是真的张力控制系统"？🔪
**杀手追问**：**"张力传感器的数据，是参与控制，还是只显示/报警？"**
- 只显示/报警 → 不是张力闭环 → **"张力控制系统"名不副实**；
- 参与控制 → 让他画控制框图、说采样周期、给张力实测曲线。
只有"张力反馈真正参与控制"，才配叫张力控制系统。

### Q5 送经量准不准靠什么？
靠**编码器**：`送出的纱长 = 盘头转过的角度 × 盘头半径`。
- **主轴编码器**：当节拍器，主轴转一圈=织一横列，告诉系统"该送纱了"；
- **盘头/电机编码器**：数实际转了多少，换算成送了多少纱。
编码器=跟轴转、每转一点"咔哒"发一个脉冲的传感器，系统**数脉冲**即知转量。**线数(PPR)**越高越准（如 2500 线）。
例：半径 200 mm、2500 线 → 每脉冲 ≈ 0.5 mm 纱。
**送经精度由三样决定**：编码器分辨率 + 直径补偿 + 电机闭环。
🔪 可问："你们的送经量靠什么测、精度多少？编码器多少线？"

### Q6 "送经量精度"和"张力精度"是一回事吗？
**不是。**
- **送经量精度** = 送出的纱**长度**准不准（几何量） —— 编码器+直径补偿+电机；
- **张力精度** = 纱被拉得**紧不紧**（力） —— 张力传感器+送经闭环。
两者分开问、分开验，不能互相替代。

### Q7 什么是"主轴相位同步"？
主轴每转一圈 = 织一个横列。这一圈里，针经历"退圈→垫纱→弯纱成圈→牵拉"，**纱主要在"弯纱/成圈"那一下被大量拉走**，并非整圈匀速消耗。**"相位"= 主轴转到这一圈的哪个角度/动作点。**
**主轴相位同步** = 让送经的动作与主轴的角度位置绑定——**走到哪一拍，就送多少纱**。主轴上装编码器实时报相位，送经据此在正确时刻送出正确量。
- 比喻：主轴 = 指挥/节拍器，送经 = 乐手，必须跟着拍子走。
- 不同步的后果：纱忽松忽紧、张力波动、断纱、布面不匀、提速送经量漂移。
- ⚠️ 转速越高，一个横列时间越短（150 转 → 0.4 秒），相位越难对 → 50 转谈"控制系统牛"站不住。
- 🔪 可问：主轴编码器多少线？相位同步精度多少？提速时送经量能否保持（速度—送经量曲线）？

### Q8 "控制 / 采样周期"是什么意思？
控制器**循环工作**：读传感器（张力/编码器）→ 计算 → 输出指令给电机。相邻两次之间的时间 = 控制/采样周期。
- **采样周期**：多久读一次数据；**控制周期**：多久算一次、更新输出（通常相同）。
- 为什么重要：闭环要**转得比"干扰变化"快得多**才控得住。周期太大 → 反应滞后 → 张力忽上忽下、**一提速就失控**。
- 比喻：开车看路的间隔，**看得越勤反应越快**；老闭眼（周期长）就追尾。
- 典型：现代伺服环路常在**毫秒级甚至更快**；张力外环约**几毫秒~十几毫秒**（因系统而异）。要"环路带宽"高，采样就必须快。
- 🔪 可问：控制周期/采样频率是多少？

### Q9 "多轴同步 / 解耦"是什么意思？
一台机常有**多个盘头**，每个配一个电机（= 一个"轴"），送不同的纱。
- **多轴同步**：这些轴都跟主轴走**同一个节拍**，各自送出各自该送的量，**步调一致**。
- **解耦**：每个盘头的张力控制**不能互相干扰**。因为它们**共用同一幅纱、同一排针**，一个盘头动会牵连旁边的纱；控制没做解耦，几个回路就会**互相较劲**，越调越乱。
- 比喻：几个人一起抬一块板走路——**要步调一致(同步)，又不能互相较劲**（你使劲我也使劲，板子就晃）。
- 不做解耦的后果：调一个盘头别的跟着震荡、张力不稳、布面不匀、多盘头/复杂花型做不了。
- 🔪 可问：多个盘头怎么同步？张力解耦用什么方法？

### Q10 "多盘头怎么同步、张力解耦用什么方法？"（好答案长什么样）
**多盘头同步 = 统一节拍 + 电子齿轮 + 实时总线：**
- 主轴编码器做**总基准**（所有盘头以主轴为总节拍）；
- **电子齿轮/电子凸轮**：每盘头按各自**比例**跟主轴转（送经量不同，比例不同）；
- **实时总线 + 分布式时钟**（如 EtherCAT / CANopen），各轴时钟对齐到**微秒级**、同步更新；
- **前馈**：主轴动作提前告诉盘头，让其不滞后。
**张力解耦 = 独立闭环 + 算法补偿 + 分层控制：**
- **每盘头独立伺服闭环**（地基，各管各的）；
- **扰动观测器 (DOB)**：把"别的盘头传来的干扰"估计并抵消；
- **前馈 / 交叉耦合补偿**：已知相互影响提前补；
- **分层控制（关键）**：上层管**送经量**（同步、确定），下层才用**张力微调** → 回路不抢，自然解耦。
**好答案 vs 糊弄：** 真做过 → 说得出电子齿轮/实时总线/扰动观测器/分层控制，并给**耦合度测试数据**；糊弄 → 只说"先进算法""伺服很精确""它们本来就不影响"。
🔬 **验收实验**：运转中故意改动一个盘头的张力/负载，记录其他盘头波动——几乎不动=解耦好；跟着震荡=没做。
🔪 可问：多盘头怎么同步（电子齿轮/凸轮？总线时钟对齐多少）？张力解耦用什么方法？能否做一次耦合度测试？

### Q11 为什么需要多个盘头？电子横移是不是一把对应一个盘头？
**为什么多个盘头**：一个盘头 = 一组"材质相同、送经量相同"的纱。需要几组不同纱（或纱太多一个盘头装不下）就上几个盘头。
- 不同梳栉用不同纱（如弹力布：锦纶地纱一盘头 + **氨纶**一盘头）；
- 不同纱要独立送经（弹力纱必须单独控张力/送经量）；
- 容量/幅宽限制（一个盘头能绕的纱根数有限 → 分段经轴）；
- 换纱/管理方便、模块化。
→ 你们要送不同纱（尤其短纤/弹性），**多盘头是必然**，这也正是"多轴同步/解耦"的由来。

**电子横移 vs 盘头：不是一回事！**
- **电子横移**控制的是**梳栉**（带导纱针的横杆）：左右移动，把纱垫到不同针上 → **决定花型**；
- **送经系统**控制的是**盘头**：放纱，控制送多少、多快。
- 对应关系：**梳栉 ⇄ 电子横移轴**；**盘头 ⇄ 送经轴**。两者数量**相互独立，不一一对应**。
- 纱路：**盘头(存纱) → 经纱 → 导纱针(装在梳栉上) → 织针**（送经管"供"，横移管"垫"）。
- 一个盘头可**供多把梳栉**（同样纱同样送经量时共用）；一把梳栉的纱也可来自**多个盘头**（分段）。
- 例：4 梳经编机 = 4 把地梳(≈4 个电子横移轴)，但可能只用 2 个盘头。
🔪 可问："几把梳栉、几把是电子横移？几个盘头、几个送经轴？"（分开问，看答不答得清）

### Q12 电子横移用的纱（如导电纱）不是整经在盘头上的吗？
**是的，纱确实整经在盘头上**——但要说清"纱路"和"控制职能"两件事：
- **纱路（同一条纱）**：整经(绕到盘头) → **盘头(存纱)** → 经纱 → **穿进梳栉上的导纱针** → 织针。
- **送经(盘头)** 管"发多少、多快"；**电子横移(梳栉)** 管"垫到哪、成什么花"。同一根纱，既"由盘头供"，又"由梳栉垫"。
- **"电子横移"本身不占用纱**，它只是移动梳栉的机构；纱始终属于"盘头 + 穿过的那把梳栉"。
- **数量对应看"纱的种类和数量"**，不是"梳栉 1:1 对盘头"：一种纱可能=一个/一组盘头 + 某把梳栉；纱太多可分段整经(多个盘头供一把梳栉)；同纱同送经量的两把梳栉可共用一个盘头。
🔪 可问："导电纱整几个盘头？穿几把梳栉？其中几把是电子横移？"

### Q13 把整套逻辑串起来（4 层闭环）
**一句话自述**：主轴转一圈→算出各盘头该放多少纱；盘头越细→实时修正转速（直径补偿）；纱在成圈那一相位被拉走→要卡点送纱（相位同步）；张力变化→张力环微调；放线准不准→靠送经量+编码器；最终靠算法按小周期做闭环校准。
**整理成 4 层闭环**：
```
第0层  节拍/同步 ：主轴编码器 → 一圈 = 一横列
第1层  前馈(基准) ：按"送经量/横列"× 主轴比例 → 算出基准转速
第2层  直径补偿  ：实时算盘头半径 r → 修正转速 (ω = v / r)
第3层  张力闭环  ：张力传感器 → 微调送经量（只做小修正）
第4层  电机闭环  ：编码器反馈 → 保证电机真的按指令转
        └── 每层都在"控制周期"内跑一遍 —— 这就是闭环
```
- ⚠️ 修正一个易错点：**一圈 = 一个横列 = 一次成圈**，成圈(纱被大量拉走)集中在**某一个相位窗口**，不是"几个位置"；多把梳栉只是**垫纱有先后**。
- **为什么"前馈 + 反馈"**：前馈保证大方向对、不滞后；反馈负责纠小偏差。只靠反馈，提速就滞后→波动大。这也呼应 Q10 的分层控制/解耦。
- 🔪 可问：送经量怎么设定/标定？前馈和反馈怎么分工？控制周期多大？

### Q14 凸轮/加速度让纱忽紧忽松，是要靠"计算"告诉盘头转速变化吗？
**对的部分**：针的运动由**凸轮/曲柄**驱动；轮廓凹凸=加速度在变 → 一圈内**纱需求速率波动**，**成圈(弯纱)时被大量拉走**、其它时候回松。**张力在一圈内有轻微脉动是正常的。**
**要修正的**：**常规送经不在"一圈内"跟凸轮波形忽快忽慢。** 积极式送经是"每横列送固定长度"，盘头按**平均速率**（∝主轴转速）连续转；圈内波动主要靠**纱线弹性 + 张力杆/缓冲**吸收。
- 比喻：不是让水龙头"一秒快一秒慢"对嘴，而是**开稳定水流，靠杯子(缓冲)接住小波浪**。
**"变化"发生的两个层面**：
| 层面 | 是否变化 | 谁负责 |
|---|---|---|
| 宏观(随主轴) | 主轴快→盘头按比例快 | 前馈同步 |
| 圈间(横列间) | EBC"多速送经"可按花型对不同横列送不同量 | 可编程送经 |
| 圈内(一横列内) | **常规不跟凸轮波形**，靠弹性/缓冲吸收 | 纱线弹性+张力缓冲 |
**凸轮轮廓的重要**：决定一圈内**峰值需求速率**与**张力峰值**；转速越高(时间被压缩)→峰值更高、越易断纱 → "高速难"的根源之一。
🔪 若对方说"靠一圈内跟随凸轮轮廓调转速"——不常规，可追问："是圈内波形跟随，还是靠弹性/缓冲吸收？多速送经支持几速？"

### Q15 圈内变化是不是靠张力传感器反馈纠？还是"平均算好+弹性吸收"？
**对的一半**：凸轮圈内的忽快忽慢**不反馈给盘头**，送经量按"**每横列平均长度**"算（前馈基准），盘头按平均值连续转。
**要修正的一半**：圈内波动**不是靠张力传感器反馈纠**的——盘头**惯量大来不及**在一圈内忽快忽慢，控制环**带宽有限**也不该管这么快的东西。圈内波动靠**纱线弹性 + 缓冲装置(张力杆/弹簧)被动吸收**。
**快慢分工表**：
| 变化快慢 | 谁负责 | 性质 |
|---|---|---|
| 圈内微观脉动(凸轮引起) | 纱线弹性 + 缓冲装置 | **被动吸收** |
| 宏观/圈间(随主轴、按花型) | 前馈(送经量 ∝ 主轴) | 主动前馈 |
| 慢变漂移(直径/纱性能/温湿度) | **张力传感器反馈**→微调平均送经量 | 主动反馈 |
| 电机执行 | 编码器闭环 | 保真执行 |
**一句话**：大动作靠"算"(前馈)；圈内小波动靠"弹性/缓冲"吃掉；慢偏差才靠"张力反馈"纠。
🔪 可问："圈内脉动靠什么吸收？张力环带宽/控制周期多少？"（答不出"缓冲吸收"、啥都推给传感器反馈=不专业）
