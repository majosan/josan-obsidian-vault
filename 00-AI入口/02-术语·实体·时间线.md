## 三、技术与学术术语

| 术语 | 一句话解释 |
|---|---|
| **VLA** | Vision-Language-Action 模型：看图+听懂指令→出动作。项目主参考 = **LabVLA** |
| **LabVLA** | 浙大+上海 AI Lab 的科学实验室 VLA，全开源（`github.com/zjunlp/LabVLA`）；模型本体 LabVLA-5B（**50 亿参数**，非 5 亿） |
| **Qwen3-VL-4B** | LabVLA-5B **内部的**视觉语言「大脑」部件，不是框架 |
| **T-Rex** | 触觉响应灵巧操作论文；MoT 架构 + 触觉编码，频率解耦 |
| **RoboGenesis** | 仿真数据引擎（不是模型），11 种原子技能（⚠️ 曾为空壳仓库） |
| **MuJoCo / MJX** | 物理仿真引擎（MJX = GPU 批量版）；**只做验证，不参与训练** |
| **Genesis** | 备选仿真引擎（流体/变形原生，2027 再评估） |
| **VQ-VAE** | 向量量化自编码器（时间维压缩）；配 CNN（空间维）双通道编码 |
| **Diffusion Policy** | 扩散策略（当前「小脑」方案，BC+RL 三阶段训练） |
| **12×12×3 编码** | 触觉编码定稿：12×12 网格 × 3 通道（压力/变化率/振动） |
| **分层架构** | 大脑(LLM) + 小脑(Specialist) + 脊髓(经典控制)，2026-07-24 取代端到端 VLA |
| **原子技能** | 抓取/倾倒/插入等基本动作，对应实验室 8 种操作 |
| **物理 AI / 世界模型** | 具身智能方向；项目判断「物理协同场景更适合世界模型而非纯 LLM」 |
| **DRIFTS** | 原位红外漫反射光谱，催化研究「金标准」设备；选为自动化小切口场景 |
| **正交交叉结构** | 横/纵导电层交叉成传感点（矩侨/尧乐结构）；专利风险核心 |
| **单层一体织** | **我方最大技术差异化**：一体织造成型（vs 多层缝制/粘合分层） |
| **CNT 纱** | 碳纳米管发热纱（加热眼罩用，ρ=40Ω/cm） |
| **NTC** | 负温度系数热敏电阻（测温/控温） |
| **FPC** | 柔性印刷电路板（手套 IO 引出用） |
| **9-DOF IMU** | 九轴惯性测量单元（加速度+陀螺仪+磁力计） |
| **RealSense D435** | Intel 深度相机（毫米级实测深度） |
| **ESP32-C2-MINI-1** | 养老床垫选用的 WiFi 模组 |
