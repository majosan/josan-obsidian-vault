## 六、红线与坑（务必记住）

1. **`josan-vault` 仓库禁止 `git add -A`** —— 曾误提交 277MB 展会原图（已修正）。大体积原始素材不入库。
2. **只 push「整理后的正式资料」**（策略/报告/方案/学习心得）；**每日会话记录、过程性草稿不进 git**（留在服务器 `memory/` 和 `projects/*/sessions/`）。
3. **正式文档命名不用日期**，用有意义的标题。
4. **两份 git 别搞混**：Josan 实际 pull 的是 `josan-vault/`（main 分支，SSH 别名 `github.com-obsidian-server`）；工作区根目录 `~/.openclaw/workspace` **已不是 git 仓库**（旧 clone 已删）。
5. **对外不编造** —— 买方是懂行的产业方；虚报=欺诈，且与「无对赌」底线冲突。
