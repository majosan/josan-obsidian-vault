## 🧤 01 / 02 · 技术底座：全柔性织物压力传感 + 触觉手套

> 目录：[[02-触觉传感器/项目概述|02-触觉传感器]]（目录 01 为 AI 化学实验室，底座文档主要在 02）

### 定位
杭州织序科技（ZX）自研的**全柔性织物电阻式压力传感阵列**——公司所有产品的「底座零件」，也是专利和出售资产的核心。

### 我们做了什么
- **传感器结构**：三层织物 —— 镀银纱线横电极 + 压敏纱线（尼龙+碳黑）+ 镀银纱线纵电极，刺绣锯齿形走线，正交交叉点成传感单元。
- **两个阵列 SKU**：SKU-1 500×500mm（齿高 3mm→3×3mm 点，13mm 等距，有效区 403×403mm）；SKU-2 1400×700mm（齿高 4mm→4×4mm 点，行 35mm/列 17mm 矩形网格）。
- **电学**：12-bit ADC → 0–255，15Hz 帧率，串口转 USB（一线供电+通讯），JSON 输出，最小可检测压力约 5g。
- **子项目：触觉手套（tactile-glove）** —— 传感器的一种产品形态：全柔性织物触觉采集手套，**共 124 个传感点**（5 指×3 关节×2×2 = 60 + 掌心 8×8 = 64），IO 全引到手腕经 FPC 连接采集板。**两套样品已缝制完成**，握物压力可检测。
- **软件**：124 点可视化页面（索引映射）、串口数据采集、前后端联动、JSON 导出 —— 已全部跑通。
- **完整验收测试体系**：4 轮测试方案 + Claude Code 数据分析脚本提示词。

### 当前状态
样品级。握物可测；**跨点一致性差（柔性织物固有问题，已接受逐点校准）**；均匀性/耐久性/温湿度待测。

### 关键事实
- **核心优势**：全织物透气可折叠、低串扰、3–4mm 微小传感点、**单层一体织工艺（最大差异化）**。
- **已知短板**：均匀性差（三层封装导致）、跨点一致性差。
- **首发场景**：医疗养老 + 智能床垫；**愿景**：机器人电子皮肤。
- **竞品**：直接竞品 = 威海矩侨工业、上海尧乐科技；间接 = 福莱新材、帕西尼感知；已量产 = 华威科、晶智感新材。
- **市场**：全球电子皮肤市场 2024 约 $63 亿 → 2034 超 $300 亿（17%+ CAGR）；人形机器人电子皮肤 2030 约 ¥90.5 亿。

## 🧪 01 + 04 · 技术主战场：AI 化学实验室（ai-chem-lab）

> 目录：[[01-AI化学实验室/项目概述|01-AI化学实验室]] + [[04-实验室自动化/项目概述|04-实验室自动化]]

### 定位
打造**高通量无人化学实验平台**，类比晶泰科技（XtalPi，生物制药）的**化学版**。核心逻辑：**前端 LLM 生成配方/实验方案 → 后端人形机器人自动执行验证。**

### 我们做了什么（这是投入最深的一条线）
- **物理实验室已就绪**：与**浙江大学**朋友联合搭建，方向是**催化剂合成高通量实验**；表征设备 + 实验平台已完成，缺的是**具身智能/机器人自动化层**（现正攻）。
- **8 种核心实验室操作**：抓取 / 倾倒 / 插入 / 旋转 / 按压 / 滑动 / 擦拭 / 夹取。
- **主参考框架 = LabVLA**（浙大 + 上海 AI Lab 开源，`github.com/zjunlp/LabVLA`）：已在 RTX 4060(8GB) 上用 **4-bit 量化**跑通 Phase 1（WebSocket/msgpack，RTT ~2.2s），Phase 2 在推进。
- **触觉编码方案（已定稿）**：手套 124 点 → **12×12 网格 × 3 通道**（压力 / 变化率 / 振动）→ CNN 编码 → 作为条件信号喂入策略模型。
- **数据策略**：仿真预训练（RoboGenesis/MuJoCo）+ 真实数据（手套 + IMU + 视觉）微调。
- **仿真选型**：主力 **MuJoCo + MJX**（免费开源，原生触觉 sensor，GPU 批量）；备选 Genesis（2027 再评估）。
- **硬件**：IMU（BNO055 调试失败→换型号）、视觉 **Intel RealSense D435**、机械臂在 Franka / OpenArm / 宇树 G1-D 间评估；WSL2(Ubuntu) 开发环境。
- **⚠️ 重大架构转向（2026-07-24）**：**放弃 LabVLA 端到端 VLA 路线 → 转向分层架构**：🧠 大脑（前沿 LLM 做 SOP 理解/24 步规划，0.1–1Hz）+ 小脑（Specialist，**Diffusion Policy**）+ 脊髓（经典控制）。
- **商业化路径（04 / 决策说明）**：把触觉技术装进「**DRIFTS 原位红外催化实验自动化系统**」卖高校/中科院（零件 ¥2000/双 → 系统 ¥30–50 万/套，政策补贴可达 80%）。

### 当前状态
概念→工程验证期。架构定稿，Phase 2（MuJoCo 场景 + WebSocket 客户端）推进中；**待真机与数据管线启动**。

### 关键事实
- 三大支柱：①高通量无人化学实验 ②具身智能 + 人机协同（1 人 + 多机器人，机器预判人下一步）③物理 AI / 世界模型。
- **触觉手套的定位已校正**：它是**示教器 / 数据捕捉器**，**不是机器人皮肤**。
- 分工：浙大→化学/催化剂/分子设计；Josan→AI 自动化/具身智能/数字孪生；目标跑通链路后融资。
- 参考论文：**LabVLA**（主框架）、**T-Rex**（触觉编码）、**RoboGenesis**（数据引擎）。
