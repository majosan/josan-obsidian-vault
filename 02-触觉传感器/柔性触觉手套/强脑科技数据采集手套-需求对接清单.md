## 一、对接背景（内部参考）

强脑科技 Revo3 灵巧手已明确配套「灵巧操作数采矩阵」（双臂轮式真机平台 + **高精度数据手套**），用于采集真机 / 人类示范 / 虚拟仿真数据训练模型。

我们以「柔性织物触觉数据采集手套」切入，目标是进入其**数采手套供应商目录 / 第二供应商**。

⚠️ 尽调结论提醒（详见配套文档）：
- 仿生手柔性触觉阵列已被**苏州能斯达**绑定（市场称独家）
- 灵巧手指尖触觉走**自研磁性方案**（专利 CN121572345B，文本明确贬低压阻路线）
- 灵巧手传感模组还有**领益智造**联合开发（样机阶段）
- **大面积织物触觉 / 数采手套是尚未锁定的开放地带** —— 本次对接的主攻方向

## 二、我方产品能力对标（内部参考，不对客）

| 指标 | 我方现状 | 行业参考（竞品） | 差距判断 |
|---|---|---|---|
| 传感点数 | 124（手指 60 + 掌心 64） | 舞肌 526 / 临界点掌部 300+ | 偏低 |
| 采样率 | 15 Hz | 60–120 Hz | **短板** |
| 最小可检测力 | ~5 g | 5 g–1 N | 优势 |
| 力维度 | 法向压力为主 | 三维力（磁性方案） | 短板 |
| 形态 | 全织物、透气、可折叠、可水洗 | 薄膜 / 刚性离散点 | **核心优势** |
| 串扰 | 电路隔离好、低串扰 | — | 优势 |
| 一致性 | 跨点一致性差，需逐点校准 | — | 弱点 |
| 大面积成本 | 摊薄 | 随点数线性上升 | 优势 |

**结论**：不硬拼帧率/点数/三维力，打「全织物形态 + 大面积成本 + 数采/示教场景」差异化。

## 三、触觉数采手套 · 行业参数底账（内部参考）

**竞品真实参考：**
- 舞肌 Wuji Glove：526 触点、EMF 磁场姿态追踪、120 FPS、主打机器人遥操作
- Manus MetaGloves Pro Haptic：毫米级手部追踪 + 实时触觉反馈
- PPS TactileGlove：握力量化、压力量化
- 矩侨工业触觉手套：人形机器人触觉感知

| 维度 | 关键指标 | 行业常见基准 |
|---|---|---|
| 传感密度 | 点数 / pitch / 空间分辨率 | 100–500+ 点，指尖更密 |
| 压力量程 | N 或 kPa | 常见 0–10N 或 0–50N 级 |
| 灵敏度 | 最小可检测力 | 5 g–1 N |
| 精度 | 线性度 / 重复性 / 迟滞 | 重复性 ±3–5% FS 常见 |
| 采样率 | FPS | 60–120 Hz |
| 响应/延迟 | 接触到位数据 | 毫秒级，越低越好 |
| 串扰 | 单点受力影响邻点 | 越低越好 |
| 一致性 | 多点间均匀性 | 织物弱项，靠逐点校准 |
| 耐久 | 循环寿命 | 万次级起步 |
| 姿态 | 手指弯曲/位姿/IMU | 多数高端款融合 EMF 或 IMU |
| 接口 | USB/无线 + SDK/ROS2 | 开源生态是加分项 |
| 认证 | IP / EMC / 体系 | 看客户场景要求 |

## 四、问题清单（可直接转发）

### 🎯 核心必问（优先转达，6 条）

1. 贵司「数据采集手套」的主要用途是什么？是否与 Revo 灵巧手配套，用于采集人手操作数据做**遥操作示教 / 模仿学习**？
2. 目前这块是自研还是有在用 / 在评估的外部供应商？方便透露**品牌、型号、大致价位**吗？
3. 对触觉传感的硬性要求：**点数 / 密度、量程、最小可检测力、采样率（Hz）**，有没有明确规格或验收标准？
4. 是**纯触觉**，还是需要同时采集**手指姿态 / 关节角度 / 位姿**（即是否要融合 IMU 或弯曲传感器）？
5. 数据接口与集成要求：USB / 无线？是否要求 **ROS / ROS2、Python / C++ SDK**？数据格式偏好？
6. 预计**用量（年需求 / 首批）**和**目标价位区间**？是否接受**定制开发 / ODM**？

### 🔍 补充追问（有时间再问）

7. 对**精度、线性度、重复性、迟滞**这些指标有具体验收值吗？
8. **响应延迟、多点串扰、长时间漂移**有没有硬性要求？
9. 是否需要触觉数据与姿态 / 视觉数据做**时间戳同步**（多模态对齐）？
10. 数据输出形式：原始 ADC 值 / 归一化压力值（N）/ 是否接触二值？
11. 对供应商资质有硬门槛吗？（ISO 9001 / 车规 IATF 16949 / 医疗 ISO 13485）
12. 方便的话，能否发一份**现有规格书（spec）或询价需求（RFQ）**给我们对标？

## 五、策略提示（内部参考）

1. 本次别急着推销参数，先通过**第 2 问**探出他们现在用谁、什么规格价位，再决定要不要补测、往哪个指标上打。
2. 切入话术定位：「**大面积织物触觉 + 数采手套示教场景**」，与能斯达（仿生手薄膜阵列）、自研磁性（指尖三维力）错位，不正面撞。
3. 若对方提到对压阻路线的疑虑（其专利贬低压阻），准备实测证据：贴合度、透气可洗、大面积成本曲线、数采手套 demo。
4. 探到规格后，重点评估：我方 **15Hz 帧率 / 124 点密度**是否满足其数采用途——数采（离线示教）对实时性要求通常低于闭环控制，这可能是我们的回旋余地。
