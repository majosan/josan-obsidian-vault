## 〇、概论

**强脑科技 = 非侵入式脑机接口全栈公司（传感器自研+整机+算法），"杭州六小龙"之一，上市前夜**（2026年初秘密递表港交所，估值超120亿，刚融20亿，全球BCI领域仅次于Neuralink的单笔融资）。

<font color="#00b050">供应商：</font>
<font color="#00b050">1. ✅ 仿生手内部的**柔性触觉传感器阵列**供应商是**苏州能斯达**（汉威科技300007控股子公司），多家财经来源称其为"独家供应商"，但市场对此有争议。</font>
<font color="#00b050">2. **蓝思科技是另一个层面**：它是战略股东（持股约5.9%，累计投资约2000万美元），负责**核心硬件模组的量产承接**（整机组装/模组制造），不是传感器本身。两者不冲突。</font>
<font color="#00b050">3. **关键发现**：强脑的触觉布局不止仿生手——2026年1-5月自研磁性触觉传感器专利族（指尖/指节三维力），Revo3灵巧手用"全掌阵列触觉传感器+指尖视触觉传感器"，并拉**道氏技术**（碳纳米管材料）入股推进**电子皮肤**应用。**大面积触觉（手掌/皮肤）可能我们的机会窗口。**</font>

**匹配结论：** 强脑的触觉传感是"三线并进"——①仿生手用能斯达柔性触觉阵列（外采）②灵巧手/机器人手指用自研磁性方案（专利2026年落地）③电子皮肤材料与道氏合作。
**我们可能合作定位：
  1.大面积柔性触觉阵列/电子皮肤模组的"第二供应商+联合方案伙伴"**
  2.直接对标能斯达在仿生手的位置
  3.是否往他们没覆盖的场景（手掌大面积、仿生腿接受腔、全身皮肤、医疗康复）或者是未来可能入局的领域来补充优化他们的场景应用。

## 三、技术路径与专利壁垒

### 3.1 技术栈
- 非侵入式EEG/EMG采集（干电极免导电膏）→ AI深度学习解码（"在喧嚣大海边听50公里外蚊子扇翅膀"）→ 控制假肢/灵巧手/康复训练
- 信号识别准确度达医疗级脑电设备95%+

### 3.2 专利总量
- 550+项申请 / 360+项授权 / 发明授权近200项（截至2024.4）；250+核心专利（2025.7口径）
- Google Patents 检索：EEG采集、注意力/睡眠/癫痫/心理检测算法、仿生手控制（手势锁定/抓握稳定性）、智能膝关节防摔、假肢控制、触觉手指/灵巧手/机器人

### 3.3 触觉专利族（2026年密集落地）
- **CN121572345B《仿生触碰感应装置、触觉手指、仿生手及仿生机器人》**（2026.1.28申请，2026.5.5授权，发明人含韩璧丞）
  - 方案：指骨+弹性表皮容置腔，内嵌**磁性触觉传感器**（永磁体+三轴霍尔/AMR/GMR/TMR磁敏芯片）
  - 能力：法向压力+双向剪切三维力，非接触式、高灵敏、长寿命；16/18bit Σ-Δ ADC，SPI/I2C/CAN-FD高频上传；用于抓力闭环/滑脱前馈/姿态自适应
  - 结构：凸台/接触槽/磁性凸块"触感传递结构"+沟壑解耦，单指节紧凑集成
  - **说明书明确贬低压阻/电容/压电路线**："传统刚性传感器（如电阻式、压电式）难以与柔性表皮顺应贴合，容易因接触面积受限而发生感应缺失，且易受手指曲率影响而产生感应盲区"——**对接必考题**
- 同族：触觉手指指节机构、触觉手指及机械手掌/机器人、紧凑型触觉手指、灵巧手控制、抓握稳定性控制等（触觉关键词检索约22条）
- **未检索到织物/纺织/大面积电子皮肤专利**（其电子皮肤走道氏碳材料合作路线）

### 3.4 专利 vs 外采的推论【推断】
- 仿生手（已量产）：触觉外采能斯达（柔性阵列）
- 灵巧手/机器人（新品）：自研磁性触觉专利2026年落地，倾向自研或"自研+外采并行"——**Revo3全掌阵列触觉传感器的最终供应商是本次对接要核实的第一问题**

| 维度   | 强脑（仿生手/Revo系列）        | 我们的柔性织物传感阵列                                       |
| ---- | --------------------- | ------------------------------------------------- |
| 感知原理 | 外采：能斯达柔性压阻阵列；自研：磁性三维力 | <font color="#ff0000">压阻式织物正交阵列（镀银纱线×压敏纱线）</font> |
| 形态   | 指节内嵌离散点 + 全掌阵列        | 全织物大面积连续阵列，可折叠透气                                  |
| 传感点  | 指节少量点/掌部离散点阵          | 目前手部是124个这列点                                      |
| 力维度  | 三维力（法向+剪切）            | <font color="#ff0000">法向压力为主</font>               |
| 带宽   | 闭环控制级（CAN-FD高频）       | <font color="#ff0000">15Hz采集级</font>              |
| 大面积  | 成本随点数线性上升             | 大面积摊薄成本                                           |
| 数据用途 | 抓力闭环/滑脱预警/灵巧操作        | 压力分布图/姿态识别/康复评估                                   |

| ★★★ | **人形机器人电子皮肤**        | 道氏碳材料合作仍在"推进"阶段（2025.10官方口径），未量产；织物路线是成熟替代           |

### 5.3 竞争/风险提示
- **能斯达是直接竞对**：同为柔性触觉阵列路线，已绑定仿生手。我们切入要差异化：①更高密度（阵列点数）②全织物（透气/可洗 vs 薄膜）③医疗养老场景（配合他们未来趋势方向）
- **自研磁性专利的"技术偏见"**：他们的专利文本贬低压阻路线——需要准备"织物压阻在特定场景的实测优势"（贴合度/透气/大面积成本/穿戴性）
- **"独家"格局**：能斯达被称独家供应商（有争议）→ 我们作为"第二供应商"切入，谈判筹码是密度/织物特性/场景方案
