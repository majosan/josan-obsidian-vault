# 04 · 生产 SOP 与工具清单

> 目标：把"做一条视频"变成流水线，每周 5 小时稳定出 1 条。
> 原则：先全免费跑 2 周，确认能坚持，再开付费会员。

## 一、工具清单与费用

| 环节 | 工具 | 费用 | 说明 |
|---|---|---|---|
| 文案/脚本 | DeepSeek（就是我） | 免费 | 你只管提需求，脚本、分镜、提示词我全包 |
| AI 绘图 | **即梦 AI**（字节，网页/App） | 免费额度+会员约 ¥50-70/月 | 主力工具，中文提示词友好，历史题材出图好 |
| 图生视频 | 即梦 AI / 可灵（快手） | 免费额度 | 只给关键镜头加运镜，别浪费额度 |
| AI 配音 | 剪映「文本朗读」 | 免费 | 解说音色足够用，不用买配音软件 |
| 剪辑/字幕 | 剪映 | 免费 | 一条龙搞定 |
| 发布 | 抖音 + 头条号/西瓜 | 免费 | 中视频联动必做 |

**预算结论**：前 2 周 0 元；第 3 周起开 1 个即梦会员（约 ¥69/月），总月成本 ≤100 元。不买任何"AI 副业课程"，所有技能我这都有。

## 二、每周 5 小时排期（照抄）

| 时间 | 时长 | 干什么 |
|---|---|---|
| 周一晚 | 30 分钟 | 选题：从 `02-选题库.md` 挑 1 个，过一遍"自检清单"，把选题发我 |
| 周二晚 | 60 分钟 | 跟我确认脚本定稿（我出初稿，你只管提修改意见） |
| 周三晚 | 90 分钟 | 即梦生成全部画面（约 7 张图 + 2 段图生视频），每张抽 2-3 次选最好 |
| 周四晚 | 90 分钟 | 剪映：配音→字幕→BGM→封面→导出 |
| 周五晚 | 30 分钟 | 发布 + 同步西瓜/头条 + 回复评论 |
| 周末 | 30 分钟 | 数据复盘（见下方模板） |

**共 5.5 小时。** 如果某周太忙，砍掉"图生视频"环节，只出静态图+推拉效果，可省 30 分钟。

## 三、单条视频生产流程（6 步）

1. **定题**（30min）→ 选题库挑题 + 自检清单打分
2. **脚本**（我出）→ 你确认后，生成分镜表 + 每镜提示词
3. **出图**（90min）→ 即梦逐镜生成，不合格的当场重抽
4. **动效**（可选）→ 关键镜头图生视频，加运镜
5. **剪辑**（90min）→ 剪映装配：配音/字幕/BGM/封面
6. **发布**（30min）→ 标题/标签/AI 标识/同步头条西瓜

## 四、数据复盘模板（每周六花 30 分钟填）

| 视频 | 播放 | 完播率 | 平均观看时长 | 点赞 | 评论 | 涨粉 | 中视频收益 | 结论 |
|---|---|---|---|---|---|---|---|---|
| 第1条-古人避暑 | | | | | | | | |

**看数据的方法（别只看播放）：**
- **完播率 >30%**：内容 OK，问题可能在封面/标题 → 换标题重发一次试试
- **完播率 <20%**：开头钩子不行 → 下条开头 3 秒换更硬的钩子
- **播放 5000+ 但没涨粉**：结尾引导弱 → 强化"关注我，下期讲XX"
- **某类选题播放明显高**：下周立刻多做同类（数据会告诉你方向）

## 五、发布与运营技巧

1. **发布时间**：工作日 18:30-20:00 / 周末 11:00-13:00
2. **发布后 1 小时**蹲评论区，每条评论都回（评论权重高，能撬动推荐）
3. **一条内容两次用**：中视频（90 秒）发西瓜/头条；同时剪一版 30 秒精华发抖音短视频，标题加"完整版在主页"
4. **别删视频**：播放再差也留着，删视频会影响账号权重
5. **每周固定更新**：断更比内容差更伤账号

## 六、月度复盘（第 4 周做一次）

- [ ] 累计发了 4 条？→ 没发够，压缩制作时间（砍动效、批量出图）
- [ ] 平均完播率趋势？→ 上升说明方向对，下降换开头钩子
- [ ] 有没有单条破 5000 播放？→ 有：复制它的选题类型；没有：回 `01-起号方案.md` 看差异化三选一要不要换
- [ ] 是否已满足中视频计划/千粉条件？→ 满足就立刻申请开通
- [ ] 情绪状态：还愿意做吗？→ 疲惫就切治愈系图文（见 01 方案第六节）
