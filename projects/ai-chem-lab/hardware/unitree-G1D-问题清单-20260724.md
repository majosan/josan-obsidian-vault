# 宇树 G1-D 技术问询清单

> **场景**：AI 化学实验室 · 高通量催化剂合成平台
> **集成对象**：LabVLA 框架（VLA 路线，50亿参数模型）
> **精度目标**：±0.15mm 定位 / 0.05-0.10N 力控
> **日期**：2026-07-24

---

## 🥇 第一优先级 — 决定能否集成 LabVLA

### Q1 底层 SDK / API 开放程度
- G1-D 是否提供 **底层控制 SDK**（C++/Python）？
- 能否通过 API **直接发送关节角度指令**（非遥控器模式）？
- 是否支持 **末端位姿控制**（笛卡尔空间）？而非仅关节空间？
- 电机通信协议是啥？**EtherCAT / CAN / 自有协议**？

> **Why**：LabVLA 输出 (50×8) delta mode 动作序列，需要能直接写入关节或末端控制接口。如果没有底层 SDK，完全无法集成。

### Q2 控制模式与频率
- 支持哪几种控制模式？
  - ☐ 位置控制 / 速度控制 / 力矩控制
- **控制循环频率**是多少？（Hz）
- 是否有**实时模式**（RTOS / PREEMPT_RT）？
- 控制指令到执行器响应的**延迟**大概多少？（ms）

> **Why**：精细操作需要高频控制闭环，位置控制≥100Hz，力矩控制≥500Hz 才够。

### Q3 重复定位精度
- **实测重复定位精度**是多少？（官网没标这个参数）
- 是否提供末端位姿的**闭环反馈**（由关节编码器回读）？
- 关节编码器分辨率？

> **Why**：DRIFTS 要求 POC 阶段 ±0.25mm，成熟阶段 ±0.15mm。G1-D 臂展 ~0.45m，如果只有 0.1° 关节精度，末端折算约 0.78mm，差很多。

## 🥈 第二优先级 — 力控与灵巧手

### Q4 灵巧手力控规格（Dex3-1 / Revo 2）
**Dex3-1 力控三指（有触觉版）：**
- 触觉传感器 **采样频率**？（Hz）
- 触觉数据**能否实时回读**到上位机？（通过什么接口？）
- **力控模式**：支持主动力控还是只做检测？
- 能否做**阻抗控制 / 导纳控制**？

**通用：**
- 灵巧手**控制频率**？（Hz）
- 夹爪/手指**位置分辨率**？

> **Why**：实验室力控需求 0.05-0.10N，Dex3-1 触觉下限标称 10g(~0.1N) 刚刚到门槛，需要确认实测能达到多少。

### Q5 力控闭环
- 手臂本体是否支持**力控/力矩控制**？
- 有没有**关节力矩传感器**？（还是仅靠电流估算？）
- 能否实现**阻抗控制**？（对末端触碰力控制至关重要）

## 🥉 第三优先级 — 集成与部署

### Q6 ROS / ROS2 支持
- 是否提供 **ROS / ROS2 驱动包**？
- 如果提供，支持哪些 topic / service？
- 如果不提供，是否有第三方社区方案？

> **Why**：现有 AI 框架栈（LabVLA + PyTorch）都跑在 Ubuntu，ROS 是机器人集成的事实标准。

### Q7 上位机与算力
- Jetson Orin 16G（100 Tops）上能否**替换为自研算法**？
- 还是只能跑宇树预装的数采软件？
- 上位机**能否直连外部 GPU 服务器**（通过以太网）？
- 能否**旁通宇树数采软件**，直接控制机器人？

### Q8 数采平台 API
- 数据采集平台是否提供 **API / SDK** 导出原始数据？
- 数据格式是啥？能否对接外部训练管道？
- 是否支持 **自定义数据格式**？

### Q9 手眼标定
- 手腕相机到末端夹爪的**手眼标定**是否预标好？
- 有没有提供**标定参数**或标定工具？
